# 원정 경제·상점·전투 다양성 · 규칙 26

2026-09-12. 사용자 요청: 전투 보상을 모아서 쓰는 경제, 상점 노드, 반복 방/적 개선, 루나 원점 조준 중 카드 상세 충돌 수정, 이후 성좌 개편 준비.

## 실제 보상과 소비

- 새 원정의 은화는 0에서 시작한다. 승리 시 일반 10~13 + 층 인덱스×2, 정예는 추가6, 보스는 추가12를 지급한다. 층 인덱스는 0~2다. 원정이 끝나면 다음 원정으로 이전하지 않는다. 영구 잔광과 별도다.
- 승리마다 연구권1장을 받는다. 지도에서 1장을 써 카드3종 중 하나를 고른다. 즉시 쓸 필요가 없으며 손패/덱이 자동으로 늘지 않는다. 선택 화면을 넘겨도 사용한 연구권은 반환하지 않는다고 표시한다. 덱이 가득 차면 사용 불가다.
- 기존 일반 카드 보상과 정예/보스 유물 보상은 유지한다. 도입전을 제외한 일반 전투는 25% 확률로 카드 보상 뒤 추가 유물 선택을 제공한다. 유물 한도나 미보유 후보가 없으면 추가 보상 없음. 무조건적인 유물 지급으로 표현하지 않는다.
- 층마다 다섯 번째 방문 행에 상점1개를 보장한다. 그 직전의 모든 경로에서 상점과 다른 보상 방 중 하나를 고를 수 있다. 상점을 강제로 방문하지 않는다.
- 은화 이벤트4종, 휴식3종, 공방3종을 조합한다. 같은 행의 휴식/공방 텍스트가 중복되지 않도록 선택한다. 첫 정비의 무료 연마는 유지한다.

| 상점 상품 | 가격 | 제약 |
| --- | ---: | --- |
| 카드1종 | 8 + 희귀도 인덱스×2 | 덱 한도, 구매 전 위력과 적/자가 효과 표시 |
| 미보유 유물1종 | 24 | 중복/보유 한도/품절 차단 |
| 회복약 | 8 | 최대 체력의30%, 만피 구매 불가 |
| 도구 연마 | 16 | 원정 그래프 피해+1, 훈련 최대+3 |
| 카드 제거 | 10 | 카드 확정 시 결제, 취소 시 무차감·같은 상점 복귀 |
| 성장점1 | 12 | 해당 상점에서1회 |

상품별 구매1회, 은화가 남으면 다른 상품을 더 살 수 있다. 재입장/새로고침으로 재고를 복구하지 않는다. 기본 성장 지급량35점은 유지하되, 상점에서 추가 성장점을 최대3점 구매할 수 있고 기존 이벤트/영구 출발 경험은 별도다. 가격과 수입은 초기 조정값이며 전체 원정의 최종 밸런스를 검증한 숫자가 아니다.

## 방과 적

`ExpeditionContent`는 기존 지도 위에 경제 원정용 콘텐츠를 구성한다. 1층 도입·정비·기술 활용·약한 무리/정예 선택의 역할을 유지한다. 활용전/돌파전의 실제 좌표는 시드별로 조금 달라진다. 이후 비보스 전투는 돌격·협공·포수 호위·봉인 순찰·수호 방진·격앙 추격·이동 포대·매듭 경비의8개 조합을 사용한다. 같은 행의 조합은 중복시키지 않는다. 적 수, 배치, 체력, 의도와 작도 장치의 조합이 바뀐다.

이는 기존에 작동하는 이동/축적/격앙/포수/봉인/연결 행동을 조합한 콘텐츠다. 새로운 AI8종이나 새 보스 전체를 구현한 것은 아니다. 보스는 기존 정의를 유지한다. 난이도는 새 경제와 성장 수입을 포함해 플레이 피드백으로 재조정해야 한다.

## 전투 화면

전장 좌표0~10/−4~4와 판정은 유지한다. 논리 화면의 Field는(460,88,1000,800), 두 축100px/단위다. 화면 아래 작도 영역을 카드 기본 위치(910px 이후)에서 분리하기 위해 균일 축소·상향 배치했다. 축척을 다르게 늘이거나 실제 좌표를 변경하지 않는다.

능력 설명과 조준 안내는 오른쪽으로 옮겼다. 기술 조준 중 DrawHand는 확대/호버/클릭을 받지 않고, 키워드 팝업도 숨긴다. HandleBoardInput은 조준 중 남아 있는 카드·키워드 영역을 차단 조건으로 사용하지 않는다. 일반 카드 선택에서는 기존 앞쪽 카드 우선·누름/뗌 일치 검사를 유지한다.

## 성좌에서 바로 알 수 있는 범위

새 전투 방식은 기존 CombatForm 장착 필드를 대부분 사용하지 않으므로 `PrototypePartial` 메타데이터만으로 ‘작동’이라고 표시하면 잘못된 안내가 된다. `GrowthRuntimeSupport`가 실행 경로 기준으로 현재 지원하는 핵심/특성/궁극기를 구분한다. ‘전투 효과 노드 찾기’, 노드 위 상태, 조건부 적용 설명을 추가했다. 미연결 노드는 ‘고유 효과 연결 대기’와 ‘경로용 습득 · 효과 없음’으로 구매 전에 구분한다. 현재 경로·숙련 투자 기능만 있다는 점을 명시한다.

루나의 관측 핵심은 새 규칙26 원정에서 장착하면 다음 전투부터 실제 관측형으로 전환된다. 기존25 이하 원정에는 이 의미 변경을 소급하지 않는다.

240개 노드 효과를 전부 구현한 것이 아니며, 미연결 선행 노드 문제가 문구만으로 해결됐다고 보지 않는다. 지금 미연결 구매를 모두 차단하면 기존 트리의 시작 경로까지 막히므로, 경로 재편과 실제 효과 연결을 다음 단계에서 함께 처리한다. [다음 개편의 기술 범위](GROWTH_REWORK_NEXT.md).

## 저장·소유권

형식2/규칙26. 기존21~25 읽기 유지. `ExpeditionEconomy / BuyShop / UseResearch`를 저널 끝에 추가한다. 새 원정/재시작에서 ChooseApproach → OpeningRoute → ExpeditionEconomy 순서로 opt-in한다. 기존 이어하기에는 새 명령을 삽입하지 않는다. 새 명령을 구버전 payload에 섞으면 거절한다.

RunGameSession이 은화/연구권/추가 유물 대기/재고/제거 예약을 소유한다. 지갑과 재고는 성공 명령의 결정적 재생으로 복원한다. 일반 카드 보상 RNG와 분리된 전리품 RNG는 seed XOR 상수로 초기화하고, 상점 재고는 seed+노드 인덱스에서 별도로 생성한다. 화면 열기, 미리보기, 실패한 구매는 난수를 소비하지 않는다. 재현을 위해 생성 순서/상품 ID/가격/확률 변경 시 새 규칙 또는 명시적 이행이 필요하다.

상점은 방문 시 불변 상품6개와 고정 bool[6] 판매 상태를 갖는다. 제거 확정 전에는 차감하지 않는다. 확정된 제거/스킵 뒤에는 완료된 지도 노드로 가는 일반 보상과 달리 원래 활성 상점으로 복귀한다. 원정 완료는 상점 나가기에서1회만 처리한다. 연습/노드 체험에는 돈이나 연구권 보상이 없고, 원래 원정 저장 보호를 유지한다.

전투 루프/충돌/미리보기의 새 배열 할당은 없다. 상점 카드 설명은 상품 참조가 바뀔 때 View에서 한 번 조립·캐시한다.
