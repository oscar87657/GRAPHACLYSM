# 첫 원정 흐름 · 규칙 25

2026-09-12. 전투 기술·판정과 핵심 노드 체험 다음 단계인 P4의 1층 페이싱을 적용했다. 새로운 능력이나 궁극기 효과를 추가한 단계는 아니다.

## 새 원정의 순서

| 방문 | 역할 | 실제 선택과 변화 |
| --- | --- | --- |
| 1 | 도입 | 장치 없는 일반 적 2명. 첫 승리 성장점 2점. 위쪽/가까운 잔영 배치 |
| 2 | 정비 | 휴식: 회복/보호막/공명. 공방: 무료 원정 피해 +1/카드 선택/카드 제거 |
| 3 | 활용 | 움직이는 적 + 일반 적 또는 포수. 여러 새 장치를 동시에 가르치지 않음 |
| 4 | 돌파 또는 도전 | 체력12의 적 3명을 몰아치거나 체력36/30/30의 정예에 도전. 일반은 카드, 정예는 유물 |
| 5 | 보상 | 기존 유물/공방/보급 분기 |
| 6 | 응용 | 기존 1층 복합 전술전. 기술을 봉인·연결·사선과 결합 |
| 7 | 보스 준비 | 휴식 또는 공방. 지도/휴식에서 성좌 변경 가능 |
| 8 | 첫 보스 | 기존 보스. 승리 성장점 3점과 기존 보스 보상 |

첫 정비·돌파·보스 준비에 들어오는 각 경로는 서로 다른 종류 둘을 선택할 수 있다. 활용전으로 들어갈 때도 기동/포수 대응이 함께 열리며 지도에 방 특징을 짧게 표시한다. 모든 노드의 진입 경로를 유지한다. 단일 상승 성좌, 네 출발 능력, 여섯 장 시작 덱, 이동/적중 규칙, 2·3층 콘텐츠는 유지한다.

첫 보스의 기본 지급 4점 중 1점을 첫 전투로 앞당겼다. 모든 방의 기본 지급은 1점 이상, 최종 보스 전 기본 총량은 시작 6점을 포함해 35점이다. 별도 이벤트 선택과 영구 출발 경험은 이 기본 총량 밖이다. 첫 공방은 기존 TrainingPower +1 (최대 +3)을 사용한다. 휴식에서 같은 공격 보상을 중복 제공하지 않는다.

지도 왼쪽 기존 안내를 현재 단계의 짧은 안내로 교체했다. 새 보상 화면은 이번 방 지급량과 사용 가능한 성장점을 표시한다. 성좌 자동 구매·구매 강제·편의 기능 해금은 추가하지 않는다.

## 저장과 소유권

형식2/규칙25. 성공 명령 ID 끝에 OpeningRoute를 추가했다. 새 방식 원정 시작/재시작에서 ChooseApproach 직후에만 기록한다. 연습·핵심 체험·기존 이어하기에는 삽입하지 않는다. 21~24 저장은 기존 생성기/도입전으로 재생한다. 구버전 payload에 새 명령을 섞으면 거부한다.

OpeningRoute.Create는 새 시작 명령에서만 불변 지도/1층 정의를 만든다. 원래 생성기의 난수 소비와 뒤층 정의를 보존하며 2·3층 노드는 동일 객체를 공유한다. RunGameSession은 진행 전 시점에만 RunMapProgress를 교체한다. 프레임/기하 루프의 새 배열이나 화면에 의한 전투 상태 수정은 없다. LastExplorationPoints는 완료 명령 재생으로 재생성되는 표시 값이다.
