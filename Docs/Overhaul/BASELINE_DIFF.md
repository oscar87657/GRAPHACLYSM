## 실제 기준 검증

수정 전 Assets를 격리 프로젝트에 복사하여 Unity 6000.3.23f1 EditMode 재실행: **194/194 통과**. `Logs/overhaul-baseline.xml`, `Logs/overhaul-baseline.log`. 이전 기록을 복사한 수치가 아니다. 사용자 Editor와 영구 기록은 변경하지 않았다.

## 입력 조사 결과

`GraphaclysmModernView` K/버튼 → ToggleCombatSkillTargeting → `GraphaclysmModernBattle.HandleBoardMovement`의 적 클릭 → UseCombatSkillOnTarget → RunGameSession → BattleSession.

기존 Core는 죽은 대상/범위 밖 인덱스를 최근접 대상으로 대체했고 FindSkillLanding의 false를 무시했다. v21은 이 두 실패를 거절한다. 기존 재생/명시 빠른 선택용 -1만 보존하며 View에서는 전달하지 않는다.

주 대상은 사거리 제한 없이 별도 공격이고 이안 일부 기술의 이동만 2.8로 제한된다. 이는 기하학 경로와 별개인 v20 규칙이다. 이번에는 수치를 임의 변경하지 않고 미리보기의 GeometryHit과 Hit을 분리한다. 이 차이를 후속 사거리 설계에서 검토해야 한다.

이 조사는 과거 사용자가 겪은 무피해 버그의 실제 원인 확정을 뜻하지 않는다. 실제 OS 마우스/K 전체 입력 재현은 검증대기다.
