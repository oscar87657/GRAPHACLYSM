# 한 번의 작도 · 플레이 가능한 전투 비교

2026-09-12. 최신 사용자 방향의 첫 제작 목표인 **같은 전장, 같은 재료, 다른 해결법**을 구현했다. 기존 원정 전체를 교체한 버전은 아니다. 240개 성좌, 첫 원정 성장 순서, 영구 성장 환급은 이번 변경으로 완성되지 않았다.

후속: 사용자의 체험 승인 후 실제 원정에 연결했다. 현재 플레이는 [규칙22 원정 연결](APPROACH_CAMPAIGN_V22.md)을 따른다. 아래 내용은 비교 전투 자체의 계약이다.

## 실행

`Assets/Scenes/SampleScene.unity`에서 Play. 메인 오른쪽 **새 전투 · 한 번의 작도로 뒤집기**에서 세 방식을 고른다. 별도 Editor 명령 없이 사용할 수 있다.

- 공통: 체력 42, 적 3명, 동일 시드 24601. 긴 황혼·파열·여백·승천·고요·잔향 여섯 장으로 시작하며 기존 보존/예약/보충 규칙을 사용한다. 영구 보정·유물·성장 보정 없이 시작한다.
- 집행 이안: 직선 집행을 즉시 사용한다. 피해 10, 살아남은 적에게 파열 6(2턴). 다음 직접 작도가 파열을 소비한다. 기술 처치는 대기시간을 초기화한다. 기존 명시 대상 별도 타격과 착지 규칙을 유지한다.
- 기록 이안: 조립 후 K, 다음 방출에서 재현할 기준점을 클릭한다. 기준점 이동 한도 3. 이번 직접 피해는 75%(정수 내림), 다음 방출에 저장된 도안이 추가 공격한다. 기록 중에는 다시 예약할 수 없다. 몸은 이동하지 않으므로 별도로 회피해야 한다.
- 조율 루나: 조립 후 K, 새 기준점을 클릭한다. 기준점 이동 한도 3, Q/E로 -90~90도 사이 30도씩 회전한다. 턴당 한 번. 몸과 손패는 그대로이며 이후 카드는 실제 조정된 궤적을 변형한다.
- 우클릭으로 조준 취소. 조정/기록 예약 전에 놓은 카드는 되돌릴 수 없고 이후 추가한 카드만 취소할 수 있다. 조준 단계 자체에는 비용이 없다.

## 검증된 대표 행동

루나가 움직이지 않고 `긴 황혼 → 파열`을 사용하면 처음에는 돌격병 한 명만 맞는다. K로 기준점을 `(5.25, -1.5)`, 회전을 `-90°`로 바꾸면 돌격병·측면병 두 명을 맞히고, 자기 적중으로 보호막을 얻으며, 동력선을 잘라 포격도 중단한다. 회귀 테스트가 실제 시작 손패와 실제 판정으로 이 조건을 검사한다.

포수 `(8, 1.8)`와 기점 `(5, 1.6)` 사이 동력선은 실제 작도 선분과 반경 0.12로 접촉을 검사한다. 절단 시 그 전투의 포격이 중단된다. 사전 예측만으로는 중단하지 않는다. 포수를 먼저 처치하거나 기존 고정 사선을 피해도 된다. 기록 공격은 동력선을 자르지 않는다.

## 실제 규칙과 표시

조율 예측은 전투가 소유한 재사용 도안 버퍼로 계산한다. 실제 조정은 같은 회전/이동을 실제 파편 좌표에 적용한다. 기록은 실제 표본과 조립 위력만 저장한다. 회복·드로우·자가 적중·공명·궁극기·원본 카드 상태 적용은 복제하지 않는다. 이미 있는 파열은 한 번 소비하며 기록이 새 기록을 만들지는 않는다.

기록 도안은 보라색, 조율 후보는 민트색이며 문장으로도 구분한다. 기록의 다음 방출 피해는 적의 예상 체력 피해에 포함한다. 결과는 직접 작도와 기록의 적중 수, 보호막, 포격 차단을 따로 표시한다. 직접/기록이 같은 적을 맞히면 각각 한 번으로 표시되며 고유 적 수로 합치지 않는다.

## 저장 격리

`SignatureBattleFactory`는 일반 전투/Application을 사용하는 별도 `IsPractice` 세션을 만든다. 저널을 만들지 않고 `CanSave=false`이며 저장 어댑터도 저장을 거부한다. View의 자동 저장·종료 저장·종료 잔광 지급을 건너뛴다. 승리 후 카드/유물/성장 보상도 지급하지 않는다. 연습 시작과 재시작은 다음 일반 원정의 시드를 진행시키지 않는다. 기존 이어하기와 영구 기록을 삭제하거나 교체하지 않는다.

일반 원정의 형식 2/규칙 21과 기존 콘텐츠 수치는 유지했다. 새 기능은 현재 비교 전투에서만 활성화한다. 이 전투를 플레이한 것이 트리 노드를 습득한 것으로 기록되지는 않는다.

- 화면 **64장 / 게임 Runtime errors 0**: 기존 저장/UI 회귀, 세 방식의 조립 전후·방출 후·720p·연습 종료/이어하기·잔광 유지. `Logs/signature-smoke-final.log`, 검증 사본 `Logs/BasicsV9Captures/smoke-result.txt`. 게임 시작 전 Unity SearchDatabase 내부 예외는 별도 Editor 문제다.
- 사람의 전투 재미 평가, 세 방식의 전체 전투 승률/소요 턴, Profiler, 새 Windows 실행 파일은 검증하지 않았다. 자동 좌표 사례가 재미 개선의 증거를 대신하지 않는다.

다음 제작의 기준은 이 전투에서 사용한 능력이 **카드 순서·위치·처치 우선순위를 실제로 바꿨는지**다. 그 결과를 확인한 뒤 시작 형태와 대형 나무를 연결한다. 미구현 노드를 사용 가능한 능력처럼 표시하는 방식으로 범위를 넓히지 않는다.
