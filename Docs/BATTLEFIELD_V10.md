# 전장·카드 UI 개편 v10 · 2026-09-10

> 캐릭터 선택의 확대·블러 연출은 이후 [v11 옆모습 눈 전환](CHARACTER_SELECTION_V11.md)으로 교체했다. 아래 캐릭터 항목은 v10 당시 구현 기록이며, 전장·카드·지형 규칙은 그대로 유효하다.

## 이번 변경

- 캐릭터 선택은 중앙 관문을 사이에 둔 이안·루나 원형 초상으로 바꿨다. 선택 초상은 약하게 강조하고, 마우스를 올린 초상은 8%가량 확대되면서 블러·저채도 상태에서 원본 색과 선명도로 전환한다. 클릭해야 실제 선택이 바뀌며 호버는 설명 미리보기만 바꾼다.
- 전투의 먹빛 좌표판을 화면 전체 배경 레이어로 확장했다. 실제 수학 좌표 범위 `x=0~10`, `y=-4~4`와 같은 축척은 유지하며 활성 필드는 1180×944 논리 픽셀이다. 플레이어·조립·적 의도·행동 UI는 가장자리의 반투명 패널로 겹친다.
- 손패는 화면 아래 중심을 기준으로 부채꼴로 겹친다. 호버 카드는 회전을 풀고 위로 올라오며, 별도 310×370 책장형 확대본에서 이름·역할·등급·문양·수식·짧은 동작·키워드를 읽는다.
- 카드의 보호막·집중·재생·잔불·약화·노출·고정·경쾌·회복·정화와 드로우를 키워드 칩으로 표시한다. 키워드에 마우스를 올리면 규칙 설명이 나타난다. 플레이어·적 상태와 전장 지형도 같은 설명 방식을 사용한다.
- 참고작의 특정 이미지·프레임·아이콘은 사용하지 않았다. [Library of Ruina 공식 Steam 페이지](https://store.steampowered.com/app/1256670/Library_Of_Ruina/)의 전투 책장이 정보를 층별로 나누는 방식만 참고하고, 기존 GRAPHACLYSM 문양·색·수식 표기를 유지했다.

## 지형 규칙

생성 전투는 일반·정예에 지형 2개, 보스에 3개를 둔다. 원정 시드와 생성 순서로 배치를 결정하므로 저장 명령을 재생하면 같은 지형이 돌아온다. 초기 플레이어·적 위치와 지형끼리는 겹치지 않으며, 시작 위치에서 최소 한 방향은 이동할 수 있다.

- `기록 기둥`: 반경 0.68. 플레이어 이동과 적의 자리 이동을 막는다. 작도선은 통과한다.
- `굴절 프리즘`: 반경 0.48. 이동을 막지 않는다. 현재 작도선이 하나 이상의 프리즘을 통과하면 그 방출에서 선에 맞은 각 적에게 피해 +2를 한 번 적용한다. 여러 프리즘을 지나도 중첩하지 않는다.

`BattleTerrainDefinition`은 Core의 불변 정의이고 `BattleDefinition`이 복사해 소유한다. `BattleSession`만 이동 차단과 프리즘 적중 보너스를 판정한다. 화면은 공개 상태를 읽어 기둥·프리즘과 활성화를 그릴 뿐 수치를 바꾸지 않는다.

던전 생성과 전투 규칙이 달라졌으므로 `RunSaveData.RulesVersion`은 9에서 10으로 올렸다. v9 원정 저장을 v10 규칙으로 조용히 재생하지 않는다. 설정 파일과 튜토리얼 확인 기록은 그대로 유지된다.

## 리소스와 수명

기존 이안 v2·루나 v6 원본을 덮어쓰지 않는다. `PortraitMedallion.shader`로 512×512 원형 선명본·블러본 네 장을 View `Awake`에서 한 번 만들고 `OnDestroy`에서 해제한다. 카드 키워드 이름·설명 배열은 카드 시각 캐시를 만들 때 한 번 구성한다. 전투 프레임마다 새 카드·지형 오브젝트를 만들지 않는다.
