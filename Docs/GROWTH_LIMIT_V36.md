# 성장점9점 한도와 트리 정리 · 규칙36

최대 누적 성장점을9점으로 정한다. 현재16노드 트리에서 기술/궁극기 각성을 같이 확보하면서 모든 강화는 가져갈 수 없는 초기 예산이다. 시작6점은 유지하고 방 보상으로 최대3점을 더 받는다. 기존 시작 경험 보조도 동일한9점 상한 안에서만 지급한다. 영구 저장이나 구매 내역을 변경하지 않는다.

한도는 사용하지 않은 포인트가 아니라 `투자한 점수+사용 가능한 점수`의 합이다. 개별 반환/전체 재배분은 실제 지출만 돌려주며 추가 지급 여유를 만들지 않는다. 한도에 도달한 방 보상은 성장점0으로 표시한다. 별도 재화로 바꾸지는 않는다. 점수 한도만 바꾸며 전투 효과/노드 비용/각성 배타/5층/유물·방 편성은 유지한다.

새 원정은 StyleTree 다음 GrowthLimit 명령으로 활성화한다. 규칙35까지의 원정은 기존 예산을 유지하고 이미 투자한 점수를 절삭하지 않는다. UI 레이아웃 정리는 기존16노드 원정에도 표시한다. 과거55/144노드의 배치와 경로는 유지한다.

## 배치

16노드 트리의 지그재그 배선을 직접 연결로 바꾼다. 뿌리에서 세 줄기로 올라가고 각 줄기에서 기술/궁극 강화로 갈라진다. 줄기 간격과 중앙 높이를 조정해 지나치게 가로로 늘어진 모양을 줄였다. 전체 보기에서도 일반 노드 이름을 표시하고, 보이는 이름을 클릭해 선택할 수 있다. 확대 시 기술 강화/궁극 강화/각성 종류를 구별하며 각성은 이중 마름모로 표시한다.

우측 패널은 투자/최대9/남은 점수, 앞으로 얻을 수 있는 점수 또는 한도 도달을 표시한다. 별도 화면이나 숨은 장착 슬롯은 추가하지 않는다.

## 구현

RunGrowthState의 HasPointLimit/MaximumPointBudget과 AddPoints가 단일 한도 검사 지점이다. int.MaxValue 지급도 한도 적용 후 처리한다. 계획용 사본은 부족한 경로 비용까지 계산하기 위한 비제한 시뮬레이션이며 실제 구매 예산을 바꾸지 않는다. 최종 계획 Remaining은 원본 포인트로 계산한다.

검증은 격리 Unity 프로젝트/합성 원정만 사용한다. 사용자 Editor/저장 보존. 전체5층의 재미/난이도 밸런스와 Profiler/새 실행 파일 빌드는 별도다.
