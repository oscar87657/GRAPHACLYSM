# 상태 연계 · 규칙30

## 적용 범위

새 원정만 MarketBalance 다음 StatusRules 명령으로 활성화한다. 이전21~29 원정은 원래 카드 정의와 고정 공격 예고를 재생한다. 기존 저장 삭제/자동 변환 없음. 변경을 체험하려면 새 원정을 시작한다.

105종 도안·색21/21/42/21·확률·가격 유지. 이전29 정의는 Version29/MarketCard, 현재 상태 연계 카드는 All/Current. 상태 ID는 재배치하지 않고 끝에 추가한다. 추진 슬롯은 호환용으로 남기되 새 규칙에서 집중으로 합산한다.

## 상태와 사용처

기존11종(보호막·집중·재생·잔불·약화·노출·고정·경쾌·가시·요새화·균열)에5종을 더해 활성16종이다. 파열 상태의 표시명만 균열로 바꾸고 카드 이름 파열은 유지한다.

| 상태 | 실제 규칙 |
| --- | --- |
| 수호 | 해로운 상태 적용 한 건을 막고1회 소모. 기존 상태 제거는 정화 담당. |
| 방패 관통 | 다음 본 방출 피해 일부가 보호막을 우회. 총 피해 증가 아님. 자가 적중의 새 부여 전에 기존 관통 소모. 기록/잔불/반격 제외. |
| 약해진 방벽 | 새 보호막 획득량을 수치만큼 차감, 최소0. 기존 보호막 유지. |
| 찢긴 상처 | 실제 적 이동에 피해. 플레이어 행동 단계 반복 견인에는 턴당1회, 적 행동 단계 자발적 이동에는 추가1회 가능. 보호막으로 막을 수 있음. 현재 실제 부여 카드는 적 대상. |
| 유도 | 다음 성공한 끌어당김 거리 증가. 루나 견인/카드 공통. 고정·지형·경계 유지. 이동 실패에는 소모하지 않음. |
| 경쾌 | 새 규칙 일반 이동1.8→2.7, 추가 이동 횟수 없음. 이동 취소 시 복구. 과거 비용 면제 유지. |
| 균열 | 본 방출 또는 새 규칙 직접 기술 적중 시 추가 피해 후 소모. 기록의 기존 소비도 유지. |

잔불은 적 행동 전에 보호막으로 막을 수 있는 피해다. 기존 잘못된 ‘보호막 무시’ 툴팁을 수정했다. 고정은 공격 정지가 아니다. 즉시 끌어당김은 지속 상태 아이콘을 만들지 않는다.

### 카드

- 견인: `frag.weave.6.*`4장, `frag.weave.13.*`4장, 고요1장. 총9장으로 이안/관측 루나도 사용한다.
- 유도: `frag.weave.3.*`4장과 비껴쓴 선. 상처: `frag.weave.2.*`, `frag.weave.10.*`8장.
- 관통은 균열 계통, 수호는 위성 계통/가시 성좌, 약해진 방벽은 제곱 잔향 계통에 배치한다.
- 새 수치형 효과도 회색/청록/보라/금색에 기존0.75/1/1.25/1.5 배율(올림)을 적용한다. 수호/경쾌/유도/견인은 이진·거리 효과로 증폭하지 않는다. 금색 수치형 상태는 보호막 외에3턴이다.
- 상태 부여를 모두 마친 뒤 견인을 한 번 처리한다. 여러 견인 카드의 거리는 합하지 않고 최대값만 사용한다. 유도·상처는 같은 방출에서 연계 가능하다.
- 본 방출의 직접 피해·장치·기록을 처리한 뒤 카드 견인을 적용한다. 도안 처리 도중 위치 변경으로 나머지 적중이 달라지지 않게 한다.
- 상처로 마지막 적을 처치하는 루나 견인도 공통 승리/보상 흐름으로 보낸다.

### 적

선형 포수는 견인 후 발사점과 실제 사선을 새 적 위치로 옮기고 공개했던 방향은 유지한다. 플레이어의 새 위치를 재조준하지 않는다. 고리 감시자의 고리는 몸과 함께 이동한다. 지면 지정 공격인 십자/쌍점 조준은 그대로 남는다.

선형 포수 체력 피격은 약해진 방벽3/2턴, 십자 포수는2/3턴, 쌍점 포격은 잔불2/3턴. 일반 공격 약화·축적 맹공 잔불은 유지한다. 고리 감시자는 턴 시작 보호막3, 연결 수호자는 홀수 턴 수호1. 제거/관통과 유도 이동에 각기 다른 사용처를 준다.

## UI·소유권

버프 청록/둥근 테두리, 디버프 붉은색/각진 테두리, 코드 도형 아이콘·짧은 이름·수치/기간·호버 설명을 함께 표시한다. 색만으로 구분하지 않는다. 별도 비트맵/프레임별 객체 생성 없음.

전투원 int 상태/기간 배열12→17(추가40바이트 원소 데이터), 규칙bool과 적 상처 발동 턴int. 현재 카드105개 불변 정의와 이전29 visual105개는 앱/View 수명. 원정 활성화 때 덱/보상 참조 배열 복사. 프레임별 임시 상태 컬렉션 없음.
