## 경로와 전투 변화

`GrowthTreePaths`는 기존에 독립적으로 살 수 있던 형태들에 실제 진입 조건을 추가한다. 진입 후보 중 하나를 습득하면 다음 능력으로 넘어갈 수 있다. 원본의 형태 소유·특성 수·국소 배타 조건도 함께 검사한다. 모든 노드는 맨 아래 출발점과 연결된다.

| 전투 판단 | 이어지는 예시 |
| --- | --- |
| 몸과 식의 위치 조정 | 교차점 채집 → 원점 못 → 궤도의 조율자 → 월륜 회전 |
| 같은 기술로 가는 다른 진입 | 교차점 채집 → 마지막 주석 → 순서 역전 → 월륜 회전 |
| 식을 나누고 턴을 바꾸기 | 마지막 주석 → 준비 장막 → 예비 방출·해체 잔문 → 분할 방출 → 시계 없는 밤 |
| 공격 조건을 궁극기로 확장 | 교차점 채집 → 파쇄의 낙인 → 성좌 붕괴 |
| 방어를 전장 장치로 확장 | 자기 서명 → 반사 장갑 → 검은 성벽 → 투명한 성역 → 흑유리화 |

실제 조건은 상세창의 `필수`, `선택 N개`, `진입 경로 중 하나`에서 확인한다. 분할 방출은 후보 다섯 중 둘을 요구하며 시계 없는 밤은 천구의 자전을 통해서도 진입한다.

## 배치와 조작

`GrowthTreeLayout`은 Section을 읽지 않는다. 실제 의존성과 전투 변화의 크기로 높이를 정하고, 위치·방어·재현·공격 조건처럼 관련된 효과와 부모 좌표로 좌우 배치를 정한다. 과밀한 높이는 여러 단으로 나눈다. 좌우 대칭 틀, 분류별 가짜 허브, 따로 떨어진 혼합 노드 모음은 없다.

- 첫 화면은 아래 출발점이다. 모든 선행 노드는 후속 노드보다 아래에 있다.
- 드래그: 좌우·상하 이동. 휠: 세로 이동. Shift+휠: 가로 이동. Ctrl+휠 및 상단 +/-: 확대·축소.
- 전체 보기: 전체 트리에 맞춤. 시작점: 아래 뿌리로 복귀.
- 노드 클릭: 선택과 진입 경로 강조. 오른쪽 상세창: 효과·비용·선행 조건·습득/장착.
- 전체 화면에서는 각 노드의 실제 진입선 하나로 연결된 기본 경로를 보여 준다. 추가 조건이 있는 노드에는 + 표시가 있고, 선택하면 모든 필수·선택·대체 경로가 함께 펼쳐진다. 습득 판정은 항상 전체 조건을 검사한다.
- 탐색이나 드래그로 성장점을 소비하지 않는다. 실제 변경은 상세창에서 확정한다.

조사 참고는 [Grim Dawn 공식 Devotion 안내](https://www.grimdawn.com/guide/character/devotion/)다. 출발점에서 선택을 이어 더 강한 효과로 진입하는 원리를 참고했다. 아래→위 배치와 구체적인 능력 간 진입 경로는 GRAPHACLYSM을 위해 결정한 설계다. 참고작의 자산은 포함하지 않았다.

## 저장과 구현 범위

해금 조건이 바뀌어 저장 규칙은 **17**, 파일 형식은 **2**다. 규칙 16 원정은 새 조건으로 재생하지 않으며 사용자 저장 파일은 삭제하거나 테스트에 사용하지 않았다. 새 원정에서 확인한다. 시작 6점·최종 보스 전 기본 총 35점은 유지한다. 원본 기획의 빌드 예제 비용에는 새 진입 경로가 포함되지 않아 그대로 적용하지 않는다.

이번 수정은 트리 연결·해금·배치·탐색이다. v16의 240개 카탈로그와 장착 기반을 사용하며, 아직 연결하지 않은 개별 전투 효과는 상세창에 `전투 효과 연결 예정`으로 표시한다.

## 검증

Unity EditMode **160/160** 통과. 양쪽 캐릭터의 유일한 시작점, 전체 144개 연결성, 순환·타 캐릭터 의존성 부재, 대체 진입 경로, 고급 노드 직접 구매 거부와 재배분을 검사한다. 저장 재생 회귀도 새 출발점을 포함한다.

화면 fixture **38장**, 게임 Runtime errors **0**. 양쪽 캐릭터의 모든 연결선이 아래→위인지와 노드 간 겹침을 검사한다. 휠·Ctrl+휠·드래그 입력에 따른 화면 변화와 성장점 미소비, 720p 화면도 검사한다. 결과는 `Logs/editmode-ascending-v17.xml`, `Logs/ascending-v17-smoke.log`, 검증 사본 `Logs/BasicsV9Captures`에 남긴다. 전체 전투 효과 구현이나 전체 런 밸런스 검증을 뜻하지 않는다.
