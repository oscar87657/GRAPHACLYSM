# 방향 돌진과 루나의 두 번째 기술 · 규칙 23

이번 변경은 집행 조작과 루나의 추가 기술에 한정한다. 대형 성좌·카드·원정 보상·영구 성장 수치는 변경하지 않는다.

## 조작과 실제 규칙

- 집행형 이안: K 또는 집행 버튼 → 전장 방향 클릭. 클릭 거리와 무관하게 3.6 이동한다. 경로의 적은 각각 피해 10, 살아남은 적에게 파열 6. 파열 집행 특성이 있으면 남은 파열을 먼저 소비하는 규칙과 처치 시 즉시 재사용을 유지한다.
- 적을 통과하며 겹쳐 착지할 수 있다. 전장 경계·기록 기둥·활성 봉인은 통과하지 않는다. 직선 경로에서 최초 장애물 앞에 멈추며 옆으로 착지를 보정하지 않는다. 경로 밖 지정 적에 대한 별도 보장 타격은 없다. 빈 방향으로 이동만 하는 것도 가능하다.
- 조율형 루나: K는 기존 도안 조율, J는 새 성운 견인이다. 몸에서 3 이내 지점을 고르면 반경 2.2 안의 적을 중심으로 최대 1.5 끌어당긴다. 적끼리 겹칠 수 있고 고정 상태·지형·봉인을 존중한다. 직접 피해·드로우·플레이어 이동 소비 없음.
- 두 루나 기술을 합쳐 한 턴에 한 번 사용한다. 다음 플레이어 턴에 다시 선택한다. 견인은 조립 전에도 가능하고, 실제로 움직일 적이 없으면 기회를 소비하지 않는다. 별도 다중 턴 대기시간은 추가하지 않았다.
- 버튼 재클릭·우클릭으로 조준 취소. 집행은 경로/착지/예상 체력·보호막 피해, 견인은 범위/각 적 도착점/이동 후 도안 접촉을 표시한다. 금색 견인 표시는 도안 접촉이며 확정 피해량을 뜻하지 않는다.
- 적을 옮겨도 이미 예고된 일반 공격 중심과 포수의 사선 시작/끝점은 유지한다. 다음 조준 갱신부터 새 좌표를 사용한다. 공급선·수호 연결은 이동한 적의 실제 좌표를 사용한다.

## 저장과 소유권

형식 2/규칙 23. 명령 끝에 ExecutionDash/LunaPull 추가. 좌표는 0.01 단위의 기존 20비트 방식이다. 기존 21/22 저장을 읽으며 과거 UseCombatSkill은 당시 적 앞 착지와 보장 타격으로 재생한다. 이어하기 후 새 조작만 방향 명령을 기록하므로 과거 진행이 재해석되지 않는다. 연습은 일반 저장·보상과 분리한다.

BattleApproaches가 돌진/견인의 경로와 연속 원 충돌을 계산하고 BattleSession 공통 처리기가 집행 피해를 적용한다. EnemyState가 포수의 고정 사선 시작점을 보관한다. View는 명령과 실제 좌표를 표시하며 체력·위치를 직접 수정하지 않는다.

GraphaclysmSpatialSkillView의 견인 연출은 View 소유 Vector2 배열 두 개를 첫 사용 또는 적 수 변경 때 현재 적 수만큼 할당하고 재사용한다. 예측 경로는 값 타입과 기존 배열을 사용하며 임시 컬렉션을 만들지 않는다. 설명은 포인터/명령 변경에 갱신한다. Editor 전용 포인터 fixture는 플레이어 빌드에서 제외된다.
