# 잔광 개편안 — 다음 원정의 출발을 준비한다

## 먼저 구분할 것

후속 규칙39에서 사용자 요청에 따라 방향을 변경했다. 기존 스펙업 항목은 삭제하지 않고 보존하며, 유물 지참과 분대 개방 등을 추가했다. 현재 구현은 [규칙39 기록](PREPARATION_V39.md)을 따른다. 아래는 당시 미구현 제안의 보관본이다.

이번에 반영한 것은 보상 화면의 한 줄 배치·가로 탐색·수령한 카드 제거와, 새 원정의 무료 시작 유물 삭제다. 아래 잔광 개편은 **제안이며 아직 구매 기능에 적용하지 않았다.** 기존 잔광, 투자 단계, 이미 진행 중인 원정은 유지한다.

사용자가 정한 방향은 ‘시작 유물은 잔광 투자 항목 중 하나’라는 점이다. 영구 해금인지 원정마다 결제하는지는 아직 확정하지 않았으며, 이 안에서는 한 번 구매하는 영구 해금을 추천한다.

## 목표

잔광 화면을 열었을 때 “체력을 더 올려야 게임이 되겠네”보다 “다음에는 이 유물과 덱으로 시작해 보자”가 먼저 떠오르게 한다. 원정의 강력한 조합은 여전히 전투 보상과 상점, 성장점 9점으로 완성한다. 잔광이 원정 성장을 대신하지 않게 한다.

## 추천하는 여섯 항목

비용은 현재 보유 재화 분포와 플레이 시간 자료가 없는 상태의 가안이다. 원정 1~2회 정도로 첫 취향 선택을 열 수 있는지를 보고 조정한다.

| 항목 | 제안 효과 | 비용 가안 | 제한 |
| --- | --- | --- | --- |
| 유물 지참 | 출발 때 유물 후보 3개 중 1개 선택 | 4잔광, 한 번 구매 | 시작 유물은 항상 1개. 두 번째 슬롯은 만들지 않음 |
| 출발 계획 | 전투방식마다 기본 덱 외 대체 덱 1개 해금 | 4잔광, 한 번 구매 | 같은 카드 수·색 예산. 상위 덱이 아니라 역할 차이 |
| 여행 경비 | 시작 은화 +6 / +12 | 3잔광 → 4잔광 | 최대 2단계. 원정 도중 수입 배율은 없음 |
| 예비 열쇠 | 시작 열쇠 +1 | 3잔광, 한 번 구매 | 현재 기본 1개와 합쳐 2개. 상자 확률은 그대로 |
| 튼튼한 여행 가방 | 최대 체력 +2 / +4 / +6 | 기존 2 → 3 → 4잔광 | 기존 단계 유지 |
| 초행자의 부적 | 전투 시작 보호막 +2 / +4 | 기존 3 → 4잔광 | 기존 단계 유지 |

‘유물 지참’을 사려고 체력이나 다른 노드를 먼저 구매하게 하지 않는다. 여섯 항목은 각각 독립적으로 접근한다. 출발 준비 화면에 해금하지 않은 항목은 잠금 표시와 효과만 보여 주고, 부족한 잔광 때문에 출발을 막지 않는다.

## 시작 유물의 구체적인 사용 흐름

잔광 화면에서 **유물 지참 해금 → 캐릭터·전투방식 선택 → 시작 유물 1개 선택 → 지도**로 이어진다. 해금하지 않았다면 유물 선택 없이 지도에서 시작한다.

첫 구현은 기존 유물 3개로 제한한다. 은제 필사침은 첫 손패를, 달의 태엽은 궁극기 준비를, 상아 봉인은 첫 적 행동의 방어를 돕는다. 이미 구현된 효과라 새 유물의 성능까지 동시에 조정할 필요가 없다. 더 강한 유물부터 무작위로 지급하거나 전체100종을 시작 후보로 풀지는 않는다.

처음에는 고정 후보를 사용한다. 무작위 후보 확장은 이후 검토하되 출발을 취소하거나 저장을 다시 불러도 후보가 바뀌지 않아야 한다. 선택한 유물은 이번 원정 보유 목록에 들어가고 일반 보상·상점의 중복 제외 규칙을 그대로 따른다. 영구 해금은 ‘유물 소유권’이 아니라 ‘매 원정 하나를 골라 지참할 권리’다.

출발 계획은 이안 집행/기록, 루나 조율/관측의 기존 기본 덱을 유지한 채 대체 구성을 추가하는 별도 작업이다. 카드 구성은 실제 도입전에서 검증한 뒤 확정한다. 이 문서만으로 새 덱이 구현되었다고 보지 않는다.

## 기존 여섯 항목은 어떻게 옮길까

현재 코드는 최대 체력, 승리 회복, 시작 공명, 성장 경험, 시작 보호막, 종료 잔광 보너스의 여섯 항목이다. 이 안을 채택한다면 체력·보호막은 유지하고 나머지 네 항목은 환급 후 제거하는 것을 추천한다.

- 승리 회복은 원정 내 유물의 선택 가치로 돌린다. 영구 회복을 쌓아 모든 원정이 같은 회복 구조로 시작하는 것을 줄인다.
- 시작 공명은 ‘달의 태엽’을 고를 이유로 돌린다. 계정 보너스와 유물 보너스를 모두 쌓아 출발 궁극기가 정답이 되는 것을 피한다.
- 성장 경험 선지급은 제거한다. 누구나 시작3점·진행6점이라는 규칙을 쉽게 이해하게 한다.
- 종료 잔광 보너스는 제거한다. 다른 보상을 사기 전에 재화 수입부터 올려야 한다는 압박을 줄인다.

이는 이번 수정의 확정 사항이 아니다. 실제 교체를 승인한 뒤 진행한다. 먼저 하나만 도입한다면 **유물 지참을 추가하고 기존 항목은 당분간 유지**하는 작은 단계도 가능하다. 다만 시작 공명과 성장 경험의 중복은 추후 검토 목록에 남긴다.

## 정확한 환급과 저장

기존 구매 규칙은 단계마다 `기본 비용 + 이미 구매한 단계 수`다. 제거 항목의 실제 누적 구매액을 돌려준다.

| 제거 제안 항목 | 1단계 환급 | 2단계 환급 | 3단계 환급 |
| --- | ---: | ---: | ---: |
| 남겨 둔 붕대 | 2 | 5 | 9 |
| 울리는 기억 | 3 | 7 | — |
| 낡은 지도 주석 | 2 | 5 | 9 |
| 되비치는 별빛 | 4 | 9 | 15 |

환급액으로 새 항목을 자동 구매하지 않는다. 환급 내역을 보여 주고 사용자가 직접 고른다. 영구 기록은 현재6칸의 순번 기반 배열에서 안정 ID 기반 기록으로 옮기고, 마이그레이션 표식을 저장해 두 번 환급하지 않게 한다. 새 기록 파일 저장에 성공한 뒤에만 실제 계정 상태를 교체한다. 손상 파일은 읽기 전용으로 두고 원본을 덮어쓰지 않는다.

진행 중인 원정에는 당시 출발 보너스와 이미 선택한 유물을 유지한다. 새 계정 상태는 다음 새 원정부터 적용한다. 유물 지참 여부와 실제 선택 ID도 원정 시작 기록에 남겨 이후 잔광 재배분이나 해금 변화로 이어하기 결과가 달라지지 않게 한다.

## 잔광 지급도 함께 점검한다

현재 종료 보상은 패배 시 `2 + 도달 층 - 1`, 완주 시8에 영구 보너스를 더한다. 이 구조는 실제로 얼마나 전투했는지를 따로 확인하지 않는다. 지급 변경은 기존 단계 환급과 함께 별도로 검증해야 한다.

추천 가안은 실제 승리1회 이상이면 기본1, 층 보스마다1, 완주 추가2다. 5층 완주 합계는8을 유지하며 전투 없이 원정을 종료하면0이다. 패배해도 전투한 기록은 남지만, 시작과 종료만 반복해서 재화를 얻지는 못한다. 첫 유물 해금까지 시간이 너무 길다면 필요한 비용을 낮추고, 재화 획득량 증가 노드를 다시 추가하지 않는다.

현재 중복 지급 방지는 최근64개 시드 목록이다. 새 체계에서는 원정 고유 ID와 종료 정산 표식을 사용하고, 저장·재접속·같은 결과 창 반복 진입에서 한 번만 지급되는지 확인한다. 이 지급·정산 변경 역시 아직 적용하지 않았다.

## 구현 순서와 완료 조건

1. 유물 지참 하나부터 구현한다. 잠금 상태에서 무료 유물이 나오지 않고, 해금 후 매 원정 하나만 선택되는지 검증한다.
2. 영구 기록의 새 저장 구조와 환급 미리보기를 만든다. 모든 기존 단계 조합과 저장 실패·재시도에서 재화 총량이 보존되어야 한다.
3. 나머지 준비 항목과 새 종료 정산을 연결한다. 보유 잔광·효과가 이어하기 원정을 소급 변경하지 않아야 한다.
4. 대체 시작 덱은 실제 도입전으로 비교한다. 기본 덱을 버릴 이유만 생겼다면 수치나 구성을 다시 조정한다.

검증 때는 ‘첫 유물 해금까지 몇 원정이 걸렸는가’, ‘같은 시작 유물만 골랐는가’, ‘영구 성장 없이도 1층의 성공 이유를 이해할 수 있었는가’를 기록한다. 초반에는 소수의 플레이로 문제를 찾되 전체 플레이어의 선호로 일반화하지 않는다.
