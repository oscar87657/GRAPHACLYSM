# 네 스타일의 기술·궁극기 성좌 · 규칙35

사용자 정정: 통합스킬트리_v2 ZIP은 참고로만 사용한다. 궁극기는 캐릭터당 하나로 합치지 않고, 집행/기록/조율/관측의 기존 네 궁극기를 각각 유지한다.

## 이번 적용 범위

새 원정은 스타일당16노드(무료 뿌리1+기존 전용 강화9+새 각성6)를 사용한다. 55노드 중 반복적인 조건부 상태 연계45개는 새 카탈로그에서 제외했다. 이전55노드 카탈로그/실행/저장 재생은 유지한다. ZIP의26노드/캐릭터 공통 궁극기/3층9점 규칙을 그대로 구현한 것이 아니다.

하나의 뿌리에서 세 줄기로 올라간다. 각 줄기는 기술 입문→기술 특성→기술 각성, 입문→궁극기 강화→궁극기 각성으로 갈라진다. 기본 궁극기는 선행을 사지 않아도 사용할 수 있다. 기술 각성3개 중1개, 궁극기 각성3개 중1개를 동시 선택한다. 각성이 아닌 강화는 병행 습득 가능하다. 반환은 말단부터, 전체 재배분도 지원한다. 기존 경로 계획은 읽기/비교용이며 자동 거래/각성 자동 교체는 이번에 추가하지 않았다.

## 각성

| 스타일 | 기술 각성 세 방향 | 궁극기 각성 세 방향 |
|---|---|---|
| 균열 집행 | 공격 후 출발점 귀환 / 세 평행 공격선 / 돌진 거리 추가 확장 | 다음 방출의 도안 잔상 / 가장 체력이 많은 파열 대상 추가 타격 / 파열 적중 수에 따른 방호 |
| 기록 포격 | 반전 도안 저장 / 몸 위치에서 재현 / 재현 접촉 반경 확장 | 반전 궁극 도안 / 재현마다 오른쪽으로 이동 / 단독 대상 재현 집중 |
| 궤도 조율 | 견인 후 조율 / ±150도 회전 / 같은 턴 두 번 조율 | 두 번째 식에 첫 도안 겹치기 / 두 번째 작도 적중 후 견인 / 두 번째 방출 공명 회수 |
| 쌍성 관측 | 위성 원점과 몸 원점의 추가 공격 / 위성 설치 위치로 전이 / 몸·위성 연결선 공격 | 성역 접촉 범위 확장 / 몸 이동을 따라가는 성역 / 위성이 있으면 원격 보호 |

범위 확장과 단일 대상 집중 등 일부 각성은 입력 자체보다 판정/출력 변화다. 모든 각성이 새로운 조작 체계를 추가한다는 뜻은 아니다. 모든 효과는 StyleTreeCatalog에 실제 기능과 제한을 함께 기재한다.

## 실행/예측

새 공격은 본 방출 전에 피해 배열을 고정한다. 도안 잔상과 몸 원점 추가 도안은 실제 EquationState 복사본을 미리보기/실행에 함께 사용하며, 카드 효과·공명·기록을 복제하지 않는다. 잔상은 한 번만 소비한다. 조율의 추가 조립을 포기하면 전용 잔상도 폐기한다. 일반 기록과 궁극기 기록의 저장소는 분리한다.

삼중 돌진은 실제3개 평행선 접촉을 판정하고 적마다 한 번만 피해를 준다. 귀환은 기존 공격 경로를 유지하고 최종 몸 위치만 출발점으로 바꾼다. 과거 루나 왕복 기술의 이동 상태는 바꾸지 않는다. 위성 귀환은 설치 사거리/합법 좌표 검사 후 전이하며 일반 이동을 복원하지 않는다.

추가 조석은 본 작도 적중 후 실제 위치를 움직인다. 그 이동과 상처 피해까지 통합한 방출 전 예측은 아직 별도 검증 대상이다. 기존 유도/카드 견인과 결합한 전체 연쇄를 전부 검증했다고 주장하지 않는다.

## 저장/메모리/후속

StyleTree 명령을 규칙35에 추가했다. ApproachTree 직후, 새 원정에서만 활성화한다. 규칙34 이하는 이전 카탈로그를 재생하며 기존 원정 자동 이관은 없다. 원본 사용자 저장 수정 없음.

전투 소유 도안 버퍼2개와 적 수만큼 피해 배열1개를 새 트리 전투 시작에 할당한다. bool 규칙 배열61개. 프레임마다 컬렉션/LINQ를 새로 만들지 않는다. 기존35점/방 보상/5층 및 영구 성장 경제는 이번 범위에서 유지한다. 줄어든 트리에 맞춘 포인트 지급 속도/잔여점 활용은 후속 밸런스 항목이다.

방 반복, 유물의 조건부 효과 편중은 후속 과제이며 이번에 수정하지 않았다. 전체 원정 수동 밸런스, Profiler, 새 실행 파일 빌드는 별도다.
