# 캐릭터 선택 옆모습 연출 v11 · 2026-09-10

## 동작

중앙 관문과 두 원형 배치는 유지한다. 이안은 화면 왼쪽을, 루나는 화면 오른쪽을 바라보는 새 옆모습이다. 기본 상태는 두 인물 모두 눈을 감고, 포인터가 올라간 인물만 동일한 위치·크기에서 눈을 뜬다. 확대·블러·저채도·선택 테두리 강조는 없다. 호버는 하단 정보를 미리 보고, 클릭은 실제 선택을 바꾼다.

선택용 표시본은 `Awake`에서 512×512로 한 번 굽고 닫힘/열림 alpha만 교차한다. `연출 줄이기`에서는 즉시 바뀌고, 기본 설정에서는 짧게 교차한다. 전투·던전 규칙은 바뀌지 않아 저장 `RulesVersion`은 10을 유지한다.

## 자산

- `luna-profile-eyes-closed-v11.png`, `luna-profile-eyes-open-v11.png`
- 네 장 모두 1254×1254 RGBA, 모서리 alpha 0이다. 기존 전신 초상은 지도·전투 화면용으로 보존한다.

기본 생성은 내장 `imagegen`의 `stylized-concept`로 수행했다. 이안 v2와 루나 v6는 각각 정체성·의상·팔레트 참고로만 사용했다. 최종 프롬프트 세트는 다음과 같다.

1. 이안 기본: “기존 정체성과 검은 장발·은빛 나비·남청색 고딕 의상을 유지한 새 머리~상반신 구도. 자연스러운 왼쪽 옆모습, 눈을 편안하게 감음, 소품 없음, 실제 투명 배경.”
2. 이안 호버: “이안 기본본의 구도·얼굴·머리·의상·조명·투명 배경을 고정하고 보이는 눈만 차분한 청보라색으로 자연스럽게 뜸.”
3. 루나 기본: “기존 정체성과 은백색 장발·검은 리본·초승달·상아 레이스·밤보라 고딕 의상을 유지한 새 머리~상반신 구도. 자연스러운 오른쪽 옆모습, 눈을 편안하게 감음, 소품 없음, 실제 투명 배경.”
4. 루나 호버: “루나 기본본의 구도·얼굴·머리·의상·조명·투명 배경을 고정하고 보이는 눈만 차분한 청록색으로 자연스럽게 뜸.”
5. 배경 추출: “체크무늬를 실제 alpha 0으로 제거하고 인물과 가는 머리카락 경계는 유지.” 루나 닫힘본은 생성기가 체크무늬를 반복해 합성했으므로 같은 구도의 정상 열린본 alpha만 기계적으로 결합했으며 RGB 인물 픽셀은 바꾸지 않았다.
