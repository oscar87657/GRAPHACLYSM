# 원정 준비·선택 전리품 · 규칙37

## 적용 범위

새 집행/기록/조율/관측 원정에 `ExpeditionSupplies`를 GrowthLimit 다음으로 기록한다. 이전36 이하 저장은 시작6점·기존 보상 흐름을 보존한다. 기존 스킬 노드·전투 판정·적 수치는 바꾸지 않는다. 새 출발/재시작이 필요하다.

## 성장 3 + 6

- 시작3점, 원정 전체 최대9점. 반환·재배분은 투자분만 반환하며 지급 여유를 되살리지 않는다.
- 비보스 전투(일반/정예) 승리마다 성장 경험1. 경험5/10에서 각각1점, 이 경로 최대2점.
- 1~4층 보스 승리마다1점. 최종 보스는 성장점 없음. 총6점을 진행 중 확보한다.
- 비전투 방 완료/그냥 지나가기는 성장점을 주지 않는다. 성장점은 전리품 슬롯이 아니라 승리 성장으로 자동 반영된다.
- 기존 성장 이벤트는 체력 최소6을 지불하고1점. 상점 성장점은24은화. 이들은 총9점 한도 내에서 점수를 일찍 확보하는 선택이며 별도 추가 한도가 아니다. 최대치에서는 구매/체력 지불을 막는다.
- 잔광 ‘낡은 지도 주석’의 기존 단계·투자 비용은 보존한다. 새 원정에서는 단계당 성장 경험1을 미리 채운다(최대3). 초기 성장점은 여전히3이다. 이전 원정 스냅샷의 출발점 효과는 유지한다.

## 무료 출발 준비

첫 방 전에 은제 필사침(시작 손패), 달의 태엽(시작 공명), 상아 봉인(시작 보호막) 중 유물 하나를 선택한다. 유물 없이 출발도 가능하며 시작 열쇠는1개다. 선택 전에는 지도 진입을 막는다. 실제 기존 유물 정의를 사용하므로 이후 보상/상점에서 중복되지 않는다.

이번에는 잔광으로 유물 선택권을 잠그지 않는다. 종료 잔광 보너스의 폐지/환급, 영구 유물 해금, 새로운 잔광 소비처는 후속 개편 범위다. 기존 계정 재화·등급 파일은 수정하거나 초기화하지 않는다.

## 선택 전리품

승리 후 최대6장의 보상 카드를 제시한다. 은화·연구권도 받기 전에는 보유량이 늘지 않는다. ‘받기’ 버튼은 해당 카드에만 적용된다. 카드/유물 선택권은 기존3지선다로 들어갔다가 전리품 화면으로 돌아온다. 선택권을 넘기면 그 슬롯만 끝나고 다른 보상은 남는다. 남은 보상을 두고 가려면 화면에서 한 번 더 확인한다.

| 보상 | 새 원정 지급 규칙 |
| --- | --- |
| 은화 | 기존10 + 층 증가분 + 0~3, 정예+6/보스+12; 수령 시 지급 |
| 연구권 | 승리마다1장, 수령 시 지급 |
| 카드 선택권 | 승리마다1회, 원하면3장 중 하나 선택 |
| 유물 선택권 | 정예/보스, 일반전25% (미보유 유물 필요) |
| 상자 열쇠 | 보스 확정1개, 그 외25% |
| 잠긴 유물 상자 | 도입전 이후20%, 유물 수장고에서도 만날 수 있음 |

열쇠와 상자 추첨은 보상 생성에서 한 번만 수행한다. 최종 보스도 전리품을 정리한 뒤 원정 완료·잔광 지급으로 진행한다. 회복 유물의 승리 회복이나 보스 층 전이 회복은 전투 효과로 유지한다. 방 선택으로 명시적으로 얻는 은화/연구권은 해당 선택 때 받는다.

## 상자

- 열쇠1개 사용: 확정 개방. 성공 후 미보유 유물 중 하나 선택.
- 직접 열기: 성공률50%, 실패하면 상자 소실. 열쇠는 소모하지 않는다.
- 시도는 상자당 한 번. 결과는 시드에서 미리 고정하고 재생 명령으로 보존하므로 저장 후 재접속으로 다시 뽑지 못한다.
- 열쇠 없음/잘못된 슬롯/이미 해결한 상자/유물16개 한도에서는 무효 소비를 거부한다.
- 상자를 그대로 두고 떠날 수 있다. 유물 수장고에는 상자 대신15% 회복 선택도 남긴다.

## 소유권·저장·할당

`RunGameSession`이 최대6개의 LootOffer 참조 배열과 보상별 해결 여부, 열쇠, 성장 경험, 상자 결과, 하위 선택 화면의 복귀 상태를 소유한다. 보상 객체와 표시 문자열은 보상 생성/명령 시에만 만든다. 시작 유물 ID 배열3개는 출발 순간만 생성한다. 성장 이벤트를 바꾼 RoomStory/최대3개 선택 배열은 방 진입 시에만 생성하며 프레임별로 복제하지 않는다. Core와 전투 충돌 경로에는 새 할당이 없다.

Presentation은 수령 버튼·확인 상태만 소유하며 직접 보유량을 수정하지 않는다. 전투 방출 애니메이션의 참조가 유지되도록 승리 직후에는 CurrentBattle을 제거하지 않고 보상 정리 때 해제한다. 기획 경로 계산용 성장 복사본은 초기3점을 보존하되 비용 계산을 위해 지급 상한은 적용하지 않는다.

`ExpeditionSupplies/ClaimLoot/OpenLootChest/LeaveLoot`는 안정 명령 enum 끝에 추가한다. 규칙37 이전 헤더는 새 명령을 거부한다. 예전 검사와 전체 화면 fixture의 과거 전투 가정은 `TryStartRun(approach, false)`로36 규칙을 명시하며, 새 규칙은 별도 회귀와 집중 화면 검사로 검증한다.
