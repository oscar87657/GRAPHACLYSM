# 전투 정보·성좌 성장 v14

2026-09-10. 카드 보상 화면의 겹치는 텍스트, 끊기는 키워드 확인, 상태 수치·지속시간의 낮은 가시성과 목록형 성장 화면을 함께 개편했다.

## 카드와 상태 정보

대형 파편 카드는 제목, 역할·등급, 문양, 수식, 설명, 키워드, 위력 영역을 서로 겹치지 않는 고정 세로 구획으로 나눈다. 일반 카드도 대형 상세본에 키워드 칩을 표시한다. 손패 원본, 확대 카드, 키워드 칩, 이동 통로, 설명 패널을 하나의 hover 영역으로 취급하므로 포인터를 설명까지 옮겨도 카드와 툴팁이 유지된다.

전장의 버프·디버프 칩은 축약 이름만 표시하지 않는다. 각 칩에 `현재 수치 · 남은 적 행동 T`를 직접 표시하고, hover 설명에도 정확한 현재 수치와 남은 행동 횟수를 함께 쓴다. 공간보다 상태가 많으면 마지막 `+N` 칩에서 적용 중인 모든 상태를 줄 단위로 확인한다.

## 성좌형 스킬트리

기존 2열×3행 카드 목록은 중심 핵에서 이동 기술과 궁극기로 갈라지는 12노드 성좌로 교체한다. 기술 형태와 궁극기 형태를 먼저 하나 선택하고, 선택한 원에서 다시 두 하위 노드 중 하나를 고른다. 선행 노드, 레벨, 성장점, 반대 갈래 잠금 상태를 선 밝기와 노드 색, 하단 상세 패널에 함께 표시한다.

- 이동 기술: 삼중 광역 또는 처치 즉시 초기화 직선을 선택한다.
- 광역 하위: 피해를 조정한 오중 궤적 또는 캐릭터별 방어 모듈.
- 처형 하위: 처치 공명 +1 또는 파열/회복·추진 공격 모듈.
- 궁극기: 캐릭터별 방어형/공격형 변주를 선택한다.
- 궁극기 하위: 다중 적중 공명 환급, 추가 피해·범위·고정·회복 중 선택한 갈래에 맞는 변형.

선택은 그 원정에서 되돌릴 수 없고 새 원정에서 초기화된다. 영구 기록은 기존처럼 별도 저장한다.

## 저장과 검증

노드 인덱스와 전투 효과가 확장되어 원정 저장은 형식 2·규칙 14다. v13 이하 원정 저장은 새 규칙으로 재생하지 않으며 설정과 영구 기록은 유지한다.

Unity EditMode **150/150**을 통과했다. 선행·배타 분기, 저장 재생, 오중 궤적, 처치 공명, 궁극기 추가 피해와 공명 환급을 포함한다. Full HD/720p 화면 fixture는 **32장, 게임 Runtime errors 0**이며 성장 트리 선택 전후, 수정된 카드 보상, 확대 카드와 수치 포함 키워드 설명을 캡처했다. 로그는 `Logs/editmode-ui-tree-v14.xml`, `Logs/ui-tree-v14-smoke.log`, 캡처는 검증 사본의 `Logs/BasicsV9Captures`에 있다.

배치 시작 중 Unity SearchDatabase 내부 예외 한 건은 게임 진입 전 Editor 서비스에서 발생했다. Windows 빌드 수동 플레이, 전체 3층 밸런스와 Profiler는 이번 검증 범위가 아니다.
