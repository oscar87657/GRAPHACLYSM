# 성장 가독성·방 선택 v19

2026-09-12. 이번 변경은 기존 단일 상승 트리를 유지하면서 설명, 투자 단계, 방 선택의 차이와 피격 정보를 보완한다.

## 성장 화면

- 노드를 클릭하면 오른쪽 설명이 고정된다. 습득/장착은 별도 버튼으로 확정한다. 마우스를 옮겨도 선택은 바뀌지 않으며 밑줄 용어만 호버 설명을 유지한다.
- 주요 능력은 행동→결과 중심으로 다시 쓰고, 나머지는 원본 첫 문장을 짧게 정리했다. 240개 표시 요약은 모두 200자 이하다. writing-studio의 구체적 행동·결과 중심 원칙을 적용했고 원본 JSON과 생성 카탈로그는 보존했다.
- 선행 깊이로 5단계를 나누고 총 투자 0/5/10/16/22점을 요구한다. 선행·국소 배타·장착 조건도 계속 검사한다. 보유 점수만 늘려 상위부터 습득할 수 없다.
- 가로 280 간격, 행당 최대 6개, 위로 펼치는 격자에 배치한다. 연결선은 노드 사이 반 열 통로로 우회한다. 드래그·스크롤·확대/축소를 유지한다.

## 실제 성장과 탐색

- 누적 5점 투자마다 숙련 1: 그래프 피해 +1, 전투 시작 보호막 +1. 최대 숙련 5이며 재배분 시 다시 계산한다.
- 공방: 체력 4를 지불해 원정 그래프 피해 +1(훈련 최대 3), 또는 카드 제거.
- 관측소: 체력 5를 지불해 성장점 +2, 또는 공명 +2.
- 보급: 다음 전투 시작 보호막 +8, 최대 체력의 15% 회복, 카드 보상 중 선택. 보호막 보급은 전투 시작에 소비된다.
- 새 이벤트 4개로 총 10개. 체력과 성장점/훈련/카드 정리/생존 자원을 교환한다. 방 완료 기본 성장점은 별도로 유지하므로 추가 성장 보상 선택 시 기존 35점 예산을 넘길 수 있다.
- 방은 총 9종이다. 보스 외 각 행에 최소 두 종류를 배치하고 다음 행이 한 방인 경우 외에는 출구를 둘 이상 제공한다. 전투/정예와 회복/성장/보급의 선택을 구분한다.

## 난이도와 피격

일반 적 체력 기본값 18→22, 층 안 진행 계수 3→4, 층 계수 17→20. 정예 추가 체력 8→16, 중간 보스 추가 20→34. 공격 기본값 2→3, 층 안 증가 주기 4→3, 정예 추가 1→2. 새 적 AI나 공격 패턴을 추가한 변경은 아니다. 숙련/훈련 성장과 함께 전체 3층 수동 밸런스 검증이 필요하다.

적 행동에서 체력 피해와 보호막 흡수를 별도로 누적한다. 실제 체력 피해는 붉은 파편과 체력 숫자, 보호막 흡수는 청록색 방어 연출과 숫자를 표시한다. 모션 감소 설정은 움직임/파편/화면 가장자리 연출을 끄고 정적인 숫자를 남긴다. 카메라 흔들림이나 전체 화면 점멸은 없다.
