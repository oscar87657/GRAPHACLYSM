# 5층 원정과 전장 패턴 · 규칙32

## 적용 범위

새 원정은 층마다 8개 방, 총 40개 방을 지나 완주한다. 기존 세 층 뒤에 4층 ‘격자의 공중정원’, 5층 ‘일식의 왕좌’를 연결했다. 기존 세 보스는 유지하고 새 보스 두 종류와 일반 적 두 종류를 추가해 적 사전은 일반19·보스5, 총24유형이다. 성좌 개편은 이번 범위에 포함하지 않는다.

4·5층은 기존 3층의 갈림길과 비전투 방 구조를 재사용하며, 전투 편성과 층 보스를 교체한다. 새 일반 적에 기존 적을 섞어 일반전2명·정예전3명으로 구성한다. 새 보스전은 탈출 칸을 확보하도록 장애물과 호위 적 없이 보스 단독으로 구성했다. 새로운 이벤트나 전용 배경 그림은 추가하지 않았다.

새 보스는 체력270/340, 기본 공격9/10. 체력 절반 이하인 다음 턴부터 공격 순서가 한 칸 바뀌고 공격+2. 패턴은 전체 턴 번호로 순환하므로 재정비 다음에 항상 첫 패턴으로 되돌아가지는 않는다. 현재 수치는 플레이테스트용이며 40개 방 전체의 수동 난이도 조율은 별도다.

## 예고와 판정

EnemyFieldPatterns가 격자7개·가로 띠4개·체크무늬10개 사각형을 제공한다. 화면은 이 사각형을 그대로 그리고, 실제 적중은 동일 사각형과 플레이어 반경의 접촉으로 계산한다. 격자 교차점에 서도 같은 적의 한 행동에서 피해가 중복되지 않는다. 공격 아닌 재정비 턴에는 영역을 표시하거나 피해를 주지 않는다.

새 공격은 땅에 예약한 공격이므로 견인으로 시전자의 몸을 옮겨도 예고 위치는 유지한다. 기존 몸 기준 직선·고리 공격의 견인 동작은 변경하지 않았다. 패턴 위치는 턴마다 교대하며 각 패턴에 안전한 영역이 남는다. 이동 경로 전체를 지속 피해 영역으로 처리하지 않는다.

## 저장과 성장

FiveFloors 명령은 TowerArchive 바로 다음, 아직 방에 진입하지 않은 새 원정에만 적용한다. 규칙32 저장에서 해당 명령을 재생해 5층 지도를 복원한다. 과거 저장은 명령이 없으므로 기존3층을 유지한다. 과거 DungeonGenerator의 층 상수나 적 enum ID를 재배치하지 않는다.

각 방 성장점1, 최종 층을 제외한 보스 추가3의 기존 규칙을 확장한 경로에도 적용한다. 방과 보스가 늘어난 만큼 성장 기회와 전리품 기회도 늘어난다. 카드·유물·회복 등 기존 방 보상 체계를 그대로 이용하며 별도의 총점 제한을 새로 만들지 않는다.

## 코드와 검증
