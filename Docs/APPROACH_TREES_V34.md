# 전투방식별 성좌 · 규칙34

새 원정의 집행·기록·조율·관측마다 55노드. 무료 출발 능력1, 전용 기술/궁극기 변경9, 조건부 상태 연계45로 구성한다. 총220개 항목이며, 220종 독립 전투 시스템은 아니다. 조건부 연계는 기존 상태 규칙을 공유한다.

하나의 뿌리에서 세 줄기로 올라간다. 노드별 직계 자식은 최대3개이며 모든 유료 노드는 직전 선행 하나를 요구한다. 각 줄기의 주요 양자택일은 반대 선택 및 그 후속 경로를 잠근다. 별도 장착 없이 습득 효과가 다음 전투부터 적용된다. 말단 반환 및 전체 재배분 가능, 무료 뿌리는 반환 불가.

집행은 돌진 거리/폭/피해, 파열 궁극기 범위/피해, 적중 방어와 처치 회복을 확장한다. 기록은 현재 출력 보존과 반복 재현을 선택하고, 궁극기 재현 횟수/피해 및 기록의 상태 연계를 확장한다. 조율은 견인 거리/범위, 반전, 추가 조립 피해/방어/기술 기회를 확장한다. 관측은 위성 거리/접촉, 원격 출력과 성역 기간/보호/회복을 확장한다.

연계 조건은 본 방출 직전 스냅샷으로 고정한다. 생성된 상태가 같은 방출의 다른 조건을 다시 켜지 않는다. 적 상태 보상은 본 작도에 맞고 살아 있는 적에게만 준다. 재현은 카드 능력을 복제하지 않는다. 조율의 추가 기술은 이동이나 드로우를 갱신하지 않는다.

ApproachTree 명령은 BattleRework 다음 새 출발에만 허용한다. 규칙34 저장은 안정적인 노드 ID의 명령 ID와 기존 journal로 복원한다. 이전 원정은 새 트리로 자동 변환하지 않는다. 이전 구매와 전투 규칙은 그대로 유지한다.

UI: 클릭 상세·키워드 설명·별도 습득·검색·드래그/확대·전체 보기. 무료 뿌리에서 기존 기본 운용 비교/분리 체험 가능. 모든 개별 강화 노드의 전후 비교나 강화된 실험 전투까지 제공하는 기능은 아니다.

전체5층 수동 밸런스, 모든 노드 조합의 재미 평가, Profiler와 새 실행 파일 빌드는 별도다.
