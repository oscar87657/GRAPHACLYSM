## 카드105·유물100 전체 문구 검수

2026-09-13 최신 후속. 카드 상세를 ‘대상/발동 조건 → 효과 이름·수치 → 지속기간’으로 통일한다. 제목과 본문에 잔불 같은 이름을 두 번 표시하지 않는다. 효과 본문은 버프/디버프의 작동 원리를 반복하지 않고, 해당 단어의 클릭 설명을 사용한다. 확대 카드도 같은 요약을 공유한다. 회복·정화처럼 수치/기간 표현이 다른 능력의 즉시 적용 표시는 유지한다.

사슬 나침반: ‘이동 후 방출하면 경쾌 1 · 2턴.’으로 변경. 월은 박자기 집중, 압력 유리병 균열, 외로운 원점 못 고정의 중복 풀이와 분할 프리즘의 개발자용 비교 문구도 제거했다. 신규76개 조건부 유물은 이미 조건·상태·수치·기간 구조여서 유지한다. 발동 횟수나 응축 체력 비용 같은 실제 판단에 필요한 제한은 무조건 삭제하지 않는다. 효과 수치와 이전 규칙 카탈로그는 변경하지 않았다.

밑줄 누락 원인은 일부 텍스트 영역의 높이가 폰트 lineHeight보다 작을 때 글자 전체를 버리던 코드다. 이제 실제 표시 영역과 겹치는 글자는 경계에서 잘라 밑줄/클릭 영역을 유지한다. 단순히 새 카드 ID를 링크 목록에 추가한 수정이 아니다.

## 필요한 용어만 짧게 설명

2026-09-13 후속: 밑줄은 고유 전투 규칙을 이해하기 위한 장치다. 회복·수식은 일반 문장에서 자동 링크하지 않는다. 버프/디버프 이름은 모두 공통 설명으로 연결하고, 효과를 이해하는 데 필요한 시점과 행동만 한두 문장으로 표시한다. 카드 자체의 대상·수치·기간 표시는 유지한다. 상태 칩은 현재 수치/남은 횟수도 보여준다.

설명 중인 용어는 본문에 다시 등장해도 밑줄/클릭 영역을 만들지 않는다. 파열/균열, 방패 관통/관통, 약해진 방벽/방벽 약화, 찢긴 상처/상처, 원점/기준점, 견인/끌어당김도 같은 개념으로 구별한다. 다른 고유 상태는 계속 클릭해 읽을 수 있다. 문단 캐시에 제외 제목을 포함해 같은 본문이 다른 제목 아래 나타나도 이전 클릭 영역을 재사용하지 않는다.

예: 잔불 ‘적 행동 전에 수치만큼 피해를 받습니다.’ / 균열 ‘다음 작도에 받는 피해가 수치만큼 늘어나고 사라집니다.’ / 수호 ‘새로 걸리는 해로운 상태를 한 번 막습니다.’ 설명이 짧아진 만큼 팝업 최소 높이도170→118로 줄였다. 이전 원정의 경쾌 설명은 비용 면제, 새 규칙은 거리 증가로 구분한다.

OnGUI 검사는 모든 능력 이름(일반 회복 제외)의 설명 연결, 모든 용어의 자기 링크 금지, 동의어 자기 링크 금지, 짧은 설명 길이, 실제 ‘파열·균열·회복·잔불’ 본문에서 잔불만 링크되는지 확인한다. Core/저장/스킬트리 변경 없음.

검증: `Logs/keyword-brief-smoke.log`, 화면361장·게임 Runtime errors0, 위 정책/실제 클릭 검사 통과. 원본/격리 사본 C# 차이0. 이번 UI·문구 수정에서 별도 EditMode 전체 재실행이나 새 실행 파일 빌드는 하지 않았다.

## 효과 문장 내부 키워드 후속 수정

사용자 이미지의 확대 카드 효과 줄은 일반 Label과 줄 전체 클릭 영역이 남아 있어, 문장 속 단어 밑줄 처리가 빠져 있었다. `DrawReadableCardBadges`도 공통 문단 렌더러를 사용하도록 수정했다. ‘적 적중 · 약화 1’에서는 ‘약화’ 글자에만2px 밑줄/클릭 영역을 만들며 대상·수치·지속시간·빈 배경 클릭은 설명을 열지 않는다. 키워드 설명을 열어도 원래 확대 카드를 유지한다. 새로운 배지나 버튼을 추가한 변경이 아니다.

OnGUI 회귀에 실제 약화 카드의 효과 줄을 그려 단어별 클릭 영역 생성, 대상 부분 클릭 무반응, 약화 클릭 시 설명/확대 카드 유지/이벤트 소비 검사를 추가했다. 전투·성좌·저장 규칙은 변경하지 않았다.

[실제 확대 카드의 고정·약화 밑줄](Screenshots/inline-card-keywords.png)을 직접 확인했다. 같은 효과를 줄 전체 클릭으로 대체하지 않는다.

후속 검증: `Logs/inline-keyword-smoke.log`, 화면361장·게임 Runtime errors0, 실제 효과 줄의 약화 단어 클릭 회귀 통과. 원본/격리 사본 C# 차이0. 이번에는 전투 규칙을 바꾸지 않았으며 새 EditMode 전체 실행은 하지 않았다.

2026-09-13. Presentation 변경이며 전투·성장·저장 규칙31은 유지한다.

카드 상세의 효과와 도안 설명, 유물 사전/상점/보유 유물/보상 설명, 적 사전의 패턴·대응법, 성좌 상세에 공통 용어 밑줄을 연결한다. 상태 칩과 카드 효과 배지도 클릭으로 설명을 연다. 작은 겹친 손패에서는 카드 선택을 우선하고 확대된 카드의 설명·효과에서 키워드를 클릭한다. 뒤 카드가 클릭을 먼저 가로채지 않도록 축소 손패에는 별도 키워드 입력을 붙이지 않는다.

클릭한 설명은 포인터가 떠나도 유지된다. ×/Esc/바깥 클릭으로 닫는다. 바깥 클릭의 누름·뗌은 소비해 뒤의 카드 사용·구매를 막는다. 설명 안의 밑줄 키워드를 다시 클릭하면 해당 뜻으로 바뀐다. 전투 기술/궁극기/응축 버튼 자체는 원래 동작을 유지하며 호버 안내 안의 키워드를 클릭해 고정할 수 있다. 조준 중에는 설명이 조준을 가리지 않도록 기존 차단을 유지한다.

기존 카드 키워드에 대상·수치만 있던 경우 공통 효과 정의를 함께 넣는다. 일반 용어 설명과 현재 카드 수치/기간을 구분한다. 경쾌는 이전 원정의 이동 비용 규칙과 현재 원정의 거리 증가를 구분해 설명한다. 적의 상태 칩은 현재 수치·남은 적 행동 횟수를 표시한다.

View가 최대512개 문단 배치 캐시를 소유한다. 문자열/사각형/스타일/정렬이 같은 설명은 커서 위치를 다시 계산하지 않는다. 글꼴과 줄바꿈은 실제 GUIStyle을 공유한다. 캐시 상한에 도달하면 이전 배치를 비우며 장면별 영구 사전을 늘리지 않는다. 키워드 팝업은 기존 하나의 사각형/문자열 상태를 재사용한다. 추가 비트맵·전투 컬렉션·저장 필드는 없다.

후속 스킬트리는 [행동 중심 재설계 초안](GROWTH_REDESIGN_BLUEPRINT.md)을 따른다. 이 문서 작업에서 새 성장 효과·경로를 적용한 것은 아니다.
