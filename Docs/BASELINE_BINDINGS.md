## 반드시 결정할 충돌: 공통 기본 궁극기가 아직 없다

현재는 같은 캐릭터라도 이름과 기본 효과가 다른 궁극기를 사용한다. 단순 데이터 복제 중복이 아니다.

| 스타일 | 현재 이름 | 기본 효과 |
|---|---|---|
| 집행 | 검은 종결선 | 실제 적중 지점 주변 반경1.8, 피해12 파열. 대상당1회, 돌진 대기 초기화 |
| 기록 | 불멸의 기록 | 궁극 도안을 다음 두 방출에 재현. 피해8+저장 조립 위력 |
| 조율 | 시계 없는 밤 | 적 행동 전 남은 손패로 추가 조립1회. 무료 드로우/이동 갱신 없음 |
| 관측 | 만월의 성역 | 도안을 두 적 행동 동안 보존. 몸/위성이 접촉하면 적 행동 전 보호막10 |

공명 비용은 모두6이며 기존 궁극기 준비/방출 입력을 공유한다. 이름 배열: `Assets/Scripts/Runtime/Presentation/GraphaclysmApproachUltimatesView.cs:9`. 실제 서로 다른 실행: `Assets/Scripts/Core/Combat/ApproachUltimates.cs:37,62`. 비용: `Assets/Scripts/Core/Combat/TacticalCombatState.cs:12`.

패키지의 ‘기본 궁극기 보존’과 ‘캐릭터당 하나’는 현재 네 효과를 그대로 둔 채 동시에 충족할 수 없다. 패키지02의 명시적 지시에 따라 임의 통합하지 않는다. 제안은 이안의 검은 종결선과 루나의 만월의 성역을 공통 기본으로 하고, 기록/추가 조립은 새 공통 궁극 노드의 성장으로 제공하는 것이다. 이는 기존 새 원정의 능력 변경이므로 사용자 결정 전 미확정이다. 과거 원정은 기존 실행기를 유지한다.

## 중복 판매/하향 위험

- 넓은 회전: 이미 기본 ±90도. 같은 범위를 다시 유료 판매하지 않는다.
- 성운 견인: 이미 기본 J 기술. 현재 사거리3/반경2.2/이동1.5로 문서 입문 수치보다 넓다. 기본 기능 제거 또는 문서 수치로 하향하지 않는다.
- 원점 조율: 기본 K가 이미 원점 이동을 지원한다. 단순 해금으로 판매하지 않는다.
- 처형 재개: 기본 집행에 처치 재사용이 있다. 추가 사용권 규칙과 한도 변경을 실제 증분으로 구분해야 한다.
- 기록 기본은 현재 조립을 비용과 함께 예약한다. 과거 기록 선택기로 바꾸려면 수명/사용 원장 및 입력을 구현해야 하며 이름 교체만으로 완료할 수 없다.

중복 노드의 최종 증분 계약은 기본 궁극기 결정 이후 별도 명시한다. 무효 노드를 정상 판매하지 않는다.
