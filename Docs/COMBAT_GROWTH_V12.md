# 전투·성장 확장 v12

2026-09-10. 기존 3층 원정과 수식 조립 전투를 유지하면서 카드·상태·유물·두 종류 성장 트리를 실제 규칙과 저장에 연결했다. 탑형 지도와 스토리는 아직 별도 구상 범위다.

## 전투 상태와 카드

기존 8종에 네 상태를 추가했다.

- `가시`: 보호막을 지난 체력 피해를 받으면 해당 공격자에게 수치만큼 반격한다.
- `추진`: 다음 방출의 적중 피해를 수치만큼 높이고 방출 뒤 소모한다.
- `요새화`: 적 행동 직전에 같은 수치의 보호막을 얻는다.
- `파열`: 다음에 받는 작도 피해가 수치만큼 늘고 적중 뒤 소모한다.

신규 파편은 꺼지지 않는 재, 가시 성좌, 유성 보폭, 별빛 보루, 파쇄의 정리, 붉은 만가, 굴절 보법, 성운의 품 8장이다. 기존 수학 변환을 다른 능력·드로우·등급 조합으로 재사용하여 카드 풀은 31종이다. 새 상태는 카드 호버·사전·상태 칩에서 같은 설명을 사용한다.

## 이번 원정 성장

방 완료 시 일반 전투 2, 정예 3, 보스 4, 비전투 1의 탐사 경험을 얻는다. 요구 경험을 채울 때마다 성장점 1을 받는다. 레벨·경험·점수·구매·적용 변주는 원정 명령으로 재생되며 새 원정을 시작하면 초기화된다.

두 캐릭터는 각각 6노드를 가진다. 첫 노드는 전투당 한 번 쓰는 기술을 열고, 두 변주를 모두 습득하면 지도 화면에서 원하는 역할을 다시 선택할 수 있다. 별도의 두 궁극기 변주도 같은 방식이다.

- 이안: 흑유리 각인 → 가시 장막 / 파열 각인, 흑유리 개방 → 산산조각 / 불멸의 기록.
- 루나: 월면 보법 → 별의 피난처 / 유성의 숨, 백야의 포옹 → 만월의 포옹 / 그믐의 칼날.

지도·일시정지의 `원정 성장` 또는 G로 트리를 열고, 전투에서는 K 또는 왼쪽 전투 기술 버튼을 사용한다.

## 영구 기록과 잔광

패배 시 기본 2에 도달 층 보정, 완주 시 기본 8의 잔광을 얻는다. 같은 시드의 종료 보상은 한 번만 지급한다. 메인 화면의 `영구 기록`에서 최대 체력, 승리 회복, 시작 공명, 시작 탐사 경험, 시작 보호막, 종료 잔광 보너스를 단계별로 산다. 이는 캐릭터 전투 기술을 직접 추가하지 않고 다음 원정의 진행을 돕는 계정 성장이다.

`legacy.save`는 원정 슬롯과 분리된 SHA-256 체크섬 파일이며 최대 64개 지급 시드를 기억한다. 영구 효과 스냅샷은 원정 저장에도 포함되어 진행 중 영구 트리를 바꿔도 이어하기 원정의 수치가 바뀌지 않는다. 원정 저장은 형식 2·규칙 12다. 과거 규칙 저장은 조용히 재생하지 않는다.
