# 파편 카드 조사와 적용 · v8

2026-09-06. 목표는 완성된 그래프를 더하는 대신 앞선 궤적 전체를 다시 조립하는 방법을 넓히는 것이다. 아래 수학 자료는 곡선의 원리 근거이며 카드명·계수·효과·등급은 GRAPHACLYSM의 게임 설계다.

## 조사 근거

- [MathWorld: Lissajous Curve](https://mathworld.wolfram.com/LissajousCurve.html): 가로·세로 진동의 주기와 위상을 달리하며, 유리수 주기 비에서 닫힌 궤적을 만든다. 이전 궤적의 가로 성분을 2배, 세로 성분을 3배 속도로 읽는 쌍성직조에 적용했다. 위상 차를 바꾸는 원리는 엇박자에도 적용했다.
- [MathWorld: Epitrochoid](https://mathworld.wolfram.com/Epitrochoid.html): 원 밖을 구르는 원 위의 점을 두 회전 성분으로 표현한다. 월식은 이전 궤적과 그 궤적의 4배속 성분을 차감하여 겹친다.
- [MathWorld: Limaçon](https://mathworld.wolfram.com/Limacon.html): 극좌표 반경의 상수항과 코사인 항으로 한쪽이 부푼 곡선을 만든다. 편월은 반경 배율 1+0.55cos(t)를 이전 궤적에 곱한다.
- [MathWorld: Shear](https://mathworld.wolfram.com/Shear.html): 축에서 떨어진 거리에 비례해 한 방향으로 미는 선형 변환이다. 비껴쓴 선은 높이의 0.7배를 가로 좌표에 더해 원·교차 무늬를 기울인다.
- [MathWorld: de Moivre's Identity](https://mathworld.wolfram.com/deMoivresIdentity.html): 복소수의 거듭제곱이 반경과 각도에 작용하는 원리다. 삼중봉인은 이전 궤적 전체를 세제곱하고 4로 나눈다.

위 자료는 Eric W. Weisstein의 Wolfram MathWorld 수학 항목이다. 원문 그림이나 텍스처를 게임 자산으로 가져오지 않았다.

## 구현 카드

모든 F는 이전 단계의 로컬 복소 궤적이고, 전장 좌표는 별도 기준점 O+F다. F₀=1.6exp(it), t는 0~2π다.

| 카드 / 등급 | 합성 규칙 | 부가 능력 | 조립 위력 / 주파수 상한 변화 |
|---|---|---|---|
| 쌍성직조 / 고급 | Re(F(2t))+i Im(F(3t)) | 적 고정 1회 · 자신 집중 1 | +2 / ×3 |
| 월식 / 희귀 | F(t)−0.4F(4t) | 적 잔불 3 · 자신 보호막 2 | +2 / ×4 |
| 편월 / 일반 | (1+0.55cos(t))F(t) | 적 약화 2 · 자신 회복 2 | +1 / +1 |
| 비껴쓴 선 / 일반 | Re(F)+0.7Im(F)+i Im(F) | 적 노출 1 · 자신 보호막 4 | +1 / 유지 |
| 엇박자 / 고급 | Re(F(t+π/2))+i Im(F(t)) | 다음 보충 +1 · 자신 정화 | +0 / 유지 |
| 삼중봉인 / 희귀 | F(t)³/4 | 적 고정 2회 · 자신 집중 3 | +3 / ×3 |

고정은 표의 횟수를 따르고, 잔불·약화·노출·집중의 수명은 2회다. 보호막은 이번 적 행동 종료까지다. 드로우 외 능력은 실제 선에 맞은 대상에만 적용한다. 응축 추가 보충 상한 1장, 전체 조립 위력 상한 10, 8개 파편과 최대 주파수 96을 유지한다. 주파수 값은 실제 남은 성분을 일일이 분석한 값이 아니라 안전한 상한이다.

쌍성직조·월식·편월을 **첫 카드로 쓸 때** 해당 고전 곡선의 예시가 된다. 임의의 앞선 F에 합성한 결과 전체를 엄밀한 리사주/에피트로코이드/리마송이라고 부르지 않는다. 삼중봉인을 첫 카드로 쓰면 반경 1.024의 원을 세 번 지나며 자동으로 세 잎 꽃이 되지는 않는다. 엇박자를 첫 카드로 쓰면 대각선 구간이 생긴다. 둘 다 비원형 궤적 뒤에 놓으면 다른 합성 무늬를 만들 수 있다.

이안은 중복 잔향 한 장을 비껴쓴 선으로, 루나는 윤무 한 장을 쌍성직조로 교체했다. 시작 덱 12장·시작 손패 5장은 같다. 전체 23종이 보상 풀과 카드 사전에서 사용되며 새 6종도 각각 고유 문양·등급색을 가진다. 문양은 식별용이고 실제 첫 카드 출력은 사전의 별도 그래프에서 읽는다.

## 조립 예시

- 쌍성직조 → 비껴쓴 선: 교차 궤적을 높이에 비례해 비튼다. 순서를 바꾸면 서로 다른 시점의 가로 성분을 읽으므로 모양이 달라진다.
- 편월 → 월식: 비대칭 궤적 자체를 빠른 회전 성분과 겹친다.
- 귀환점 → 쌍성직조 → 편월: 플레이어 위치에 기준점을 잡고 교차 무늬의 한쪽 반경을 늘린다.
- 귀환점 → 쌍성직조 → 비껴쓴 선 → 편월 → 엇박자 → 삼중봉인 → 월식 → 고요: 최대 주파수 상한 48의 8개 조립 예시. 모든 조합이 적을 맞히거나 화면 안에 전부 들어간다고 보장하지 않는다.

## 필드와 검증 범위

화면의 필드는 760×608에서 950×760 논리 픽셀로 늘렸다. 두 축 모두 단위당 95px이며 면적은 56.25% 증가했다. 전장 좌표 범위 x=0~10, y=−4~4와 이동 거리·적중 반경은 유지한다. 화면 확장은 곡선이나 피해를 임의로 확대하는 규칙이 아니다.

좌측은 체력·궁극기·조립·취소·이동, 우측은 적 의도·호버 상세·방출·응축·해체, 중앙 하단은 최대 8장 손패다. 손패의 좁은 카드는 축약 기호를 사용하고 정확한 규칙은 호버/사전에서 표시한다. 카드 설명과 하단 배지 간격도 조정했다.
