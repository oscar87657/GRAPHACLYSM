# 핵심 능력 비교·시험하기 · 우선순위 3

사용자는 현재 전투 기술의 다양성과 판정에 만족했고 궁극기는 더 차별화할 필요가 있다고 평가했다. 이번에는 기존 우선순위 3인 선택 전 이해·체험을 진행한다. 전투 수치·궁극기·성장 비용·원정 규칙은 바꾸지 않는다. 궁극기 재설계는 후속 과제로 남긴다.

## 제공하는 흐름

G 성좌 → 핵심 노드 클릭 → **변화 비교 · 직접 시험하기** → 기술 사용 전/후 실제 도안 비교 → 지도·휴식에서 별도 체험 → **체험 종료 · 성좌로 G**.

- 첫 대상은 `ian.inscription.core`, `ian.archive.core`, `luna.orbit.core`, `luna.binary.core` 네 개다. 잠겨 있어도 비교와 체험 가능. 습득·장착·환급은 자동 실행하지 않는다.
- 모든 비교는 같은 고정 손패·적 배치에서 긴 황혼과 파열을 조립한다. 사용 전은 능력을 아직 쓰지 않은 상태, 사용 후는 해당 방식의 실제 기술을 실행한 상태다. 현재 원정의 전체 빌드를 복제한 것이 아니라 구현된 기본 운용 예제다.
- 집행은 경로 이동·체력 피해·파열과 다음 방출 예측, 기록은 현재 방출의 출력 차이와 보라색 예약 도안, 조율은 기준점/회전 전후, 관측은 위성만 닿아도 전달되는 자가 강화를 보여준다. 기록 예정 위치는 실제 도안 예측 버퍼다.
- 비교 화면은 전투 중에도 볼 수 있지만 직접 체험 진입은 지도·휴식에서만 허용한다. 진행 중인 전투의 조립/방출을 중단해 다른 전투를 덮어쓰지 않는다.
- 체험은 같은 두 카드가 미리 조립된 실제 전투로 시작한다. 남은 손패와 기존 K/J 조작을 사용한다. 체험 재시작은 같은 시드·손패·준비 상태다. 승리·패배 화면에서도 다시 시험하거나 원래 성좌로 복귀한다.
- 원정 객체·체력·손패·예약 카드·덱·난수·노드·성장점은 유지한다. 체험에는 원정 보상/종료 잔광이 없고, 복귀 시 선택 노드·스크롤·확대·검색을 복구한다. 원래 구매 여부는 돌아온 뒤 사용자가 결정한다.
- 아직 미구현인 노드·각성·궁극기의 가짜 시연은 제공하지 않는다. 관측 핵심의 체험은 현재 출발 선택에서 제공되는 관측 방식이며, 기존 원정에서 그 노드를 습득하면 자동 전환된다는 뜻은 아니다. 각 노드의 실제 적용 범위는 기존 성좌 설명을 유지한다.

## 소유권·저장

`NodeTrialComparison`은 창을 열 때만 독립된 연습 RunGameSession 두 개를 만들고 실제 명령으로 예제를 구성한다. View는 실제 방출 예측·좌표·체력과 같은 표본을 렌더링한다. 원정 객체를 복제/재연산해 비교 상태로 변형하지 않는다. 문구·적 표시는 생성 시 캐시한다.

`PrototypeGameFlow.TryStartNodeTrial`은 원래 원정/캐릭터/선택 인덱스를 보존하고 독립 연습을 CurrentRun으로 둔다. 중첩 진입·다른 캐릭터 노드·미구현 노드·전투 중 진입은 거절한다. `TryReturnFromNodeTrial`은 같은 원정 객체를 돌려준다. 일반 메인/캐릭터 선택 종료 API도 체험 중에는 우선 원정을 복구해 원본을 유실하지 않는다. 체험 재시작은 다음 원정 시드를 진행시키지 않는다.

View는 진입 전 원정을 저장하고 실패하면 체험을 시작하지 않는다. 체험 중 자동 저장·종료·포커스 상실 저장의 대상도 보존한 원래 원정이다. 체험 진행은 저장하지 않으며 앱을 종료하면 이어하기는 원래 원정이다. 원정 저널에 체험 명령을 넣지 않는다. 형식2/규칙24와 기존21~23 호환 유지.

비교 창 수명에는 연습 두 개, 체험 수명에는 연습 하나와 원래 원정 참조가 존재한다. 비교를 닫거나 체험 진입 시 비교 참조를 해제한다. 기록형 비교는 각 전투의 216KiB 파편 버퍼 3개씩 최대 6개와 기존 전투 배열을 가지며 다른 방식은 더 적다. 입장 전환 순간에는 새 체험과 비교 상태가 잠깐 함께 존재할 수 있다. 프레임마다 전투/컬렉션을 생성하지 않는다.

## 검증과 다음 작업

최종 EditMode 284/284 통과: `Logs/node-trials-final.xml`. 네 잠긴 핵심 진입/복귀, 원정 참조·저널·다음 시드 보존, 체험 재시작, 잘못된 진입 거절, 종료 경로, 네 실제 전후 동작을 포함한다.

최종 화면104장·게임 Runtime errors0: `Logs/node-trials-smoke-final.log`. 원본 저장 파일 내용/체험 보상 없음/성좌 카메라·선택 복귀, 패배 후 다시 시험, 방출 도중 G로 종료까지 검사했다. 1080p/720p 비교 화면을 직접 확인하고 관측 위성 표식 겹침과 기록 예제 위치를 보완했다. C# 원본/검증 사본 차이0건. 대표 화면은 `Docs/Screenshots/node-trial-observation.png`, `node-trial-recording-720p.png`.

다음 원래 우선순위는 초반 원정의 ‘능력 획득 → 활용 → 성장 체감’ 흐름 조율이다. 궁극기 차별화도 후속 설계 대상이며 현재 수치 보정형을 최종안으로 취급하지 않는다. 궁극기 개편 시 이 비교·체험 방식에 검증된 효과를 추가한다. 전체 성좌 시연·새 각성·Windows 새 빌드·Profiler·수동 재미 평가는 이번 완료 범위가 아니다.
