# 전투 방식의 원정 연결 · 규칙 22

2026-09-12. 사용자가 비교 전투를 체험하고 긍정적으로 평가해 다음 단계 진행을 승인했다. 이번 변경은 그 세 전투 방식을 기존 원정/성장/저장에 연결한다. 대형 나무 전체나 3층 전투 구성을 완전히 재설계한 단계는 아니다.

## 새 원정 시작

메인 **새 기록 시작 → 캐릭터 선택**. 이안은 집행/기록 두 버튼, 루나는 조율 버튼으로 출발한다. 메인 오른쪽 비교 전투는 이전처럼 저장 없는 연습으로 남는다.

새 방식의 원정은 긴 황혼·파열·여백·승천·고요·잔향 여섯 장을 모두 손에 들고 시작한다. 각 캐릭터의 체력과 영구 보정은 유지한다. 첫 전투는 비교 전투의 동일 좌표를 사용하는 도입전이며 적 체력 26/24/36, 공격 4/4/8이다. 비교 전투 수치는 바꾸지 않았다.

이후 기존 3층 지도, 방 선택, 카드/유물 보상, 성장점, 휴식/공방, 보스를 이어간다. 후속 선형 포수가 있는 전투에는 기점 `(5,1.6)`과 연결된 동력선을 표시하고 실제 작도로 끊어 포격을 중단한다. 현재 생성 전투의 선형 포수는 방당 최대 하나이며 이 연결은 전투 수명의 단일 상태다. 모든 전투에 새 연결 퍼즐을 추가한 것은 아니다.

## 기존 나무의 실제 확장

새 원정에서는 다음 핵심 능력을 장착하면 **다음 전투**의 방식이 결정된다. 장착한 구현 핵심이 없으면 출발할 때 고른 방식을 유지한다.

- `ian.inscription.core` 균열의 기록자: 집행형.
- `ian.archive.core` 잔상의 기록자: 기록형.
- `luna.orbit.core` 궤도의 조율자: 조율형. 시작 능력과 중복 강화되지는 않는다.

다음 세 특성은 관련 형태/핵심을 장착한 상태에서 함께 장착해야 작동한다. 기존 선행 경로, 투자 문턱, 비용과 두 특성 한도는 유지한다.

- **파열 집행** (`ian.execute.m2`): 집행이 기존 파열을 피해에 더하고 소비한다. 이때 새 파열을 다시 붙이지 않아 같은 파열을 다음 작도에서 중복 소비하지 않는다. 파열이 없을 때는 기존 집행처럼 새 파열 6을 남긴다. 미리보기와 기술의 체력/보호막 피해는 같은 소비량을 사용한다.
- **먹빛 필사** (`ian.archive.m3`): 기록과 예약이 비어 있을 때 응축하면 현재 좌표의 도안을 기록한다. 다음 방출에서 추가 공격한다. 응축 체력 비용/적 행동은 유지되며 카드 능력과 드로우를 복제하지 않는다.
- **역위상 조율** (`luna.rotate.m2`): 조준 중 `R`로 회전/가로축 거울 반전을 전환한다. 조정 전후의 실제 도안을 보여주고 클릭으로 확정한다. 원래 회전 입력 `Q/E`도 유지한다.

기록 출력에는 저장 당시 조립 위력과 원정의 그래프 피해 보정(숙련/훈련/관련 유물)이 포함된다. 이후 강화가 과거 기록의 출력을 소급 변경하지 않는다.

나무의 해당 노드 상세에는 현재 원정에서 작동하는 효과와 다음 전투 적용 시점을 표시한다. 원본 설계 데이터는 덮어쓰지 않으며 기존 규칙 원정에서는 새 효과가 적용된다고 표시하지 않는다. **두 전투 기술 슬롯 전체와 다른 240노드의 개별 효과가 완성된 것은 아니다.** 현재 K는 전투 방식의 주 행동이며 다른 기술 형태를 장착한다고 모두 독립 기술로 제공하지 않는다.

## 저장 계약

형식은 2, 규칙은 22다. 기존 규칙 21 파일도 검사 후 읽으며 그 원정은 예전 덱/전투/성장 효과를 유지한다. 신규 선택을 과거 원정에 삽입하지 않는다. 21 미만 파일을 새로 호환한 것은 아니다.

명령 ID는 기존 끝에 `ChooseApproach`, `DiagramAbility`만 추가했다. 출발 선택은 저널 첫 명령으로만 허용한다. 새 시작 덱/손패 정책도 그 명령에서 결정적으로 구성한다. 도안 좌표는 미리보기/실행/저장 모두 소수 둘째 자리로 맞춘다. 조정 명령은 기존 좌표 20비트 + 연산 3비트(일곱 회전 후보, 하나의 반전)로 기록한다. 잘못된 좌표/연산은 소비 없이 거부한다.

핵심/특성 변경은 기존 성장 명령으로 복원한다. 다음 방 생성 시 불변 `CompiledGrowthBuild`를 넘기며 진행 중인 전투의 능력은 바꾸지 않는다. 재시작은 같은 출발 방식을 유지한다. 비교 전투는 계속 원정 슬롯/영구 재화/일반 원정 난수와 분리된다.

## 검증과 남은 일

최종 **EditMode 245/245 통과**, **화면 73장·게임 Runtime errors 0**. 게임 진입 전 Unity SearchDatabase 내부 예외는 기존 Editor 서비스 문제이며 게임 오류와 분리했다. 테스트 전용 격리 프로젝트를 사용했으며 사용자 저장 파일은 테스트하지 않았다.

검증 로그: `Logs/approach-campaign.xml`, `Logs/approach-campaign-smoke-final.log`. 새 원정 세 방식의 진입/조립/저장 후 이어하기 화면을 기존 화면 검사에 추가했다. 핵심 효과, 기존 21 저장, 특성의 기존 나무 습득/장착 경로, 도안/기록 복원을 검사한다. 첫 도입전에서 실제 카드/기술로 승리해 성장 보상을 받고 다음 방으로 이어지는 사례도 회귀에 포함한다.

사람의 전체 원정 재미/난이도 평가, 3층 전체 밸런스, 새 Profiler와 Windows 실행 파일 빌드는 미검증이다. 다음 작업은 원정 안에서 세 방식의 성장 속도와 적 배치가 충분히 다른 선택을 만드는지 확인하고, 효과가 검증된 노드를 더 연결하는 것이다. 영구 성장 재화 보너스 폐지/환급과 모든 노드의 시험하기는 이번 범위가 아니다.
