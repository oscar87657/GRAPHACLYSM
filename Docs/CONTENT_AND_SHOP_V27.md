# 상점 진열·전투 콘텐츠 확장 v27

2026-09-12. 사용자 요청: 상점에서 실제 카드와 유물을 보고 구매하고, 카드 종류·적 공격 방식·유물 종류를 늘린다. 성좌 개편은 이 작업과 별도로 이어간다.

## 구현

- 상점 왼쪽에는 실제 카드 앞면(문양·수식·역할·희귀도·설명·키워드·위력), 옆에는 유물 그림과 효과를 크게 진열한다. 오른쪽에는 회복·훈련·제거·성장점 서비스를 둔다. 가격/구매 버튼은 상품과 분리하고 판매 후에도 상품을 남겨 구매 완료를 표시한다.
- 유물은 기존 이미지가 있으면 재사용한다. 이미지가 없는 유물은 공통 벡터 문법의 문양을 사용하며 새 유물 네 개에는 전용 문양을 제공한다. 신규 회화 PNG를 제작한 것은 아니다.
- 카드 총41종(기존35+6), 유물 총24종(기존20+4). 도감·보상·상점·덱에서 동일 정의와 표시를 사용한다. 시작 덱과 상점 가격/재고 개수는 변경하지 않는다.

## 새 카드

| 카드 | 이전 도안 F 전체에 적용하는 변화 | 적중 효과 |
|---|---|---|
| 솟는 첨탑 | x×0.65, y×1.4 | 적 파열2 / 자신 보호막4 |
| 직각의 춤 | 기준점 둘레로90° 회전 | 적 약화1 / 다음 보충+1 |
| 오르는 사선 | y←y+0.7x | 적 노출2 / 자신 추진2 |
| 동쪽의 문 | 기준점 오른쪽2 | 적 고정1 |
| 별의 하강 | 기준점 아래1.5 | 자신 요새화4 |
| 두 개의 고리 | 가로F(t)·세로F(2t) | 적 잔불3 / 자신 정화 |

기준점 이동은 필드 내부 제한, 변형은 기준점을 보존한다. 고리 카드는 세로 시간축만 두 배로 읽고 주파수 보수 상한도×2로 검사한다. 고정 버퍼1536표본·조립8개·주파수96 제한, 취소와 실제 Sample 기반 판정은 유지한다. 도감의 첫 카드 그림은 합성 뒤의 모든 결과를 보장하는 고정 그림이 아니다.

## 적의 새 공격 방식

| 적 | 실제 공격 영역 | 대응 |
|---|---|---|
| 환형 파수꾼 | 턴 시작 자기 위치 중심 반경1.2~3.2 고리 | 작은 원 안으로 접근하거나 큰 원 밖으로 이동 |
| 십자 포수 | 턴 시작 플레이어 위치를 지나는 가로·세로 반폭0.24 띠 | 대각선으로 두 띠 모두 벗어나기 |
| 쌍점 폭격수 | 턴 시작 플레이어 위치와 전장 중심 반대편의 반경0.85 원 | 두 원 모두 피하기 |

플레이어 반경을 실제 접촉에 포함한다. 겹친 두 폭격은 한 적의 공격1회이며 중복 피해를 주지 않는다. 턴 시작에 확정한 경고 영역은 플레이어나 적이 이동해도 해당 턴 중 재조준하지 않는다. 다음 턴에는 다시 조준한다. 경고 영역·오른쪽 행동 이름·적 이름 호버의 대응 설명을 추가했다.

새 원정의 도입/활용/약한 무리와 보스는 유지하며 이후 일반/정예 전투 조합을8→11개로 확장한다. 신규 위험 역할 하나와 기존 적의 조합을 사용한다. 11개의 새 AI를 만든 것은 아니다.

## 새 유물의 실제 발동

| 유물 | 조건과 보상 |
|---|---|
| 외로운 원점 못 | 본 방출로 적 하나만 맞히면 이번 적 행동 동안 고정. 공격은 취소하지 않음 |
| 쌍둥이 공명종 | 본 방출로 자신(위성 포함)과 적을 함께 맞히면 공명+1, 최대6 |
| 압력 유리병 | 응축한 식의 본 방출로 맞힌 적에게 파열3. 다음 타격에서 소비 |
| 되감는 실패 | 파편이 있는 식을 해체하면 보호막5. 빈 식에는 미발동 |

기록 후속/장치 피해에서 조건을 다시 평가하지 않는다. 단일 적중 수는 본 방출의 피해 스냅샷으로 계산하므로 처치 순서에 따라 달라지지 않는다. 응축 여부는 TryBeginPlot에서 초기화 전에 저장한다. 해체 보호막은 예약 취소나 빈 조립 반복으로 복제되지 않는다. 상점 구매 후 다음 전투부터 보유 유물이 적용된다.

## 저장·소유권·메모리

- 형식2/규칙27. ContentExpansion 명령을 끝에 추가하고 새 방식 원정에서만 ChooseApproach→OpeningRoute→ExpeditionEconomy→ContentExpansion을 기록한다. 지도 진행 중 활성화는 거절한다.
- FragmentCardCatalog.Legacy/FragmentRelicCatalog.Legacy는 이전35/20개 배열을 보존한다. 기본 원정 생성은 여전히 이 풀을 사용하므로 규칙21~26 저널의 RNG 선택과 보상을 소급 변경하지 않는다. All은 기존 항목 뒤에 새 항목을 붙인 앱 수명 불변 풀이다.
- opt-in 명령에서만 RunGameSession 소유 rewardPool41/relicPool24 복사본으로 전환하고, 같은 시드/영구 보너스의 원본 생성→도입 배치→확장 배치를 만든다. 이미 이동 보정한 지도를 중복 보정하지 않는다. 화면 열기와 상품 구경은 난수를 소비하지 않는다.
- 기존26 원정에도 새 상점 표시를 사용할 수 있지만 새 카드/유물/적 풀은 새 원정에서만 활성화된다. 구버전 payload에 새 명령을 넣으면 거절한다.
- BattleSession은 유물 효과 크기 int4개와 방출 응축 여부 bool1개를 소유한다. 새 전투 루프 배열은 없다. EnemyState는 기존 조준 좌표를 사용한다. 기존 도감/카드 visual 배열은 전체 카탈로그 크기에 맞춰 초기화한다. 유물 문양은 재사용 선·원 그리기이고 별도 Texture 생성은 없다. 상점 효과 문자열은 상품 참조 변경 때 한 번 조립하고 GUIStyle 하나를 View 수명으로 재사용한다. 고리 경고는96개 선분을 기존 ClipToField로 잘라 손패 영역으로 넘치지 않게 한다.

## 검증과 한계

EditMode 322/322 통과 (`Logs/content-v27-verified.xml`). 신규 테스트는 이전 도안 합성/취소/기준점 경계/주파수, 세 공격의 서로 다른 이동 지점 실제 피해, 조건부 유물 발동/미발동, 규칙26 복원과 신규 opt-in/구버전 payload의 신규 명령 거절,40개 시드 적 등장 여부를 검사한다. 기존 경제 테스트도 새 원정에서 구매·보상·제거·저장 복원을 실행한다. 추가 회귀에서는 실제 전투를 거쳐 상점까지 진행하고 신규 카드와 신규 유물을 각각 구매한 뒤 저장 복원까지 확인한다.

격리 사본으로 검사하며 사용자 Editor와 원정 저장은 건드리지 않는다. 전체3층 수동 밸런스·재미·새 Windows 빌드·Profiler 측정은 미검증이다. 상점의 재고 확장/재입고와 성좌 전체 전투 효과 구현은 이번 범위가 아니다.
