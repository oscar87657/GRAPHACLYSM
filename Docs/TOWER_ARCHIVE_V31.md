# 탑의 적 사전·보스·유물100 · 규칙31

## 적용

새 출발에 StatusRules 다음 TowerArchive 명령을 기록한다. 이전21~30 원정은 기존 적 배치와 유물 정의를 유지한다. 기존 저장을 삭제하거나 진행 중 원정의 지도를 바꾸지 않는다. 새 적 사전과 최신 유물 목록은 처음부터 열람 가능하며 새 콘텐츠 원정은 새 출발이 필요하다.

첫 도입/활용/돌파 전투는 보존하고5행 이후 전투 배치를 확장한다. 각 층의 기존 마지막 보스 노드(7/15/23행)와 지도 연결은 유지하면서 고유 보스와 호위를 배치한다. 일반2명/정예3명/보스+호위2명, 일반 적은 층당 체력+7/공격+1. 전체 원정 난이도 수치는 시제품이며 수동 조정 대상이다.

## 적20종

기존11행동 유형에6일반 유형과3보스를 추가한다. 사전은 유형 기준이며 도입전의 이름·수치가 다른 훈련용 적도 기존 행동 유형에 속한다. 카드 사전의 ‘적 사전’ 탭에서 이름/기본 수치/행동 순서/대응법을 볼 수 있다. 일반 적은 실제 방/층 수치가 달라질 수 있다.

| 새 일반 적 | 행동과 대응 |
| --- | --- |
| 회전 포탑 | 직선과 십자 교대. 직선은 견인, 십자는 대각선 회피. |
| 환월 직조자 | 몸 고리와 지면 쌍점 교대. 이동시키면 바뀌는 영역을 구분. |
| 유리 수복사 | 생존 아군 전체 회복5와 원형 공격 교대. 부활 없음. 우선 처치 대상. |
| 방패 거머리 | 체력 피해를 주면 보호막6 획득. 회피/완전 방어로 공급 차단. |
| 재를 밟는 사냥꾼 | 이동 뒤 두 번 공격, 체력 피격 시 잔불. 고정/상처/정화 활용. |
| 금기의 주술사 | 보호막5·수호1 준비 뒤 십자 공격. 강화 제거/대각선 이동. |

### 층별 보스

| 층 | 보스 | 기본 체력/공격 | 4턴 순환 |
| --- | --- | --- | --- |
|1|흑유리 섭정|120/6|직선 → 십자 → 고리 → 보호막12|
|2|침묵의 서고장|170/7|십자 → 고리 → 쌍점 → 생존 아군 회복8|

세 번째 공격은 기본+2. 체력 절반 이하의 다음 턴부터 공격 형태 순서를 한 칸 옮기고 공격+2, 재정비 턴은 유지한다. 이미 공개한 공격은 체력 변화 도중 바뀌지 않는다. 다음 행동에Ⅰ/Ⅱ단계와 실제 피해·재정비를 표시한다. 보스는 큰 문양/체력바로 구별한다. 고리 턴의 보호막3과 공격 형태별 기존 디버프 규칙도 적용된다.

위치 판정·예고는 EnemyState.AttackShape를 공유한다. 몸 기반 직선/고리는 견인에 따라 이동하며 지면 지정 십자/쌍점은 남는다. 세 보스가9개 독립 기하 시스템을 가진다는 뜻은 아니며, 공유되는 공격 형태의 순환/재정비/호위/단계를 조합한다.

## 유물100종

현재 풀100 = 기존24를 손본 정의 + 조건부76. 새76은19조건×4보상 조합이며100개 독립 전투 하위 시스템을 만드는 방식은 아니다. 조건19: 첫/짧은/긴/이동/정지/자가/동시/다중/단독/응축/저체력/보호막/잔불/균열/유도/고정/보스/프리즘/홀수 턴 방출.

보상은 집중·보호막·관통·수호·재생·요새화·경쾌·가시 또는 적의 잔불·약화·유도·상처다. 조건마다4가지 조합을 이름/설명/문양과 함께 배치한다. 수호·경쾌·유도1, 보호막5, 다른 수치3, 지속2턴. 전체 목록의 진실 원본은 `RelicArchive.cs`와 게임 유물 사전이다.

조건은 본 방출 처리 직전에 고정한다. 이번 카드/유물이 방금 만든 상태로 다른 조건을 소급 충족하지 않는다. 본 방출/기록/장치 처리 뒤 유물을 적용하고, 그 뒤 카드 견인으로 유도·상처를 사용할 수 있다. 추가 공격은 유물을 다시 평가하지 않는다. 조건을 만족하면 유물당 본 방출1회. 적 대상 보상은 본 방출에 맞고 살아 있는 적에게만 적용한다. 자기 보상은 설명에 적중이 요구되지 않으면 빗나간 유효 방출에도 적용한다.

## 소유권·검증

EnemyArchive20개/RelicArchive100개 정의와 문자열은 앱 수명. View 유물 텍스처 참조 배열24→100(새76개는코드문양), 적 사전은 기존8칸 페이지 사용. 조건 평가는 전투 수명의 정수 비트마스크1개와 횟수1개, 원정 유물 컬렉션 참조를 사용한다. 프레임마다 배열/객체를 만들지 않는다. 판정은 Core, 원정 교체와 보상은 Application, 사전과 문양은 Presentation이 소유한다.

새76개 유물의 실제 조건 충족 방출을 개별 검사하고, 보스3종의 공격 형태/재정비/단계 전환, 수복사 비부활, 세 층 보스 배치, 저장 버전 경계를 검사한다. 과거 효과 테스트는 Version30을 대상으로 보존한다. 화면 fixture는 유물 상세/페이지와 적 사전20종, 보스별4턴·2단계를 캡처한다.

수동 전체 원정 밸런스·장시간 재미·Profiler·새 Windows 실행 파일 빌드는 별도다.
