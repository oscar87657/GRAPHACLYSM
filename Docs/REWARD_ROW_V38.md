## 이번 수정

보상 타일 3×2 배치를 삭제하고 세로 카드들을 한 줄로 배치한다. viewport1680×540, 카드300×516, 간격26.6장일 때 마지막 일부가 보이고 가로 스크롤이 열린다. 카드 크기를 줄이거나 두 번째 줄로 내리지 않는다.

마우스 드래그·휠·하단 가로 스크롤바·좌우 버튼으로 이동한다.8논리px 이상 드래그하면 수령 클릭을 취소하며 마우스를 뗄 때 그 아래 카드가 눌리지 않게 한다. 수령/선택권 사용/넘김/상자 시도 완료 카드는 보상 줄에서 제거한다. 남은 카드만 왼쪽부터 채우고 가로 위치를 새 범위로 제한한다. 수령한 카드는 화면에서만 제외하며 저장에 필요한 원래 인덱스와 해결 표식은 보존한다. 따라서 앞 카드가 없어져도 뒤 카드의 명령 대상은 바뀌지 않는다.

상자 실패 결과와 최근 수령은 상단 한 줄로 알린다. 모든 보상이 사라져도 자동으로 다음 방에 진입하지 않고 계속 진행 버튼을 남긴다. 남은 보상 포기는 확인을 거친다.6칸이라는 현재 보상 생성 상한은 변경하지 않는다.
