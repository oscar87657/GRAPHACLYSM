# 네 색의105종 작도 카드 · v28

> 색 분류는 [전체 재검토안](CARD_COLOR_REVIEW.md)으로 대체되었다. 아래는 최초 구현 기록이다. 현재 표시는 DiagramRarity, 기존 Rarity/Tier는 가격·추첨·전투 보존용이며 서로 다를 수 있다.

2026-09-13. 사용자 요청에 따라 카드 수를41→105종으로 확장하고, 실제 도안과 전투 활용을 얼마나 바꾸는지에 따라 기존 카드를 포함한 전체 풀을 재분류했다. 이번에는 유물/적/스킬트리를 추가 변경하지 않는다.

## 등급의 의미와 표시

내부 CardRarity 네 값은 유지하되 등급명/숫자를 카드에 쓰지 않는다. 테두리·왼쪽 띠·상단 배경·문양의 네 색으로 표시한다. 역할명(직조/변형/이동/지원)은 등급이 아니므로 유지한다. 보상/손패/상점/도감에서 같은 visual 정의를 사용한다. 도감에 네 색 필터와 모든 색 버튼, 역할과 색의 조합이 비었을 때의 안내를 추가했다.

| 색 | 분류 기준 | 예 |
|---|---|---|
| 회백 | 도안을 유지하는 기준점 이동·단순 위치/크기 조절 | 귀환점·동쪽의 문·고요 |
| 청록 | 축의 비율·고정 회전·단일 반경 파동을 바꾸는 조형 | 솟는 첨탑·직각의 춤·꽃잎 파동 |
| 보라 | 시간축 재해석·여러 겹의 잔상·축 간 혼합으로 궤적을 다시 조립 | 두 개의 고리·다중 리본·대위 레이스 |
| 금 | 여러 변형을 결합해 큰 실루엣 변화와 전술 조건을 함께 만드는 조형 | 유성 보폭·재를 걷는 바람·거울 프리즘·유성 군무 |

사용자가 기준으로 든 유성 보폭과 재를 걷는 바람은 금색으로 재분류했다. 이것은 피해량 순위가 아니다. 단순 이동은 상황에 따라 좋은 선택이지만 도안 변화의 범위는 작다. 최고 색이어도 무조건 더 많은 피해나 카드 효과를 복제하지 않는다. 전투 능력 수치는 기존41종에서 바꾸지 않았다. 새 원정의 상점 가격은 재분류된 내부 등급을 기존8+2×등급 식에 적용하므로8/10/12/14은화다. 등장 확률을 색에 따라 희소하게 만드는 추가 제한은 넣지 않았다.

## 신규64종의 실제 차이

새 카드는16개 수학적 변형 계통에서4개씩 파생된다. 같은 계통에서는 주기·축 조합·부가 효과를 달리한다.64개의 완전히 독립된 전투 시스템이라고 표현하지 않는다. 단순 기준점 이동 카드는 새64종에 없다.

- 꽃잎 파동: 이전 도안의 반경을3/4/6/8갈래로 부풀린다.
- 회전 화관: 도안 전체를 회전하면서 별도의 반경 파동을 건다.
- 파쇄 직조: 서로 다른 주기의 반경과 복소 비틀림을 함께 적용한다.
- 역행 잔상: 역방향 시간축으로 읽은 도안을 회전시켜 원본에 포갠다.
- 교차 전단: 다른 주기의 세로를 가로에, 가로를 세로에 섞는다.
- 나비 직조: 세로는 두 번 읽고 가로는 여러 겹의 날개로 펼친다.
- 위성 잔향: 원본을 공전시키고 역행하는 곡선을 겹친다.
- 제곱 잔상: 복소 제곱 도안과 역행 도안을 합친다.
- 축간 물결: 각 축을 서로 다른 주기 파동으로 휘감는다.
- 다중 리본: 가로와 세로의 시간축을3:2/4:3/5:4/7:5로 다시 읽는다.
- 대위 레이스: 정행/역행 곡선을 원본에 동시에 더하고 뺀다.
- 공전 매듭: 두 다른 시간축 도안 중 한쪽을 공전시켜 결합한다.
- 부채 날개: 가로·세로에 서로 다른 부채 파동을 적용한다.
- 안쪽 개화: 반경 계수가 음수로 넘어가 안팎이 뒤집히는 꽃잎을 만든다.
- 거울 프리즘: 한쪽 도안의 세로를 뒤집은 뒤 다른 도안과 묶어 회전한다.
- 유성 군무: 다중 반경 파동과 별도로 회전하는 역행 꼬리를 합친다.

모든 연산은 앞서 조립한 실제 F(t) 전체에 작용한다. 고정 문양을 대신 발사하거나 화면에만 화려한 그림을 얹지 않는다. 카드의 ‘잔상/위성/공전’은 이 순간의 곡선 합성 용어이며, 다음 턴의 자동 공격이나 루나의 설치 위성을 생성한다는 의미가 아니다. 카드 그림은 첫 파편 예시로 초기화하지만 실제 결과는 순서에 따라 달라진다.

부가 효과는 잔불+보호막, 파열+추진, 약화+회복, 노출+집중, 고정+요새화, 잔불+가시, 파열+재생, 적/자신 정화 조합이다. 한 카드의 두 효과 상한은 유지한다. 쌍방 정화를 결합한 신규 복합 조형은 금색으로 분류한다. 계통·주기·색·정확한 식은 `AdvancedWeaves.cs`, 카드 상태 효과는 `WeaveArchive.cs`가 소유한다.

## 계산·메모리·저장

- 기존 FragmentKind 값을 바꾸지 않고64개 프로필 키를 뒤에 붙인다. AdvancedWeaves는64개 불변 프로필과 사전 계산한 이름/설명/수식 문자열을 가진다. 새 이동·범위 판정 엔진은 만들지 않는다.
- 이전 x/y prefix를1536번 읽어 다음 층에 저장한다. 매 프레임 조합을 재귀 계산하지 않는다. 주파수는 연산별 곱/합의 보수 상한으로 검사하고96초과를 거부한다. 조립8개, 기준점 유지, 취소 버퍼를 그대로 쓴다. 새 연산에 별도 전투 샘플 배열은 없다.
- View의 기존 문양 배열은105장에 맞춰 생성한다. 신규 문양 생성에는 View 수명의 FragmentEquation 하나(약216KiB+메타데이터)를 재사용하며 카드마다65점만 보관한다. 프레임 중 식/문양 생성 없음. 도감 필터는기존105개 인덱스 버퍼를 재사용한다.
- 저장 형식2/규칙28. 새 원정은 기존 ContentExpansion 뒤에 GrandArchive를 기록한다. 초기 지도 선택 전에만 보상 풀105개와 시작 덱의 동일ID 재분류 정의를 채택한다. 기존21~27 이어하기에 삽입하지 않는다.
- Legacy는35개, Version27은41개의 원래 정의/가격을 유지한다. Find는 기존ID의 과거 정의를 반환하고 Current/All은 재분류105개를 반환한다. 이전 저널의 선택 RNG·가격·초기 덱을 바꾸지 않는다. 구버전 payload에 GrandArchive를 섞으면 거절한다. UI 색은 기존 저장에서도 최신 분류로 표시하되 과거 상점 가격은 보존한다.
- 신규64종은 새 원정의 카드 보상·연구권·상점 풀에 실제로 들어간다. 기존 저장에서 신종 카드를 받으려면 새 기록으로 출발해야 한다.

## 검증과 남은 범위

EditMode332/332 (`Logs/archive28-tests.xml`).105개ID/네 등급/지정 카드 금색,64개 실제 합성 곡선의 비중복·유한성·기준점 보존·정확한 취소,5계통의 독립 수식 검산,64개 첫 카드 사용과 미리보기/실제 피해 일치,주파수/조립 한도 거절,과거 정의 보존/저장 재생을 검사했다. 실제 상점에 신규64종 중 카드가 등장하여 구매·복원되는 경제 회귀도 포함한다.
