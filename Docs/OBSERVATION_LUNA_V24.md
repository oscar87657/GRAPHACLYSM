# 루나의 두 번째 전투 방식 · 쌍성 관측형

사용자가 원한 것은 J 기술 버튼 추가가 아니라 이안의 집행/기록처럼 출발 시 고르는 두 번째 전투 방식이다. 캐릭터 선택에 조율 루나 / 관측 루나를 나란히 제공하고 체험 전투에도 관측형을 추가했다.

## 실제 규칙

- 조율형은 기존 K 도안 이동·회전 / J 성운 견인과 공유 턴당 한 번을 그대로 사용한다.
- 관측형 K는 위성 하나를 설치하거나 옮긴다. 몸에서 3 이내, 중심 좌표 x=.5~9.5/y=-3.5~3.5, 기둥·활성 봉인 밖. 턴당 한 번이며 카드·체력·이동 기회를 소비하지 않는다.
- 위성은 전투 동안 남고 다음 전투에서는 다시 설치한다. 적의 공격 대상이나 피해를 흡수하는 방벽은 아니다. 배치 후 몸과 멀어져도 연결은 유지된다.
- 현재 작도가 몸 또는 위성에 닿으면 기존 자가 강화·궁극기 자가 효과·자가 적중 공명 규칙이 한 번 적용된다. 몸과 위성이 모두 닿아도 복제되지 않는다. 위성 판정은 몸과 같은 실제 선분/자가 적중 반경을 사용한다.
- 조립 전에 J로 다음 식의 출발점을 몸/위성 중 선택한다. 첫 카드에 선택한 실제 좌표를 사용하며 다음 조립에도 선택이 유지된다. 조립 중에는 전환할 수 없고 첫 카드를 취소해 빈 조립이 되면 다시 선택할 수 있다.
- 위성을 옮기거나 몸이 이동해도 이미 만든 식은 움직이지 않는다. 귀환점 카드는 원격 선택과 무관하게 몸으로 돌아온다. 조율형의 즉석 회전·견인은 관측형에 제공하지 않는다.
- 흰 작도·위성 판정 원·자가 강화 전달선을 함께 표시한다. 위성만 닿아도 몸의 보호 안내가 켜지는 것은 원격으로 강화를 받는다는 의미다. 적 조준과 피해는 여전히 실제 몸을 기준으로 처리한다.

운용 예: 몸에서 식을 조립 → 선 위에 위성을 설치 → 몸만 적 조준 밖으로 이동 → 방출하며 위성을 통해 보호. 다음 턴에는 J로 위성을 원점으로 선택해 몸을 옮기지 않고 먼 곳에서 식을 시작한다.

## 저장·범위

형식2/규칙24. CombatApproach.Observation=4를 추가하며 기존 enum 값은 유지한다. PlaceSatellite/SatelliteOrigin 명령을 끝에 추가한다. 위치는 0.01로 양자화하고 선택·위치·턴당 사용 여부는 명령 재생으로 복원한다. 기존21/22/23 저장은 계속 읽고 이전 명령 의미는 바꾸지 않는다. 이전 규칙 파일에 새 출발 값·명령이 들어간 경우 거절한다.

관측형은 원정 시작 선택과 전투 생성·재시작·체험에 연결했다. 기존 원정이 노드를 구매했다는 이유만으로 관측형으로 자동 변경되지는 않는다. 240노드 전체나 관측형의 전용 하위 특성/각성은 구현 완료로 취급하지 않는다. 현재 binary 핵심 설명은 시작부터 제공되는 기본 기능이며 중복 투자로 위성 수를 늘리지 않는다.

Core의 위성 상태는 BattleSession 소유 bool 두 개와 double 두 개다. 기존 approachUsedTurn을 배치에 재사용한다. 자가 적중은 기존 ResolvePlot의 단일 playerHit 처리로 합쳐 카드/궁극기 효과를 중복 호출하지 않는다. View는 코드로 표식을 그리며 새 텍스처·배열·매 프레임 문자열 할당을 추가하지 않는다.
