# GRAPHACLYSM 전투 개편: 수식을 짓고, 그 안에 선다

- 기준: 2026-09-06 사용자 요청
- 이 문서의 수치는 첫 플레이 검증용 설계다. 구현 여부는 PROTOTYPE.md와 구분한다.
- 확정 요구: 필드 위 플레이어, 아군 적중 버프, 더 작은 수식 카드, 중심에서 퍼지는 작도, 카드 설명·등급 표현, 캐릭터 궁극기, 이안과 흰머리 동생 루나, 아르케아 중심의 새 아트 방향.

## 1. 한 턴에 풀 문제

이번 공격으로 누구를 맞힐지, 자신도 선 위에 설지, 다가오는 적 공격을 피할지, 에너지를 수식과 위치 중 어디에 쓸지 고른다. 같은 선이 적에게 피해·약화를, 자신에게 보호·강화를 준다. 효과의 종류를 늘릴수록 위치와 조립 순서가 다른 답을 만들도록 한다.

기본 조작은 `적 의도 확인 → 이동과 수식 조립 → 적/자신의 적중 미리보기 → 필요하면 궁극기 준비 → 작도 → 적 행동`이다. 이동은 작도 전, 카드 사이에도 가능하다.

## 2. 좌표와 판정

- 전장: 기존 x=0~10, y=-4~4. 수식의 중심은 (5,0), 입력 u=x-5.
- 첫 위치: 플레이어 (4,-2), 피격 반경 0.48. 적처럼 원형 판정을 사용한다.
- 이동: 턴당 한 번, 상하좌우 1.5칸, 에너지 1. 필드 밖과 적의 몸 위에는 갈 수 없다.
- 자신의 그래프는 자신의 체력을 깎지 않는다. 자신을 적중하면 기본 보호막 3을 얻고 각인의 아군 효과를 받는다.
- 같은 작도에서 한 대상은 한 번만 효과를 받는다. 수천 번 교차하는 복잡한 그래프가 보호막·회복·충전을 무한히 쌓지 않는다.
- 축적 적은 축적 턴에 보호막 12를 얻고 해당 적 행동 종료 때 남은 보호막이 사라진다. 정화는 그래프 피해 처리 후 남은 강화부터 제거한다.
- 적의 일반 공격은 턴 시작에 플레이어가 있던 좌표를 조준한다. 이동 후 조준점이 따라오지 않는다. 축적 공격은 더 넓은 범위를 사용한다.
- 그래프 장식, 빛 번짐, 공개된 조준선은 피해 판정에 포함되지 않는다.

## 3. 카드의 단위

한 글자씩 입력하는 문법 퍼즐보다 의미가 있는 작은 연산 블록을 현재 구현으로 사용한다. 완성 포물선·장미 카드 대신 입력과 연산을 직접 연결한다.

| 분류 | 예시 | 결정하는 것 |
|---|---|---|
| 입력 | u=x-5, θ | 직교 또는 극좌표의 출발값 |
| 연산 | 제곱, 세제곱, sin, cos, 절댓값 | 현재 값의 모양 |
| 계수 | ×2, ×0.5, +1, -1, 부호 반전 | 연산 전후의 크기·오프셋 |
| 각인 | 수호, 잔불, 노출, 봉합 | 같은 선의 적/아군 효과 쌍 |
| 유틸 | 정화, 위상 | 상태 해제와 다음 이동·적 이동 제어 |

예: `u → 제곱 → ×0.5 → -1 → 수호`는 y=0.5(x-5)²-1인 방어용 포물선을 직접 만든다. `θ → ×2 → sin → ×2`는 r=2sin(2θ)가 되어 네 방향의 꽃잎을 만든다. 같은 계수를 sin 앞에 놓으면 반복 수가, 뒤에 놓으면 크기가 달라진다.

입력은 에너지 0, 대부분의 연산·각인은 1이다. 입력 1개와 최대 연산 8개, 각인·유틸 합계 최대 2개를 한 작도에 담는다. 입력 다음에는 연산과 각인을 섞어 놓을 수 있다. 연산은 순서대로 적용하며 반복 사용을 허용한다. 같은 각인은 한 작도에 중복 연결할 수 없다.

시작 덱과 보상은 새 조립 카드만 사용한다. 기존 18종 그래프는 수학 검증 자료로 보존하고, 이후 고급 제작식에 필요한 원시 연산으로 분해한다. 뉴턴 수렴처럼 별도 표현을 요구하는 식을 곧바로 일반 토큰과 합칠 수 있다고 표현하지 않는다.

## 4. 효과와 수명

| 효과 | 기능 | 소멸 시점 |
|---|---|---|
| 보호막 | 다음 피해를 먼저 흡수 | 적 행동 단계 종료 |
| 집중 | 다음 작도의 적중 피해 증가 | 해당 작도에 소비 |
| 재생 | 적 행동 종료 후 회복 | 정해진 적 행동 단계 수 소모 |
| 잔불 | 적 행동 시작 시 지속 피해 | 정해진 적 행동 단계 수 소모 |
| 약화 | 적 공격 또는 플레이어 작도 피해 감소 | 정해진 적 행동 단계 수 소모 |
| 노출 | 받는 그래프 적중 피해 증가 | 정해진 적 행동 단계 수 소모 |
| 고정 | 좌표 이동 의도를 막음 | 정해진 적 행동 단계 수 소모 |
| 경쾌 | 다음 이동의 에너지 비용 면제 | 이동에 소비하거나 지속시간 종료 |

첫 각인 쌍은 수호(적 약화 / 자신 보호막), 잔불(적 지속 피해 / 자신 집중), 노출(적 취약 / 자신 재생), 봉합(적 고정 / 자신 회복), 정화(적 강화 해제 / 자신 약화 해제), 위상(적 이동 고정 / 자신 경쾌)으로 구성한다.

새로 얻는 집중은 이번 공격을 소급 강화하지 않는다. 기존 집중을 먼저 사용하고 새 집중을 다음 작도에 남긴다. 각인으로 거는 노출도 다음 공격부터 적용한다. 자신을 맞힐 때의 회복은 최대 체력을 넘지 않으며, 과잉 회복은 다른 자원으로 바뀌지 않는다.

판정 순서는 기하·기존 상태로 피해 계산 → 피해 및 적 각인 적용 → 자신 적중 효과 → 궁극기 충전 → 사망 확인이다. 적 행동 단계는 지속 피해 → 생존 적의 공개 행동 → 플레이어 피해·보호막 → 재생·상태 시간 경과 → 승패 확인이다. 지속 피해가 마지막 적을 처치했을 때도 정상 보상을 지급한다.

## 5. 이안과 루나

두 캐릭터는 서로의 피부색이나 성격을 선악처럼 대비시키지 않는다. 이안의 어두운 기록과 루나의 밝은 봉합이 서로 다른 전투 습관으로 이어지도록 한다. 구체적인 나이·과거 사건은 제안으로 남긴다.

| 항목 | 이안 | 루나 |
|---|---|---|
| 관계·외형 | 참고 이미지의 흑발 캐릭터 | 이안의 흰머리 동생 |
| 전투 방향 | 관찰, 노출, 다음 공격 준비 | 위치 조정, 회복, 자신까지 잇는 수식 |
| 현재 능력치 | HP 42 / 에너지 4 / 손패 6 | HP 36 / 에너지 5 / 손패 6 |
| 궁극기 | 흑유리 개방 | 백야의 포옹 |
| 궁극기 방향 | 다음 작도 적중 피해 +6, 적 고정 | 다음 작도의 자신 적중 반경 확대, 자신 적중 시 추가 회복·보호막 |

궁극기는 공명 6으로 준비한다. 작도 1회에 기본 공명 1, 자신과 적을 함께 맞히면 추가 1을 얻는다. 대상 수나 선분 수로 충전량이 늘지 않는다. 작도 전에 준비를 취소할 수 있고 실제 작도에서 공명을 소비한다. 게이지는 전투 사이에 유지한다. 궁극기는 에너지를 소모하지 않지만 준비된 궁극기와 카드 선택의 결과를 미리 보여 준다.

## 6. 예시 판단

적이 현재 위치를 조준하고 있고 에너지가 2 남았다. 수식을 한 번 더 증폭하면 적 둘을 맞히지만 자신은 빗나간다. 이동 후 수호를 각인하면 적 하나만 맞히는 대신 공격을 피하고 보호막을 얻는다. 궁극기가 차 있다면 이번 턴 폭딜에 쓰거나, 다음 정예 전투로 게이지를 가져갈 수 있다.

다양함의 기준은 효과 개수가 아니라 이런 선택이 생기는가다. 이동으로 모든 공격을 항상 피할 수 있으면 넓은 축적 공격, 봉쇄 구역, 이동 적을 추가한다. 자신을 매번 손쉽게 맞힐 수 있으면 초기 위치·반경·에너지 비용을 조정한다.

## 7. 카드와 전투 UI

- 카드에 이름, 분류, 비용, 수식 조각, 한 줄 효과를 항상 표시한다.
- 상세 툴팁은 `수식 변화 / 적중한 적 / 적중한 자신 / 지속시간·중첩 / 지금 사용할 수 없는 이유`를 보여 준다.
- 등급은 테두리·상단 표시·등급명에 사용한다. 분류는 별도 문구로 구분한다. 작은 인장은 정식 프레임 작업의 제안이다.
- 일반: 은회색. 고급: 청록. 희귀: 라벤더. 전설: 창백한 금색. 높은 등급도 본문 대비를 유지한다.
- 플레이어는 밝은 반경·캐릭터 초상·이름, 적은 붉은 원으로 구분한다. 아군 적중은 민트빛, 적 적중은 청록으로 표시한다.
- 적의 공격은 붉은 조준 범위, 이동은 별도의 방향선으로 공개한다. 아군 버프 반경과 적 공격 반경은 실제 좌표 단위를 화면으로 환산한다.

## 8. 작도 연출

수식을 바꿀 때는 완성된 얇은 예측선을 즉시 보여 준다. 작도 때는 중심의 원환이 점등하고 확장되는 빛의 반경 안에서 실제 선이 나타난다. 작은 파편 입자와 궁극기 컷인은 후속 연출 제안이다. 직교·극좌표·폴리노미오그래프 모두 중심으로부터의 거리로 선을 공개하되 좌표 자체를 이동하거나 이미지를 늘이지 않는다.

판정은 완성 기하로 한 번만 계산한다. 작도 중 적·플레이어 이동과 카드 입력은 잠겨 예측과 실제 결과가 달라지지 않는다. 빛 번짐 아래에서도 선과 피격 원의 접촉이 보여야 한다.

## 9. 이후 검토할 전술 요소 — 미구현 제안

| 후보 | 발생시키려는 선택 | 도입 조건 |
|---|---|---|
| 봉쇄 지대 | 맞힐 위치와 서 있을 위치를 따로 고민 | 기본 이동이 지나치게 강할 때 |
| 반사 | 적 공격을 기다릴지 먼저 처치할지 | 적 의도와 방어가 안정된 뒤 |
| 침묵 | 각인에 의존한 덱의 우회 해법 | 해제·예고 수단과 함께 |
| 부식 | 보호막과 체력 회복의 가치 차이 | 방어 수치 테스트 이후 |
| 끌어당김·밀치기 | 다음 수식에 맞는 적 배치 | 위치 충돌·경계 규칙 확정 후 |
| 유보·보존 | 지금 쓰는 카드와 다음 턴 자원 | 드로우·취소 트랜잭션 확장 후 |
| 반사·복제·구간 | 수식의 공간 구조를 더 세밀하게 조립 | 다중 곡선 판정과 비용 규칙 이후 |
| 보스 좌표 왜곡 | 익숙한 연산을 다시 해석 | 가독성·접근성 검증 이후 |

무작위 회피율, 보이지 않는 저항, 중첩마다 달라지는 예외는 첫 개편에 넣지 않는다. 부가 효과는 시작 덱에서 한두 종류씩 배우고 보상으로 확장한다.

## 10. 구현 검증 기준

1. 적만 적중 / 자신만 적중 / 동시 적중 / 모두 빗나감의 결과가 다르다.
2. 같은 대상은 한 작도에 한 번만 처리한다. 샘플 교차가 늘어도 효과 적용 횟수는 늘지 않는다.
3. 연산 순서·반복·극좌표의 계산이 표시 수식과 일치한다.
4. 각인 취소 시 비용·손패·수식·예상 효과가 함께 복구된다.
5. 이동 한도·비용·필드 경계·적 점유·작도 중 입력 금지가 동작한다.
6. 상태의 중첩 상한·소멸 시점·지속 피해 승리·궁극기 소비를 테스트한다.
7. 이안과 루나 모두 타이틀부터 전투·보상까지 연결된다.
8. 16:9 Game 뷰에서 카드 설명·툴팁·플레이어·의도·방사 작도를 확인한다.
