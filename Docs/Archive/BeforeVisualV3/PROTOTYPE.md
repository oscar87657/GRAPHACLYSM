# GRAPHACLYSM Prototype · v0.5

2026-09-06 전투 조립 개편. [전체 기획](GAME_DESIGN_DOCUMENT.md), [전투 규칙](COMBAT_REDESIGN.md), [아트 조사](ART_DIRECTION.md)를 함께 참조한다.

## 실행과 조작

1. Unity 6000.3.23f1에서 `Assets/Scenes/SampleScene.unity`를 열고 Game 뷰를 **1920×1080**으로 설정한다.
2. Play → 새로운 작도 시작 → 이안 또는 루나 → 맵 진입로를 선택한다.
3. 매 턴 6장의 손패에서 **좌표 조각 또는 각도 조각** 하나를 먼저 낸다. 입력은 0 EN이다.
4. 제곱·사인 등의 연산과 배율·상수 카드를 순서대로 연결한다. 현재 만든 값 전체에 다음 연산을 적용한다.
5. 각인·유틸은 최대 2개까지 붙인다. 카드 호버 툴팁에서 적과 자신에게 생기는 효과, 지속시간, 사용 불가 이유를 확인한다.
6. 상단 화살표로 턴당 한 번 이동할 수 있다. 이동은 1 EN, 상하좌우 1.5칸이다. 붉은 범위는 이번 적 공격의 예정 범위다.
7. 선이 적에 닿으면 HIT와 피해량이, 자신에 닿으면 민트빛 반경과 자가 적중 안내가 나온다. 자신의 선은 피해 대신 기본 보호막 3과 각인 효과를 준다.
8. 공명 6이 되면 궁극기 버튼을 눌러 준비한다. 다시 누르면 취소하며 실제 작도에서 소비한다. 버튼 호버로 상세 효과를 확인한다.
9. `작도 실행`을 누르면 중앙에서 선이 펼쳐지고, 작도 완료 뒤 적 행동과 다음 손패가 자동 처리된다.
10. 우클릭 또는 상단 마지막 수식 조각 클릭으로 최근 카드 선택을 취소한다. 이동 비용은 카드 취소로 돌아오지 않는다.

전투 승리 후 카드 또는 정예 유물을 선택하거나 건너뛴다. 다음 조우에 체력·공명·덱·유물이 이어진다. 궁극기는 이안의 공격·이동 봉쇄와 루나의 정화·방어·회복으로 나뉜다. 자세한 수치는 COMBAT_REDESIGN을 따른다.

예시: `좌표 → 상수 -1 → 수호`는 y=(x-5)-1을 만들고 (4,-2)에 서 있는 자신에게 보호막을 준다. 적에게도 닿게 하려면 현재 적 좌표를 보며 배율이나 이동을 바꾼다. `각도 → 2배 → sin → 2배`는 r=2sin(2θ)다.

## 구현 범위

- 이안 HP 42 / EN 4, 루나 HP 36 / EN 5. 각 14장 시작 덱·기본 손패 6장.
- 플레이어 필드 배치, 턴당 이동, 고정된 적 조준점과 공격 범위, 자가 적중 보너스.
- 조립 카드 18종: 입력 2 / 연산 5 / 계수 5 / 각인 4 / 유틸 2.
- 보호막·집중·재생·잔불·약화·노출·고정·경쾌 8종. 중첩 수치 상한 24, 수명 경과, 정화.
- 축적 적의 보호막 12와 넓은 맹공, 일반 적의 약화, 맹공의 잔불 부여.
- 공명 충전·준비 취소·전투 간 유지, 캐릭터 궁극기 2종.
- 카드 설명, 사용 불가 이유 툴팁, 등급 테두리·색·등급명, 확대한 보상 카드.
- 얇은 전체 예측선과 중앙 방사 작도. 일반 곡선의 출력·충돌 샘플 160개 공유.
- 타이틀·캐릭터 선택·3층 분기 맵·전투·카드/유물 보상·완주/패배.
- 새 캐릭터 초상과 배경 v2. 기존 v1 파일과 사용자 참고 원본은 보존.

기존 완성 그래프 18종과 변환 4종, 폴리노미오그래프의 실제 선·GL 출력은 수학 보관함과 회귀 테스트에 남아 있다. 새 시작 덱과 보상은 그 완성 카드들을 사용하지 않는다. 고급 곡선을 모두 새 조립 문법으로 만드는 기능은 아직 없다.

## 재현

Editor에서 Test Runner의 EditMode 전체를 실행하거나 프로젝트가 닫혀 있을 때 다음 명령을 사용한다. 열려 있다면 검증 복사본을 사용한다.

```powershell
$unity = 'C:\Program Files\Unity\Hub\Editor\6000.3.23f1\Editor\Unity.exe'
& $unity -batchmode -projectPath $PWD.Path -runTests -testPlatform EditMode -testResults "$PWD/Logs/editmode-combat-v2.xml" -logFile "$PWD/Logs/editmode-combat-v2.log"
```

시각 진단은 검증용 프로젝트에 `-executeMethod Graphaclysm.Editor.CombatV2Smoke.RunBatch`를 전달한다. `-quit`, `-nographics`는 붙이지 않는다. 종료는 진단 도구가 담당한다. Game 뷰의 Full HD 프리셋이 필요하다.

## 현재 한계

수치는 첫 프로토타입 값이며 전체 런의 난이도·카드 출현율·반복 플레이 균형은 아직 조정 전이다. 정식 튜토리얼, 전투 스프라이트 애니메이션, 궁극기 컷인, 새 음향, 드래그 조립, 괄호·숫자 편집기, 상점·저장은 없다. 새 아트는 생성 시안이다.

화면은 IMGUI이며 Full HD를 우선 검증했다. 새 전투 전체의 GPU·프레임·할당 측정은 미완료다. 이전 GL 측정은 [PERFORMANCE.md](PERFORMANCE.md)의 변경 전 기준값으로 유지한다.
