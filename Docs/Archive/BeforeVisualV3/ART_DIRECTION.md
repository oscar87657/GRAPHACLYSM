## 이안

사용자 참고: `C:/Users/송인석/Downloads/1000010689(1).png`.

흑발, 청안, 은빛 나비 장식, 짙은 케이프, 흰 블라우스와 리본, 겹친 치마, 가방과 카메라를 읽을 수 있게 유지한다. 새 시안은 얼굴을 크게 재설계하기보다 이 실루엣과 소품을 판타지 전장에 연결했다. 검은 부분도 한 덩어리로 뭉개지지 않게 남색·보랏빛 반사광으로 나눈다.

카메라가 잃어버린 장면과 수식을 기록한다는 설정은 서사 제안이다. 사용자 확인 없이 과거·나이·성격을 확정하지 않는다.

## 루나

이안의 동생이며 흰머리로 대비한다는 요구를 반영한다. 밝은 머리, 백색 케이프, 청회색 그림자와 연보라 포인트를 사용한다. 리본·가방·나비 계열의 작은 모티프로 관계를 느끼게 하되 이안의 단순 색상 반전으로 만들지 않는다. 봉합·회복 성향은 둥근 빛과 열린 손의 형태로 표현한다.

## 색과 화면

| 역할 | 방향 |
|---|---|
| 배경 | 냉백색 하늘, 연보라 유적, 얕은 반사면, 낮은 디테일의 중앙 |
| 판독면 | 짙은 청회색, 불투명도 높은 설명 패널 |
| 실제 그래프 | 청록빛 예측선, 백청색 작도선 |
| 적 | 붉은 피격 원, 붉은 공격 예정 범위 |
| 플레이어 | 초상과 이름, 밝은 원형 반경, 자가 적중 시 민트빛 |
| 일반 / 고급 / 희귀 / 전설 | 은회색 / 청록 / 라벤더 / 창백한 금색 테두리와 등급명 |

밝은 배경만으로 전투 전체를 덮으면 가는 그래프와 작은 글씨가 사라진다. 현재 타이틀과 선택 화면에는 배경을 크게 쓰고 전투 필드에는 어두운 판독면을 겹쳤다. 등급은 색과 문구를 함께 표시한다. 정식 카드 프레임 일러스트와 아이콘 세트는 아직 없다.

작도는 중앙 (5,0)에서 확장되는 반경 안의 실제 선을 공개한다. 장식 원환은 판정에 참여하지 않으며, 얇은 전체 예측선은 작도 중에도 남는다. 별도의 입자 시스템·Bloom·궁극기 컷인은 미구현이다.

기존 v1 자산은 덮어쓰지 않았다. 이안의 참고 원본도 변경하지 않았다. 최종 제작 전에는 손·소품의 일관성, 작은 크기에서의 얼굴 가독성, 실제 전투 스프라이트 포즈를 별도로 정리한다.
