# GRAPHACLYSM 게임 기획서

버전 0.11 · 2026-09-06 · 카드 사전·기준점 이동·3층 원정 v7.

## 핵심 경험

카드의 빈칸에 앞선 궤적 전체를 넣고, 원하는 위치에서 방출하여 적에게 피해를 주고 같은 선 위의 자신에게 강화를 준다. 카드에는 이름·고유 문양·미완성 수식과 1~2개의 부가 능력을 담는다. 계산기·자유 문자 입력·시작 전용 카드·에너지 비용은 현재 런에 없다.

## 현재 전투

| 항목 | 구현 |
|---|---|
| 카드 | 17종. 회전·반경·비율·위치가 서로 다른 연산과 효과 |
| 시작 | 이안/루나 각각 12장 덱, 시작 손패 5장. 시작 덱에 귀환점 포함 |
| 손패/조립 | 각각 최대 8장. 손패 보존, 조립 카드는 별도 예약 |
| 방출 | 현재 궤적과 능력 발동, 적 행동 후 기본 2장 + 드로우 능력/유물 보충 |
| 응축 | 식/손패 보존. 첫 체력 2, 두 번째 체력 4 소비. 기본 1장 + 파편 보너스 최대 1장, 적 행동 |
| 해체 | 예약 파편을 버리고 적 행동, 기본 보충. 공격과 카드 추가 드로우 없음 |
| 위력 | 파편마다 추가 피해 0~3, 합계 최대 10. 선이 닿은 적에게 대상당 한 번 |
| 이동/취소 | 턴당 한 번 상하좌우 1.5 무료 이동. 작도 전 이동 취소. 응축 이후 새 파편만 취소 |
| 드로우 보호 | 예약 카드 재셔플 금지, 보너스는 한 번만, 넘치는 드로우/응축 보너스는 저장하지 않음 |

응축의 체력 비용은 보호막으로 막지 못하며 비용보다 체력이 많아야 한다. 일반 턴 보충 유물은 응축에 적용하지 않는다. 빠른 방출과 오래 준비하는 선택을 서로 다른 유물로 지원한다. 현재 수치는 검증 가능한 플레이 시안이며 재미와 전체 런 밸런스는 실제 플레이로 조정한다.

캐릭터 HP는 이안 42·루나 36. 자신이 선에 닿으면 기본 보호막 3과 카드의 자신 능력을 받는다. 공명 최대 6, 이안 궁극기는 피해 +6·적 이동 봉쇄, 루나는 자가 적중 범위 확대·정화·보호막 8·회복 5다.

## 서로 다른 무늬와 기준점

공통 F₀(t)=1.6exp(it)에 파편을 중첩하며 전장 좌표는 O+F(t)다. 초기 기준점 O=(5,0). 귀환점은 사용 당시 플레이어 위치로 기준점을 옮기고, 서쪽의 문은 왼쪽 2, 승천은 위로 1.5 이동시킨다. 카드 이후 플레이어 이동으로 이미 정한 기준점이 따라 움직이지 않는다. 기준점 이동은 취소·응축·방출 이력과 함께 관리한다.

여백/낙화는 F 내부에 상수를 더하는 변형이므로 뒤의 회전에 영향을 받는다. 기준점 이동 카드는 O를 바꾸므로 뒤의 회전에도 중심을 유지한다. 속삭임의 1/4 역회전, 오엽성의 5갈래 반경 변조, 격류의 1.7배 확대, 긴 황혼의 가로 1.4/세로 0.65 변형으로 기존 계수와 다른 곡선을 만든다.

정확한 실제 좌표로 표시·판정하고 화면에 맞춰 정규화하지 않는다. 1,536개 선분, 최대 주파수 96, 최대 8개 파편으로 비용을 제한한다. 작도는 현재 기준점에서 바깥으로 공개한다.

## 3층 원정

유리의 회랑 → 밤의 서고 → 무명의 천문대. 층마다 보스를 포함한 8개 방을 방문하고 한 경로는 총 24개 방이다. 45~66개 노드를 시드로 생성하며 화면에는 현재 층의 지도만 보여 준다. 매 층 3번째 방 비전투, 5번째 유물, 8번째 보스다. 기본 전투 방도 매 층 최소 3곳을 보장한다.

1·2층 보스를 이기면 체력 8 회복과 유물 보상 뒤 다음 층으로 이어진다. 덱·체력·공명·유물은 유지하고 조립식은 전투마다 초기화한다. 최종 보스에서만 완주한다. 후반 층은 적 체력·공격력이 증가한다. 이벤트 6종, 휴식·유물·덱 제거, 여덟 적 배치는 유지한다.

유물은 14종이다. 시작 보호막/공명, 첫 방출 피해, 3개 이하·6개 이상 조립 피해, 자가 적중 보호막, 이동 후 방출 보호막, 승리 공명 등을 추가했다. 에너지 유물은 현재 풀에 없다.

## 화면과 아트

메인에 카드 사전/유물 탭을 추가했다. 역할 필터·페이지·정확한 효과·첫 파편 곡선 예시를 제공한다. 카드 앞면에는 이름·역할색 문양·수식·짧은 동작·위력/드로우 배지를 둔다. 모든 능력을 전투에 상시 나열하지 않고 호버/상세에서 읽는다.

이동 버튼은 왼쪽 하단, 이동 취소/파편 취소는 그 위의 같은 행, 방출/응축은 오른쪽 고정 폭으로 배치했다. 응축 비용과 보충량은 버튼 가까이에 표시한다. 해체는 작은 보조 버튼으로 연다.

타이틀 인물 없음, 이안 v2·루나 v6·배경 v3를 유지한다. 루나는 긴 흰머리·밤 보라 고스 드레스, 이안과 반대 방향이다. 새 카드 문양은 기존 코드 선 체계를 사용하며 새 bitmap은 없다.
