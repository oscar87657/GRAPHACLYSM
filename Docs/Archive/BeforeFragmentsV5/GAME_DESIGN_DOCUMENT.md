# GRAPHACLYSM 게임 기획서

버전 0.8 · 2026-09-06 · 던전·계산기 전투 v4. PC 수식 조합형 덱 빌딩 로그라이트.

## 핵심 경험

**두 좌표의 식을 쌓아 궤적을 만들고, 적을 공격하면서 같은 선으로 자신을 강화한다.** 방마다 적의 배치가 바뀌고, 전투 사이 선택이 덱·체력·유물에 남는다.

시작 카드가 선의 출발점을 정하던 구조를 계산기로 바꿨다. 숫자·사칙연산·괄호·삼각함수로 x(t), y(t)를 직접 편집한다. 기술 카드는 선택한 좌표에 변형 하나와 적중 능력 두 개를 함께 붙인다. 계산기 입력은 무료이며 카드는 1 EN이다. 어떤 손패도 수식 시작을 막지 않는다.

## 현재 구현

| 항목 | 규칙 |
|---|---|
| 수식 | 두 좌표의 자유 입력과 계산기 버튼. t=0~2π, 필드 x에는 중심 오프셋 5 추가 |
| 작도 한도 | 필드 안의 선 길이 0.05~64. 복잡한 궤적도 길이 안에서 허용 |
| 카드 | CalculatorCardCatalog 11종. 수식 변형 하나 + 적/자신 적중 능력 |
| 시작 덱 | 이안·루나 각각 12장, 기본 손패 5장. 시작 전용 카드 없음 |
| 조합 | 카드 변형 최대 8개. 사용 시 선택한 x 또는 y에 순서대로 적용 |
| 유지 | 기본 두 식은 다음 턴·방에도 유지. 카드 변형과 그 능력은 해당 턴에만 유지 |
| 필드 | x=0~10, y=−4~4. 정면, 두 축의 단위 크기 동일 |
| 이동 | 초기 (4,−2), 반경 0.48. 상하좌우 1.5, 턴당 한 번, 1 EN. 작도 전 취소 가능 |
| 적중 | 적: 기본 피해 8 + 기울기 보너스 0~8 + 보정. 자신: 기본 보호막 3 + 기술 능력 |
| 궁극기 | 공명 최대 6. 작도 +1, 적·자신 동시 적중 추가 +1. 준비 취소와 전투 간 유지 |
| 런 | 캐릭터 선택 → 생성된 8층 던전 → 전투/비전투 방 → 보스 → 완주 또는 패배 |

카드 앞면은 이름·비용·선 그림·짧은 변화·능력 요약이다. 대상·지속시간·정확한 연산은 상세에서 읽는다. 수식과 능력을 따로 장착하지 않는다. 같은 대상과 여러 번 교차해도 피해와 각 카드의 능력은 대상당 한 번만 적용한다.

## 던전과 선택

한 런은 8층이며 전체 지도에 15~22개 방을 만든다. 보스층을 제외하면 층마다 2~3개 방이 있고, 선택한 경로의 8개 방을 방문한다. 새 여정과 재시작은 다른 시드를 사용한다. 같은 시드·캐릭터의 생성 결과는 재현 가능하다. 저장·시드 직접 입력 UI는 아직 없다.

전투·정예·보스·이벤트·유물·휴식의 여섯 종류를 구분한다. 3층은 이벤트 또는 휴식, 5층은 유물방, 8층은 보스를 보장한다. 모든 노드에 접근 경로가 있고 보스까지 이어진다. 선택한 갈림길에 따라 이후 접근 가능한 방이 달라진다.

이벤트는 멈춘 시계, 파편을 파는 사람, 지워진 도서관, 거꾸로 뜬 별, 서툰 작도, 닫히지 않는 상자 6종이다. 체력을 내고 카드·유물·공명을 얻거나 회복·덱 정리를 선택한다. 선택 전에 비용과 결과를 표시한다. 휴식은 체력 30% 회복 / 공명 3 / 카드 제거 중 하나, 유물방은 미보유 유물 선택 또는 체력 15% 회복이다. 모든 비전투 방은 지나갈 수도 있다.

제거한 카드는 이번 런에서 사라진다. 기본 손패 크기보다 덱을 줄일 수 없고 제거 화면에서 취소하면 체력 비용도 내지 않는다. 체력 비용으로 사망하는 선택은 막는다. 남은 유물이 한두 개면 실제 남은 수만 제시하며, 전부 모았으면 다른 선택으로 진행할 수 있다.

전투는 원형·윗줄·아랫줄·중앙 밀집·양 끝·수직·대각선·엇갈린 배치의 8개 원형에 반전과 위치 변화를 준다. 같은 원형 궤적으로 모든 배치를 해결하기 어렵도록 가장자리와 중앙 배치를 함께 넣었다. 정예와 보스는 능력치가 올라간다. 현재 AI는 기존 세 패턴을 조합하며 새로운 보스 전용 단계는 미구현이다.

## 이안과 루나

| 항목 | 이안 | 루나 |
|---|---|---|
| 외형 | 참고 원본의 흑발·청안, 나비 장식·케이프·카메라 | 흰 단발, 청록 재킷·바지, 투명 천문 작도륜과 컴퍼스 |
| 능력치 | HP 42 / EN 4 / 손패 5 | HP 36 / EN 5 / 손패 5 |
| 궁극기 | 흑유리 개방: 이번 피해 +6, 적중한 적 이동 봉쇄 | 백야의 포옹: 자신 적중 반경 1, 자가 적중 시 정화·보호막 8·회복 5 추가 |
| 덱 성향 | 잔불·보호막·노출 | 회복·재생·고정·이동 보조 |

루나는 이안의 흰머리 동생이라는 관계를 유지한다. 천문 도구 조율자 외형은 이번 디자인 제안이며 나이·과거 사건을 확정하지 않는다.

## 화면과 검증 범위

상아색 배경·먹빛 정면 좌표판·보랏빛 작도선·금속 장식을 사용한다. Orbit/Pretendard/Cormorant 서체와 등급 테두리를 유지한다. 전투 왼쪽은 계산기와 자원, 오른쪽은 적 의도, 아래는 손패다. 이벤트·휴식·유물·덱 정리 화면도 같은 스타일로 연결했다.

실제 함수의 선을 중심에서 바깥으로 공개하고, 완성 기하로 한 번 판정한다. 구현 수치와 순서는 [전투 설계](COMBAT_REDESIGN.md), 실행과 검증 기록은 [PROTOTYPE](PROTOTYPE.md), 조사·생성 기록은 [아트 방향](ART_DIRECTION.md)에 있다. 이전 v3 문서는 [보관본](Docs/Archive/BeforeRoguelikeV4/GAME_DESIGN_DOCUMENT.md)에 남겼다.

현재 수치·적 배치·잉크 64는 플레이 조정용이다. 자동 검사는 상태 전이와 수학 계산을 확인하며 재미나 전체 런 밸런스를 보증하지 않는다. 다음 검토는 반복되는 최적 수식, 좌표 편집 부담, 카드 변형의 가치, 정예 생존율이다. 단계형 튜토리얼·수식 즐겨찾기·카드 강화·상점·저장·새 음향은 미구현이다. 뉴턴 수렴 등 legacy 고급 그래프 모두를 현재 문법으로 만들 수 있는 것은 아니다.
