# 전투 설계 · 계산기 전투 v4

2026-09-06. 시작 카드를 뽑아 선을 여는 과정을 없애고 **직접 두 식을 쌓은 뒤 기술로 변형과 적중 능력을 더하는 전투**로 바꿨다. 별도 각인·유틸 카드는 실제 덱에 넣지 않는다.

## 계산기와 선의 길이

입력칸은 중심 기준 x(t), y(t)다. t는 0~2π를 한 번 진행하고 실제 필드 x에는 5를 더한다. 기본 식 `t-3`, `t-3`에서 시작하며 입력·수정 자체에 EN을 쓰지 않는다. 숫자·사칙연산·괄호로 항을 쌓고 삼각함수로 여러 회전을 결합할 수 있다. 최종 식은 기본 두 식에 사용한 카드 변형을 순서대로 감싼 결과다.

지원 문법: 숫자 0~12와 소수, t, pi, + − × ÷, 괄호, sin/cos/abs/sqr. 곱셈은 명시한다. 지수 기호 ^, 임의 함수, 코드 실행은 지원하지 않는다. 각 축 128자·64노드·연산 24개·재귀 깊이 16의 제한된 파서다. 편집은 두 축이 모두 유효할 때만 반영한다. 잘못된 입력은 마지막 유효 식을 망가뜨리지 않으며 UI는 미완성 입력 중 작도와 카드 사용을 잠근다.

기본 두 식은 다음 턴과 다음 전투에도 유지한다. 턴에 붙인 카드 변형은 다음 턴에 지워지므로 손패의 능력과 새로운 적 위치에 맞추어 다시 선택한다. 전투 계획 중에만 식과 카드 축을 바꿀 수 있다.

잉크는 **필드 안에서 실제로 긋는 선분 길이의 합**이다. 0.05 이상 64 이하에서 작도할 수 있다. 겹쳐 지나간 길이도 누적한다. 점·전부 정의되지 않은 식·지나치게 긴 궤적은 작도할 수 없다. 복잡한 수식의 전장 덮기를 제한하는 초기 규칙이며 64는 플레이 조정 대상이다.

### 두 회전으로 만드는 스피로그래프

```text
입력 x(t) = 2*cos(3*t)+cos(7*t)
입력 y(t) = 2*sin(3*t)-sin(7*t)
필드 x(t) = 5 + 입력 x(t),  0 ≤ t ≤ 2π
```

실제 두 회전 항을 평가하여 열 개의 꽃잎이 있는 궤적을 만든다. 선 길이는 현재 샘플링에서 약 52.5다. 완성 그래프 프리셋이나 이미지 공격이 아니다. 하이포트로코이드의 두 회전 좌표식을 재매개변수화한 예이며 t는 극좌표각 자체와 구분한다. 수학 근거는 [Wolfram MathWorld: Hypotrochoid](https://mathworld.wolfram.com/Hypotrochoid.html)를 참고했다.

중앙형 스피로그래프는 가장자리 적을 놓칠 수 있다. 던전의 여덟 배치 원형과 반전·좌표 변화를 통해 크기·이동·축별 변형의 필요를 만든다. 특정 수식이 늘 최선인지 여부는 실제 플레이에서 추가 검증한다.

## 기술 카드

모든 실제 카드는 1 EN이다. 카드당 수식 변형 하나 + 적중 능력 두 개다. `v`는 카드 사용 시 선택한 축의 이전 값이며 x축 중심 오프셋 5는 모든 카드 적용 뒤에 더한다. x와 y에 각각 붙인 카드의 순서가 보존된다. 카드 변형은 합계 최대 8개다.

| 이름 | 변형 | 적 적중 | 자신 적중 | 등급 |
|---|---|---|---|---|
| 잔향 | sin(v) | 잔불 2, 2회 | 집중 1, 2회 | 일반 |
| 은월 | cos(v) | 고정 1회 | 회복 2 | 일반 |
| 서리꽃 | v² | 약화 1, 2회 | 보호막 3 | 일반 |
| 파열 | 2v | 노출 2, 2회 | 집중 1, 2회 | 고급 |
| 고요 | v/2 | 약화 1, 2회 | 재생 2, 2회 | 일반 |
| 상현 | v+1 | 고정 1회 | 회복 3 | 일반 |
| 낙화 | v−1 | 잔불 2, 2회 | 보호막 3 | 일반 |
| 유리정원 | abs(v) | 노출 2, 2회 | 보호막 3 | 고급 |
| 검은 개화 | v³ | 잔불 3, 2회 | 집중 2, 2회 | 희귀 |
| 거울밤 | −v | 남은 강화 해제 | 해로운 상태 해제 | 희귀 |
| 월식 | −v | 고정 2회 | 경쾌 1, 2회 | 전설 |

모든 카드는 그래프 기본 공격을 공유한다. 자기 적중은 기본 보호막 3에 카드의 자신 능력을 더한다. 선에 닿지 않은 대상에게는 능력을 적용하지 않는다. 카드 사용 시에는 수식만 변하고 능력은 작도 적중 때 적용한다. 취소는 수식·비용·손패·향후 능력을 함께 되돌린다.

반복 카드는 각 카드의 능력을 한 번씩 합산하지만 선이 같은 대상과 여러 번 교차해도 피해나 능력을 중복 적용하지 않는다. 상태 수치 상한은 24, 수명은 긴 쪽을 유지한다. 실제 카탈로그는 CalculatorCardCatalog 11종이다. SkillCardCatalog/SpellCardCatalog/PrototypeCardCatalog는 legacy 수학·회귀 코드로 남아 있다.

## 위치와 의도

전장 x=0~10, y=−4~4. 화면은 760×608 논리 픽셀로 두 축 모두 단위당 76px이다. 화면 크기가 바뀌면 전체 UI를 균일하게 축소하고 남는 공간을 레터박스로 채운다.

플레이어 초기 (4,−2), 반경 0.48. 턴당 한 번 상하좌우 1.5 이동, 비용 1 EN. 경계 밖이나 적과 겹치는 위치에는 이동하지 못한다. 경쾌는 이동을 무료로 만들고 소비된다. 작도 전 `이동 취소` 또는 Backspace로 원래 위치·이동 기회·실제 소비 EN을 복구한다. 경쾌로 무료 이동했다면 경쾌의 수치와 남은 수명을 돌려주고 EN은 돌려주지 않는다. 연속 취소로 자원을 늘릴 수 없다. 카드 취소로 이동 에너지가 환급되지 않는다.

적은 턴 시작의 플레이어 위치를 조준하며 이동 후 따라오지 않는다. 일반 공격 반경 0.85, 맹공 반경 1.65. 일반 체력 피해는 약화 1, 맹공 체력 피해는 잔불 2를 준다. 축적 턴에는 보호막 12가 생기며 해당 적 행동 종료에 사라진다. 이동형 적은 공개한 목적지로 이동한다. 고정이 있으면 이동을 생략한다.

필드에는 기본적으로 현재 조준 범위 중 가장 넓은 하나만 표시한다. 적 또는 오른쪽 의도 패널에 마우스를 올리면 해당 적의 조준 범위·연결선을 강조한다. 명중 원의 실제 반경은 0.48이며 적 호버 시 윤곽을 표시한다. 이름·체력·행동은 오른쪽에 두고 작은 글로 필드를 채우지 않는다.

## 효과 순서와 수명

1. 완성 그래프와 기존 상태로 적중·피해를 계산한다. 기본 피해 8 + 기울기 보너스 0~8 + 집중·노출·유물·궁극기 보정.
2. 적의 보호막을 사용한 뒤 체력 피해를 적용하고, 사용한 기술 순서로 적 대상 능력을 적용한다. 정화도 피해 이후 남은 강화부터 제거한다.
3. 이전 집중을 소비하고, 자신 적중 시 기본 보호막·궁극기·각 기술의 자신 능력을 적용한다. 새 집중은 다음 작도용이다.
4. 궁극기 공명을 소비하고 작도 충전을 더한다. 사망을 확인하고 적 행동 또는 보상으로 전이한다.
5. 적 행동은 잔불 피해 → 생존 적 행동 → 재생 → 상태 수명 감소 순서다. 잔불로 마지막 적을 처치해도 공통 승리 처리로 보상을 지급한다.

보호막은 피해를 먼저 흡수한다. 현재 기술의 보호막은 이번 적 행동 종료까지다. 집중은 다음 작도에 소비된다. 재생·잔불·약화·노출·고정의 회수는 적 행동 단계 기준이다. 경쾌는 다음 이동 또는 수명 만료에 사라진다. 회복은 최대 체력을 넘지 않는다. 플레이어와 마지막 적이 같은 행동 단계에 죽는 경우 패배를 우선한다.

미리보기 피해 문구는 현재 보호막을 뺀 예상 체력 피해다. 보호막이 전부 흡수하면 `방어`로 표시하지만 선의 적중 능력은 여전히 발동한다. 새 집중·노출은 이번 피해를 소급 변경하지 않는다.

## 캐릭터와 궁극기

이안 HP 42 / EN 4, 루나 HP 36 / EN 5. 시작 덱은 각 12장, 손패 5장이다. 시작 전용 카드가 없으며 어떤 손패에서도 기본 두 식을 직접 편집할 수 있다. 유물로 손패·에너지가 늘어날 수 있다.

공명 최대 6. 작도마다 1, 적과 자신 동시 적중 시 추가 1을 얻는다. 적 수·교차 수로 충전량이 늘지 않는다. 궁극기를 준비했다가 취소할 수 있으며 실제 작도에만 6을 소비한다. 전투 사이에 공명이 유지된다.

- 이안 `흑유리 개방`: 이번 작도 피해 +6, 적중한 적의 이번 이동 봉쇄.
- 루나 `백야의 포옹`: 이번 자신 적중 반경 1. 자가 적중 시 추가 정화·보호막 8·회복 5.

## 표시와 작도 시간

카드 앞면은 기술명·비용·작은 선 그림·변화 설명·능력 요약이다. 수식과 지속시간은 호버 상세, 완성 수식은 `수식 보기`로 연다. 선택 이력에는 이름만 남긴다. 등급은 은회색/청록/라벤더/금색 테두리이며 상세와 보상에서 등급명을 함께 표시한다.

작도 1.85초: 0~0.18초 집광, 0.18~0.96초 중심에서 바깥으로 실제 선 공개, 1.08초 결과 처리, 이후 적중 파편·피해 숫자·잔광, 1.85초 적 행동과 다음 손패. 밝은 선은 얇은 백색 중심과 보라색 부드러운 가장자리로 구성한다. 전체 예측선은 유지한다. 궁극기는 이름 띠가 겹쳐진다.

계산기 곡선 768개 선분과 Core 클리핑을 렌더러·적/자신 판정이 공유한다. legacy 곡선은 160개 선분이다. 고주파·불연속 수식에는 근사 오차가 남으며 적응형 샘플링은 아직 없다. 효과 때문에 수식 좌표를 움직이지 않는다. 별 모양·금속 장식·빛 번짐은 판정에 참여하지 않는다. 작도 중 카드·이동 입력은 잠긴다.

## 이후 후보 — 미구현

봉쇄 지대는 이동 회피가 지나치게 강할 때, 밀치기는 적 배치를 바꾸는 선택이 부족할 때, 카드 보존은 다음 턴 준비가 부족할 때 검토한다. 반사·부식·침묵·보스 좌표 왜곡은 현재 카드 가독성과 밸런스를 검증한 뒤 추가한다. 복잡한 효과를 별도 카드로 계속 분리하여 조작 수를 다시 늘리지 않는다.
