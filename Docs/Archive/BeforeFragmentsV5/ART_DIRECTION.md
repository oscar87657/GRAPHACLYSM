# GRAPHACLYSM 아트 방향 · v4

2026-09-06. 최신 요구는 **모던함과 고풍스러움이 공존하는, 읽기 쉬운 화면**이다. v3 공통 화면을 유지하면서 생성 지도·계산기·이벤트·휴식·유물·덱 정리를 확장하고 루나를 새로 디자인했다. 이전 방향은 [v2 보관본](Docs/Archive/BeforeVisualV3/ART_DIRECTION.md)에 있다.

## 공통 시각 규칙

| 역할 | 적용 |
|---|---|
| 배경 | 상아색·연보라의 부유 공간. 천문 기구처럼 가늘게 새긴 금속·유리 파편은 가장자리로 보냄 |
| 좌표판 | 먹빛의 정면 직사각 판독면, 점 격자와 두 축, 가는 금속 모서리 |
| 그래프 | 얇은 보라색 예측선, 백색 중심·보라색 가장자리의 작도선 |
| 인물 | 큰 초상은 타이틀·선택·지도에 사용. 전투 왼쪽은 계산기, 필드는 작은 얼굴과 실제 원형 반경 |
| 적 | 작은 결정형 표식과 번호·체력 막대. 이름·행동은 오른쪽에서 읽음 |
| 적 공격 | 절제된 붉은 조준 원. 기본 하나만 표시하고 호버한 적을 강조 |
| 자기 강화 | 민트빛 반경과 적중 빛 |
| 등급 | 일반 은회색 / 고급 청록 / 희귀 라벤더 / 전설 금색. 등급명은 상세·보상에 표시 |

필드는 원근이나 쿼터뷰를 쓰지 않는다. x·y 모두 단위당 76 논리 픽셀로 실제 원이 원으로 보인다. UI 전체는 1920×1080 기준에서 균일하게 확대·축소한다. 축소된 화면에서도 장식이 어긋나지 않도록 선 좌표 변환을 하나의 행렬로 합성한다.

카드 앞면에는 기술명·비용·선 그림·짧은 변화·능력만 남긴다. 수식·분류·등급·지속시간을 모든 카드에 반복하지 않는다. 다섯 장은 겹치지 않는 일렬 배치이며 호버 시 살짝 올라간다. 보상은 전투 위의 복잡한 오버레이 대신 독립 화면이다.

| 역할 | 글꼴 | 선정 이유·출처 |

Arcaea의 실제 사용 글꼴이라고 주장하지 않는다. 위 조합은 이번 게임을 위한 선택이다. 세 폰트는 수정 없이 `Assets/Resources/Fonts`에 포함했고 OFL 문서는 `Docs/FontLicenses` 및 빌드에 포함되는 `Assets/StreamingAssets/FontLicenses`에 보관했다. OS 기본 폰트에 의존하지 않는다.

## 캐릭터

이안 참고 원본: `C:/Users/송인석/Downloads/1000010689(1).png`. 흑발·청안·은빛 나비 장식·어두운 케이프·블라우스·겹친 치마·가방·카메라를 유지한다. 흰머리 동생 루나는 단발·가느다란 땋은 머리·작은 초승달 금속 장식으로 이안의 긴 머리와 구별한다. 청록색 짧은 재킷, 상아색 셔츠, 짙은 바지, 밝은 부츠와 좁은 반투명 뒷자락으로 독립된 실루엣을 만든다. 대표 소품은 투명 천문 작도륜과 황동 컴퍼스다. 카메라·큰 케이프·치마·나비를 반복하지 않는다.

화면에서 루나를 천문 도구의 조율자로 소개한다. 이는 이번 외형 제안이며 인물의 구체적인 나이·과거·직업 서사는 확정하지 않는다. 선택 대사도 “틀린 회전은 없어. 아직 맞물리지 않았을 뿐.”으로 도구와 연결했다.

새 자산은 `luna-instrument-maker-v4.png`다. 첫 생성의 체크무늬가 RGB에 들어 있어 image_gen의 배경 추출 편집으로 실제 alpha PNG를 다시 받았다. 최종 1024×1536 Format32bppArgb와 모서리 alpha 0을 확인하고 Unity 화면에서 투명 경계를 확인했다. 사용자 이안 원본과 v2 초상은 보존했다.

## 작도 연출

중심 집광 → 바깥으로 새겨지는 선 → 적중점의 짧은 파편 → 잔광 순서다. GL의 부드러운 가장자리 셰이더로 얇은 중심선과 빛 번짐을 한 배치에 쌓는다. 거대한 회전 원환이나 바닥 원근은 사용하지 않는다. 궁극기에는 별도의 이름 띠를 더한다.

발광과 파편은 장식이고 실제 선의 좌표를 바꾸지 않는다. 1.08초에 완성 기하로 한 번 판정하고 1.85초에 다음 행동으로 넘긴다. 별도 렌더 파이프라인 Bloom·영상 컷인·신규 음향은 아직 없다. 이전 성능 측정은 이 새로운 화면 전체의 측정 결과가 아니다.

## v4 지도·계산기·방 화면

지도는 8개 세로 열과 최대 3개 레인이다. 전투 결정·이벤트 시계·휴식 초승달·유물 마름모를 코드로 그리고 방 종류와 이름을 붙인다. 이동 가능한 노드와 선택 경로를 강조하고 미래 연결선은 낮은 대비로 남긴다. 방 본문·비용·선택지는 별도 넓은 화면에서 읽는다.

전투의 왼쪽 초상 자리는 두 식 입력과 계산기 버튼에 쓴다. 카드 반복 문구 “선택 좌표를”를 없애고 “코사인으로 감싸기”, “두 배로 늘리기”처럼 짧게 쓴다. 대상 축은 필드 위에 한 번 표시한다. 수식과 카드 능력이 겹쳐 글이 몰리지 않도록 최종 식은 펼침 보기로 분리한다.

중심에서 선을 공개하는 연출은 유지하되 실제 계산기 기하는 768개 선분으로 표시·판정한다. 스피로그래프도 동일한 기하를 사용하며 발광 장식이 실제 좌표를 바꾸지 않는다. 새 음향은 이번 변경에 포함하지 않았다.
