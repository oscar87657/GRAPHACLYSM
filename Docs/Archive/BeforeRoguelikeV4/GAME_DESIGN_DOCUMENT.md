# GRAPHACLYSM 게임 기획서

버전 0.7 · 2026-09-06 · 카드·화면 v3. PC 수식 조합형 덱 빌딩 로그라이트.

## 핵심 경험

**기술 카드를 이어 선을 만들고, 그 선으로 적을 공격하면서 자신을 강화한다.**

카드 한 장은 수식 구성 하나와 적중 능력 1~2개를 함께 가진다. 수식과 능력을 각각 따로 플레이하던 구조를 통합했다. 완성 그래프를 고르는 방식은 사용하지 않는다. 예를 들어 `초점 → 잔향 → 낙화`는 y=sin(x−5)−1을 만들며, 적에게 잔불을 남기고 자신에게 보호막과 다음 작도를 위한 집중을 준다. 능력은 실제로 선에 닿은 대상에게만 적용된다.

사용자가 지적한 정보량을 줄이기 위해 카드 앞면에는 기술명·비용·선 모양·짧은 변화와 능력만 표시한다. 수식·효과 대상·지속시간은 상세 보기로 분리한다. 입력/연산/계수는 내부 문법이며 플레이어에게 매번 분류를 읽도록 요구하지 않는다.

## 현재 구현

| 항목 | 규칙 |
|---|---|
| 카드 | `SkillCardCatalog` 13종. 그래프 구성 하나 + 능력 1~2개 |
| 시작 덱 | 이안·루나 각각 12장, 기본 손패 5장. 시작 카드 한 장 이상 보장 |
| 비용 | 초점·월륜 0, 나머지 기술 1 EN |
| 조합 | 시작 1장 + 순서가 있는 변형 최대 8장. 반복 사용 가능 |
| 필드 | x=0~10, y=−4~4. 정면 표시, 가로·세로 단위 크기 동일 |
| 플레이어 | 초기 (4,−2), 반경 0.48. 턴당 한 번 상하좌우 1.5 이동, 1 EN |
| 적중 | 적: 기본 피해 8 + 기울기 보너스 0~8 + 상태/유물 보정. 자신: 기본 보호막 3 + 기술 능력 |
| 궁극기 | 공명 6. 작도당 +1, 적과 자신 동시 적중 시 추가 +1. 준비 취소·전투 간 유지 |
| 런 | 타이틀 → 여행자 선택 → 3층 분기 맵 → 전투 → 카드/정예 유물 → 완주·패배 |

입력 뒤의 연산은 현재 값 전체에 차례대로 적용한다. `월륜 → 파열 → 잔향 → 파열`은 r=2sin(2θ)다. 같은 배율이라도 사인 앞에 놓으면 반복 수가, 뒤에 놓으면 크기가 달라진다. 최근 카드 취소는 수식·비용·손패·향후 능력을 함께 복원하며 이동 비용은 돌려주지 않는다.

대상당 적중은 작도 한 번에 한 번이다. 여러 선분이 교차해도 효과가 반복되지 않는다. 여러 기술에 붙은 같은 능력은 각 기술당 한 번 합산한다. 모든 효과·수치·순서는 [전투 설계](COMBAT_REDESIGN.md)에 정리했다.

## 이안과 루나

| 항목 | 이안 | 루나 |
|---|---|---|
| 외형 | 사용자 참고의 흑발·청안, 나비 장식·케이프·카메라 | 흰머리 동생, 밝은 케이프와 연보라 포인트 |
| 능력치 | HP 42 / EN 4 / 손패 5 | HP 36 / EN 5 / 손패 5 |
| 궁극기 | 흑유리 개방: 이번 작도 피해 +6, 적중한 적 이동 봉쇄 | 백야의 포옹: 자신 적중 반경 1, 자가 적중 시 정화·보호막 8·회복 5 추가 |
| 덱 성향 | 보호막·잔불·수식 변형 | 극좌표·회복·집중·이동 보조 |

인물 관계와 참고 외형을 유지한다. 화면의 짧은 대사는 분위기 시안이며 나이·과거 사건·결말을 확정하지 않는다.

## 화면과 연출

상아색 대기, 먹빛 좌표판, 보랏빛 선, 가는 금속 장식을 공통으로 쓴다. 한글 제목·수치는 Orbit, 본문은 Pretendard, 영문 표제는 Cormorant Garamond다. 타이틀·선택·맵·전투·카드 보상·유물 보상·완주·패배·도움말에 동일한 스타일을 적용했다.

필드는 원근감 없는 정면 좌표판이다. 적 이름과 다음 행동은 오른쪽, 캐릭터와 체력·공명은 왼쪽에 둔다. 필드에는 대상 표식, 실제 위치, 피해 예상과 필요한 조준 범위를 남긴다. 카드 다섯 장은 겹치지 않는 일렬 배치다.

작도는 중심의 짧은 집광, 바깥으로 진행되는 발광선, 적중 지점의 파편, 잔광 순서다. 전체 예측선은 남고 실제 판정은 완성 기하로 한 번만 처리한다. 궁극기는 작도 위에 이름 띠를 추가한다. 새 음향과 별도 영상 컷인은 미구현이다. 조사·글꼴·자산 출처는 [아트 방향](ART_DIRECTION.md)에 있다.

## 남은 설계 과제

수치와 시작 덱은 플레이 검증용이다. 먼저 입력 카드 낭비, 한 턴 카드 사용 수, 자가 적중 빈도, 이동 회피율, 궁극기 주기와 정예 생존율을 측정한다. 효과를 더 늘리기 전에 현재 기술 각각이 다른 선택을 만드는지 확인한다.

이후 후보는 봉쇄 지대·밀치기·카드 보존·강화·상점·이벤트·저장이다. 기존 뉴턴 수렴 등 고급 그래프는 수학 보관함에만 있으며 일반 런 해금 콘텐츠는 아니다. 글자·괄호를 자유 입력하는 수식 편집기와 단계형 튜토리얼도 미구현이다.

규칙 변경은 Core 테스트, 화면 변경은 실제 Unity 캡처로 확인한다. [실행·검증 기록](PROTOTYPE.md)을 참고한다. 이전 기획은 [v2 보관본](Docs/Archive/BeforeVisualV3/GAME_DESIGN_DOCUMENT.md)에 있다.
