# GRAPHACLYSM 아트 방향 · v6

2026-09-06. 최신 요구는 **모던함과 고풍스러움이 공존하는, 읽기 쉬운 화면**이다. 수식 파편 전투의 정보를 줄이고 타이틀 인물을 제거했다. 루나는 앳된 인상과 긴 흰머리, 밤의 고풍스러운 고스 드레스로 재디자인했다. 카드는 완성 그래프 그림과 비용 숫자를 없애고 빈칸이 있는 기호를 강조한다. 이전 방향은 [v2 보관본](Docs/Archive/BeforeVisualV3/ART_DIRECTION.md)에 있다.

## 공통 시각 규칙

| 역할 | 적용 |
|---|---|
| 배경 | 상아색·연보라의 부유 공간. 천문 기구처럼 가늘게 새긴 금속·유리 파편은 가장자리로 보냄 |
| 좌표판 | 먹빛의 정면 직사각 판독면, 점 격자와 두 축, 가는 금속 모서리 |
| 그래프 | 얇은 보라색 예측선, 백색 중심·보라색 가장자리의 작도선 |
| 인물 | 큰 초상은 선택·지도에 사용. 타이틀은 얇은 천체 기하 장식만 사용. 전투 왼쪽은 파편 조립대, 필드는 작은 얼굴과 실제 원형 반경 |
| 적 | 작은 결정형 표식과 번호·체력 막대. 이름·행동은 오른쪽에서 읽음 |
| 적 공격 | 절제된 붉은 조준 원. 기본 하나만 표시하고 호버한 적을 강조 |
| 자기 강화 | 민트빛 반경과 적중 빛 |
| 등급 | 일반 은회색 / 고급 청록 / 희귀 라벤더 / 전설 금색. 등급명은 상세·보상에 표시 |

필드는 원근이나 쿼터뷰를 쓰지 않는다. x·y 모두 단위당 76 논리 픽셀로 실제 원이 원으로 보인다. UI 전체는 1920×1080 기준에서 균일하게 확대·축소한다. 축소된 화면에서도 장식이 어긋나지 않도록 선 좌표 변환을 하나의 행렬로 합성한다.

전투 카드 앞면에는 기술명·파편 기호·드로우 배지만 남긴다. 짧은 변화·능력은 호버, 보상·덱 제거의 넓은 카드에서 읽는다. 수식·분류·등급·지속시간을 모든 카드에 반복하지 않는다. 다섯 장은 겹치지 않는 일렬 배치이며 호버 시 살짝 올라간다. 보상은 전투 위의 복잡한 오버레이 대신 독립 화면이다.

## 작도 연출

중심 집광 → 바깥으로 새겨지는 선 → 적중점의 짧은 파편 → 잔광 순서다. GL의 부드러운 가장자리 셰이더로 얇은 중심선과 빛 번짐을 한 배치에 쌓는다. 거대한 회전 원환이나 바닥 원근은 사용하지 않는다. 궁극기에는 별도의 이름 띠를 더한다.

발광과 파편은 장식이고 실제 선의 좌표를 바꾸지 않는다. 1.08초에 완성 기하로 한 번 판정하고 1.85초에 다음 행동으로 넘긴다. 별도 렌더 파이프라인 Bloom·영상 컷인·신규 음향은 아직 없다. 이전 성능 측정은 이 새로운 화면 전체의 측정 결과가 아니다.

## 지도·파편 조립대·방 화면

지도는 8개 세로 열과 최대 3개 레인이다. 전투 결정·이벤트 시계·휴식 초승달·유물 마름모를 코드로 그리고 방 종류와 이름을 붙인다. 이동 가능한 노드와 선택 경로를 강조하고 미래 연결선은 낮은 대비로 남긴다. 방 본문·비용·선택지는 별도 넓은 화면에서 읽는다.

전투 왼쪽에는 파편을 안쪽부터 바깥쪽 순서로 쌓는다. 이름과 작은 들여쓰기로 순서를 보여 준다. 미완성 기호의 반복 표시는 상세 모드로 옮겼다. 새 파편은 짧게 아래에서 들어오고, 응축하여 확정한 파편은 색을 낮춘다. F를 값 하나가 아닌 궤적 전체로 받는 규칙은 상세 보기에서 설명한다.

전투 기본 카드는 기술명·기호·드로우 배지를 쓴다. 계산기, x/y 입력, EN 표시는 없다. 손패가 많아도 큰 축약 기호를 유지하며 호버 카드가 확대되어 변화와 능력을 표시한다. 카드의 괄호/빈칸은 그래프의 재료가 아직 비어 있다는 뜻이다. 등급 색과 기존 서체를 재사용한다.

방출·응축은 오른쪽의 주 행동으로 두고 해체는 `···` 보조 메뉴에 둔다. 응축의 적 행동/보충 설명은 호버로 표시한다. 해체로 공격하지 않는다는 세부 규칙은 도움말과 실행 문서에 기록한다. 화면의 “턴 드로우”는 받을 수 있는 보충량이며 손패 한도는 8장이다.

중심에서 바깥으로 선을 공개하는 연출은 유지한다. 현재 기하는 1,536개 선분이며 같은 선을 판정한다. 새 카드 조합의 곡선을 보기 좋게 만들기 위해 좌표를 임의로 늘리거나 화면에 맞추어 정규화하지 않는다. 형상이 바뀌는 이유는 실제 회전·중첩·반경·이동 연산이다.

v6는 코드 기반 정보 정리와 루나 bitmap 교체다. 전투 배경의 밝은 덮개를 alpha 0.91로 올려 가장자리 장식을 낮은 대비로 두었다. 적 목록은 이름·다음 행동·체력, 상세는 호버/상단 버튼으로 확인한다. 타이틀은 인물 없이 여백과 천체 선 장식으로 구성한다. 기존 기하·작도 연출·음향은 유지한다. 최종 17장으로 8장 손패, 호버/상세, 응축/방출, 이동 취소, 방 화면, 720p를 확인했다.
