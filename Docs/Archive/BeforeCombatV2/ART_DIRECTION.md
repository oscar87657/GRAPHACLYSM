## 1. 한 줄 방향

**고딕 성당의 어둠 속에서 중세의 천문 기구와 채색 필사본이 살아 움직이는 수학 다크 판타지.**

흔한 선술집·두루마리 판타지보다 `중세의 학문과 의식`에 집중한다. 금속으로 된 계산 기구, 손으로 그린 원형 도해, 금박이 벗겨진 책, 뾰족한 고딕 아치를 한 화면에 묶고 실제 전투 판정은 현대 게임처럼 선명하게 보여 준다.

## 3. 시각 원칙

### 3.1 중세는 재료로, 판타지는 빛으로 표현한다

- 중세: 석재, 벨럼, 잉크, 황동, 밀랍, 짙은 목재
- 판타지: 그래프 곡선, 교점, 룬 슬롯에서만 나오는 제한된 발광
- 발광하지 않아도 되는 테두리와 배경까지 네온으로 만들지 않는다.

### 3.2 장식과 판정을 분리한다

- 황동 원환과 필사본 문양은 분위기를 만든다.
- 청록색 주 곡선은 실제 공격 판정이다.
- 보라색 보조 곡선은 변환 또는 파동 효과다.
- 적중 지점만 순간적으로 상아색에 가까운 밝기로 번쩍인다.

### 3.3 화면의 위계는 필사본의 페이지처럼 만든다

가장 중요한 정보에는 넓은 금박 테두리를, 보조 정보에는 얇은 잉크선을 쓴다. 모든 칸을 화려하게 꾸미지 않는다. 빈 공간과 어두운 면이 있어야 금박과 마법이 살아난다.

## 5. 타이포그래피

- 영문 제목과 큰 장 제목: `Cinzel` 계열을 우선 검토한다. 로마 비문 계열의 골격을 사용하되 자간을 넓혀 의식적인 인상을 만든다.
- 한국어 제목과 본문: `Noto Serif KR` 또는 획이 단단한 명조 계열을 사용한다.
- 수식, 피해량, 좌표: 고정폭 글꼴을 사용해 숫자의 폭과 정렬을 유지한다.
- 장식용 블랙레터는 한두 단어의 장 제목에만 허용한다. 카드 설명과 버튼에는 사용하지 않는다.
- 제목은 이미지에 굽지 않고 Unity 텍스트로 렌더링한다. 현지화, 해상도 변경, 대비 조정이 가능해야 한다.

## 6. 화면별 규칙

### 타이틀

- 폐허가 된 고딕 서고와 거대한 아스트롤라베를 한눈에 보여 준다.
- 타이틀은 중앙 상단, 첫 행동 버튼은 중앙 하단에 둔다.
- 배경의 원환은 천천히 돌지만 제목 뒤의 명도 변화는 작게 유지한다.

### 캐릭터 선택

- 초상화가 화면의 중심이고 능력치는 아래쪽의 어두운 벨럼 판독면에 둔다.
- 선택 캐릭터는 금색 외곽선과 원환 회전으로 표시한다.
- 아르카는 육각형·직선·상아/청색, 노아는 파동·천구의·적색/자주색으로 구분한다.

### 전투

- 좌표 평면은 어두운 석판 위에 새긴 황동 눈금처럼 표현한다.
- 현재 수식은 펼친 벨럼 조각, 상태 정보는 금속 명판에 배치한다.
- 그래프와 적중 예상은 기존의 청록색을 유지해 장식에서 분리한다.

### 카드

- 카드 외곽: 얇은 황동선 → 어두운 가죽 → 안쪽 벨럼 순서의 3층 구조
- 기초 함수: 울트라마린 인장과 각진 상단 프레임
- 변환: 자주색 인장과 원형 상단 프레임
- 비용: 왁스 인장처럼 독립된 원형 슬롯
- 선택 가능 상태는 색만 바꾸지 않고 금박 테두리, 밝기, 상승 애니메이션을 함께 사용한다.

### 맵

- 양피지 지도가 아니라 성당 바닥에 새겨진 의식 회로로 표현한다.
- 일반 노드는 철, 정예는 자주색 유리, 보스는 적색 밀랍과 금박으로 구분한다.

## 7. 캐릭터 시각 설정

### 아르카 — 공리의 작도사

기하학적 안정성을 몸에 두른 학자 기사다. 상아색 망토와 남청색 로브, 황동 제도 도구를 사용한다. 실루엣은 수직선과 육각형에 가깝고, 자세는 정돈되어 있다. 발광은 작은 청색 점과 직선 연결에 집중한다.

### 노아 — 조화파의 술사

소리와 파동을 천구의처럼 다루는 궁정 마술사다. 자주색과 검붉은 로브, 조율 도구와 황동 고리를 사용한다. 실루엣은 비대칭 곡선과 느슨한 천으로 만들고, 발광은 보라색 파동과 반복 궤도에 집중한다.

## 9. 생성 프롬프트 기록

### 타이틀 배경

`고딕 폐허 서고 내부, 중앙의 거대한 황동 아스트롤라베와 수학 마법진, 필사본의 금박·울트라마린과 사실적인 중세 석재·금속을 결합한 16:9 다크 판타지 게임 배경. 중앙 상단 제목과 중앙 하단 버튼을 위한 어두운 여백. 텍스트, UI, 인물, 로고, 워터마크 없음.`

### 아르카

`상아색 벨럼 망토와 남청색 중세 로브, 황동 제도 도구를 지닌 성인 여성 학자 기사. 손 위에 육각형과 직선으로 된 작은 정리 마법진. 차분하고 분석적인 인상, 프리미엄 다크 판타지 캐릭터 선택 초상, 투명 배경, 텍스트와 UI 없음.`

### 노아

`검붉은색과 자주색 중세 로브, 조율 도구를 지닌 성인 남성형 궁정 음악 마술사. 손 사이에 보라색 조화파와 작은 천구의. 우아하고 불안정한 인상, 아르카와 짝을 이루는 프리미엄 다크 판타지 캐릭터 선택 초상, 투명 배경, 텍스트와 UI 없음.`

## 10. 금지 사항

- 모든 요소에 금색 테두리를 둘러 중요도 위계를 없애지 않는다.
- 네온 홀로그램, 현대 SF 패널, 유리 재질 모바일 UI를 섞지 않는다.
- 작은 본문에 장식 글꼴을 사용하지 않는다.
- 장식용 원환이 적에게 닿았다는 이유로 공격처럼 보이게 만들지 않는다.
- 실제 역사 종교의 상징을 그대로 핵심 문양으로 사용하지 않는다.
- 특정 게임의 카드 프레임, 캐릭터 실루엣, 로고 구성을 복제하지 않는다.
