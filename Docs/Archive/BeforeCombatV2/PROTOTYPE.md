# GRAPHACLYSM Prototype

전체 게임 방향과 확정·미정 규칙은 [GAME_DESIGN_DOCUMENT.md](GAME_DESIGN_DOCUMENT.md)에 정리되어 있다.
중세 판타지 시각 기준과 제작 순서는 [ART_DIRECTION.md](ART_DIRECTION.md)에 정리되어 있다.

## 실행

1. Unity에서 `Assets/Scenes/SampleScene`을 연다.
2. Game 뷰 해상도를 16:9로 설정한다.
3. Play를 누른다.

씬을 수정하지 않아도 `GraphaclysmBootstrap`이 프로토타입을 자동으로 생성한다.

## 조작

- 실행하면 타이틀 화면에서 `새로운 작도 시작`을 누른다.
- 아르카 또는 노아를 클릭해 능력치와 시작 성향을 확인하고 런을 시작한다.
- 런 종료 화면에서 같은 작도사로 재시작하거나 캐릭터 선택으로 돌아갈 수 있다.
- 매 턴 덱에서 뽑은 카드 5장을 받는다.
- 런 시작과 보상 이후에는 연결된 작도 지점 중 다음 경로를 선택한다.
- 손패는 화면 중앙을 기준으로 부채꼴로 펼쳐진다.
- 카드에 마우스를 올리면 부드럽게 앞으로 올라오며 확대·정렬·강조된다.
- 우클릭하거나 상단 수식 체인의 마지막 카드를 다시 누르면 선택을 취소한다.
- 파란 카드에서 기초 함수 하나를 고른다.
- 남은 에너지로 보라색 변환 카드를 연결한다.
- 청록색으로 빛나는 적과 예상 피해를 확인한다.
- 적 아래의 공격·축적·전이 의도를 확인한다. 전이 적은 황금색 선과 원으로 이동 목표가 표시된다.
- `작도 실행`을 눌러 그래프를 발사한다.
- 기울기가 큰 상태로 교차하면 피해가 증가한다.
- 사용한 카드와 남은 손패는 버린 더미로 이동하며, 드로우 더미가 비면 다시 섞인다.
- 전투에서 승리하면 서로 다른 카드 3장 중 하나를 보상으로 선택한다.
- 선택한 카드는 런 덱에 추가되며, 현재 체력을 유지한 채 다음 조우로 이동한다.

## 현재 검증 범위

- 타이틀, 캐릭터 선택, 런, 결과 화면의 전체 진입 흐름
- 능력치와 시작 덱이 다른 플레이 가능 작도사 2명
- 화면 배치 검증용 타이틀 배경과 캐릭터 초상. 최종 자산은 도트 아트로 교체 예정
- 기초 그래프 카드 18종: 직선, 포물선, 파동, 절댓값, 원, 장미곡선, 리사주, 나선, T-폴리모노, 3차, 4차, 5·8·12근 폴리노미오그래프, 하이포트로코이드, 마우러 장미, 하모노그래프, 슈퍼포뮬러
- 변환 카드 4종
- 정예 전투 유물 선택과 에너지·손패·피해·회복 효과
- 실시간 수식 및 그래프 미리보기
- 5·8·12근 뉴턴 수렴 경계·반복 등고선의 실제 선분 작도와 교차 피해
- 폴리노미오그래프 GL 배치 출력, 기존 미리보기·순차 작도·적 표시 순서 유지
- 일반·고급·희귀·전설 카드 등급과 가중 보상 추첨
- 회전하는 수학 마법진 장식층
- 그래프와 적의 교차 판정
- 기울기에 따른 피해량
- 사전 공개되는 적 의도와 맹공·축적·전이 행동 패턴
- 적 반격, 승리, 패배, 재시작
- 12장 시작 덱, 5장 드로우, 버린 더미 재순환
- 3층 분기 맵, 일반·정예·보스 조우, 경로 잠금과 완료 표시
- 카드 보상, 체력·덱 영속, 런 완주
- 마지막 카드 선택의 수식·에너지·손패·버린 더미 완전 복구

게임 규칙은 Unity에 의존하지 않는 `Graphaclysm.Core`에 있고, 현재 IMGUI 화면은 `Graphaclysm.Runtime`에 있다. 자세한 의존성·메모리 규칙은 프로젝트 루트의 `ARCHITECTURE.md`를 참고한다.

## 성능 및 회귀 검증

- Unity 메뉴 `GRAPHACLYSM → Diagnostics → Profile Polynomiograph`로 기존 IMGUI와 GL 출력을 비교한다. Play Mode가 꺼진 상태에서 실행한다.
- 도구가 Full HD(1920×1080)로 설정하고 5·8·12근을 각각 45프레임 준비 후 120프레임 측정한다. 결과는 `Logs/PolynomiographProfile/<실행 시각>/`에 CSV·환경 정보·Game 뷰 캡처로 저장한다.
- 성능 측정이 끝난 뒤 전체 프레임 할당의 Profiler 경로를 별도로 기록하고, 변환·마지막 변환 제거·부분 작도·다음 턴을 검증한다. 이 진단용 수식 설치는 시작 덱을 바꾸지 않는다.
- 실행이 끝나면 이전 Game 뷰 해상도와 Profiler 설정을 복구한다.
- 2026-09-06: Unity EditMode 44/44 통과. Full HD Game 뷰의 실제 캡처에서 그래프·적 겹침 순서, 변환, 순차 작도와 다음 턴 초기화를 확인했다.
- 측정 수치와 재현 명령, 남은 할당은 [PERFORMANCE.md](PERFORMANCE.md)에 기록한다.
