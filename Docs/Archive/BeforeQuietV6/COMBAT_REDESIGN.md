# 전투 설계 · 수식 파편 v5

2026-09-06. 계산기 UI·자유 입력·에너지 비용을 실제 런에서 제거했다. 카드를 차곡차곡 놓되 **각 카드의 빈칸에 앞선 궤적 전체가 들어가는 합성**을 사용한다.

## 회전의 합성과 중첩

F(t)는 중심 기준 복소 평면 궤적이다. 실수부가 x−5, 허수부가 y이며 t=0~2π다. 모든 파편은 F를 받아 새 궤적을 만든다. 기본 기준 F₀=1.6exp(it)는 카드들이 공유하는 회전이며 빈 조립대에서는 표시·공격하지 않는다. 시작 전용 카드가 없고 모든 파편이 첫 수로 가능하다.

단순한 sin(sin(F)) 계열에 갇히지 않도록, F의 시간 매개변수를 다시 읽는 역회전·고속 반복과 복소 곱셈을 사용한다. 이는 수학적으로 두 회전의 합으로 만드는 트로코이드 계열을 확장한 게임 설계다. 두 회전 좌표식의 근거는 [Wolfram MathWorld: Hypotrochoid](https://mathworld.wolfram.com/Hypotrochoid.html)이며 아래의 카드 연산·계수·비용 규칙은 이 프로젝트의 설계다.

예를 들어 잔향 → 윤무는 `1.6exp(3it)+0.8exp(−it)`, 윤무 → 잔향은 `1.6exp(3it)+0.8exp(−9it)`가 된다. 같은 카드도 순서에 따라 다른 주파수와 무늬를 만든다. 앞선 식의 일부만 수정하는 x/y 선택 UI는 없다.

| 파편 | 전체 궤적을 받는 변형 | 적중 능력 / 드로우 | 등급 |
|---|---|---|---|
| 잔향 | F(t)+½F(−3t) | 적 잔불 2 · 자신 집중 1 | 일반 |
| 윤무 | exp(2it)F(t) | 적 고정 1회 · 자신 보호막 3 | 일반 |
| 개화 | (0.65+0.35cos3t)F(t) | 적 노출 2 · 자신 회복 3 | 고급 |
| 파열 | 1.35F(t) | 적 노출 2 · 자신 보호막 3 | 일반 |
| 고요 | 0.72F(t) | 자신 재생 2 · 다음 보충 +1 | 일반 |
| 거울밤 | conjugate(F(t)) | 적 강화 해제 · 자신 해로운 상태 해제 | 희귀 |
| 여백 | F(t)+0.8 | 자신 보호막 3 · 다음 보충 +1 | 일반 |
| 낙화 | F(t)−0.8i | 적 잔불 2 · 자신 회복 3 | 일반 |
| 유리정원 | F(t)²/2 | 적 잔불 3 · 자신 집중 2 | 희귀 |
| 성운 | F(t)+F(5t)/3 | 자신 회복 3 · 다음 보충 +2 | 전설 |

지속 효과는 기본 2회, 보호막은 이번 적 행동 종료까지다. 카드의 파편 표시는 기호 요약이며 정확한 계수·대상·수명은 상세에 둔다. 모든 파편은 그래프 기본 피해를 공유한다. 드로우 능력은 적중과 관계없는 보충 효과이고 나머지는 실제 선에 닿은 대상에게만 적용한다.

## 손패·응축·방출

시작 덱 12장, 시작 손패 5장, 보존 손패 한도 8장이다. 카드를 쓰면 손패에서 조립대의 예약 영역으로 옮긴다. 파편은 최대 8개다. 비용 EN은 없고 빈 손패의 부족을 응축·드로우로 해결한다.

- **응축:** 현재 식과 손패 유지 → 파편 확정 → 적 행동 → 기본 2장 + 새 파편의 드로우 보너스 보충. 방출/해체 전까지 두 번 가능하다. 빈 식에서도 손패를 모으는 데 사용할 수 있다.
- **방출:** 현재 식으로 대상당 한 번 공격·자기 강화. 조립 예약 카드를 버린 더미로 이동한다. 적 행동이 끝나면 식과 카드 능력은 초기화하고 남은 손패는 보존하며 보충한다.
- **해체:** 예약 파편을 버리고 식을 비운 뒤 적 행동과 기본 보충. 공격과 파편 추가 드로우 없이 준비 횟수를 초기화한다. 잘못 조립한 식에서도 진행이 막히지 않게 한다.

드로우 파편은 다음 보충에서 한 번만 계산한다. 응축에 사용한 드로우 효과가 이후 방출에서 다시 나오지 않는다. 손패 한도나 남은 카드가 부족하면 가능한 수만 받고 남는 드로우 권리는 저장하지 않는다. 예약 카드는 버린 더미 재셔플에 참여하지 않아 자기 자신을 뽑는 순환이 없다.

이번 응축 이후 새로 놓은 카드만 역순으로 취소할 수 있다. 응축을 확정하면 그 이전 파편은 되돌릴 수 없다. 따라서 취소로 드로우를 엿보거나 보너스를 복제하지 못한다. 상태 보존·초기화는 BattleSession, 손패·예약·드로우는 DeckSession, 두 객체의 원자적 명령은 BattleGameSession이 소유한다.

첫 파편 이후 한 장마다 적중 피해 +2, 최대 +14를 준다. 이 보너스는 실제 적중한 적에게만 더하며 카드 수만으로 화면 전체를 공격하지 않는다. 여러 파편의 동일 능력은 카드당 한 번 합산하되 선이 같은 적을 여러 번 통과해도 피해를 중복 적용하지 않는다.

현재 런은 FragmentCardCatalog/FragmentRelicCatalog를 사용한다. 에너지 유물 두 종은 턴 드로우 +1로 바꿨다. 시작 손패 +1 유물은 첫 손패만 늘리며 한도는 여전히 8이다. 던전과 비전투 방의 지속 자원 규칙은 v4를 유지한다. 조립한 식은 다른 전투로 가져가지 않는다.

## 수학 출력과 제한

전장에 맞추어 곡선을 자동 확대·축소하지 않는다. 카드가 만든 실제 궤적을 표시·판정하며 경계 밖은 자른다. 이전 잉크 64 제한은 현재 모드에 적용하지 않는다. 여덟 카드 슬롯과 최대 주파수 96으로 출력 복잡도를 제한한다.

1,536개 동일 간격 점의 층별 버퍼를 사용한다. 역회전과 고속 반복은 이전 층의 매개변수 인덱스를 다시 읽으므로 F를 두 번 감쌀 때마다 계산량이 지수적으로 증가하지 않는다. 주파수 한도는 최대 성분의 보수적인 상한이며 카드를 바꾸거나 순서를 조정하면 추가할 수 있다. 무제한 수학 문법·프랙탈·임의의 고차원 도형 전체를 지원한다는 뜻은 아니다.

## 위치와 의도

전장 x=0~10, y=−4~4. 화면은 760×608 논리 픽셀로 두 축 모두 단위당 76px이다. 화면 크기가 바뀌면 전체 UI를 균일하게 축소하고 남는 공간을 레터박스로 채운다.

플레이어 초기 (4,−2), 반경 0.48. 턴당 한 번 상하좌우 1.5 이동, 비용 없음. 경계 밖이나 적과 겹치는 위치에는 이동하지 못한다. 현재 파편에는 경쾌를 넣지 않는다. 경쾌의 기존 무료 이동 규칙은 legacy 회귀에 남긴다. 작도 전 `이동 취소` 또는 Backspace로 원래 위치와 이동 기회를 복구한다. 파편 취소와 이동 취소는 독립된다.

적은 턴 시작의 플레이어 위치를 조준하며 이동 후 따라오지 않는다. 일반 공격 반경 0.85, 맹공 반경 1.65. 일반 체력 피해는 약화 1, 맹공 체력 피해는 잔불 2를 준다. 축적 턴에는 보호막 12가 생기며 해당 적 행동 종료에 사라진다. 이동형 적은 공개한 목적지로 이동한다. 고정이 있으면 이동을 생략한다.

필드에는 기본적으로 현재 조준 범위 중 가장 넓은 하나만 표시한다. 적 또는 오른쪽 의도 패널에 마우스를 올리면 해당 적의 조준 범위·연결선을 강조한다. 명중 원의 실제 반경은 0.48이며 적 호버 시 윤곽을 표시한다. 이름·체력·행동은 오른쪽에 두고 작은 글로 필드를 채우지 않는다.

## 효과 순서와 수명

1. 완성 그래프와 기존 상태로 적중·피해를 계산한다. 기본 피해 8 + 기울기 보너스 0~8 + 조립 보너스 2×(파편 수−1) + 집중·노출·유물·궁극기 보정.
2. 적의 보호막을 사용한 뒤 체력 피해를 적용하고, 사용한 기술 순서로 적 대상 능력을 적용한다. 정화도 피해 이후 남은 강화부터 제거한다.
3. 이전 집중을 소비하고, 자신 적중 시 기본 보호막·궁극기·각 기술의 자신 능력을 적용한다. 새 집중은 다음 작도용이다.
4. 궁극기 공명을 소비하고 작도 충전을 더한다. 사망을 확인하고 적 행동 또는 보상으로 전이한다.
5. 적 행동은 잔불 피해 → 생존 적 행동 → 재생 → 상태 수명 감소 순서다. 잔불로 마지막 적을 처치해도 공통 승리 처리로 보상을 지급한다.

보호막은 피해를 먼저 흡수한다. 현재 기술의 보호막은 이번 적 행동 종료까지다. 집중은 다음 작도에 소비된다. 재생·잔불·약화·노출·고정의 회수는 적 행동 단계 기준이다. 경쾌는 다음 이동 또는 수명 만료에 사라진다. 회복은 최대 체력을 넘지 않는다. 플레이어와 마지막 적이 같은 행동 단계에 죽는 경우 패배를 우선한다.

미리보기 피해 문구는 현재 보호막을 뺀 예상 체력 피해다. 보호막이 전부 흡수하면 `방어`로 표시하지만 선의 적중 능력은 여전히 발동한다. 새 집중·노출은 이번 피해를 소급 변경하지 않는다.

## 캐릭터와 궁극기

이안 HP 42, 루나 HP 36. 에너지 비용은 없다. 시작 덱은 각 12장, 손패 5장이다. 시작 전용 카드가 없으며 어떤 손패에서도 어느 파편이든 첫 카드로 사용할 수 있다. 유물로 시작 손패·턴 보충량이 늘어날 수 있다.

공명 최대 6. 작도마다 1, 적과 자신 동시 적중 시 추가 1을 얻는다. 적 수·교차 수로 충전량이 늘지 않는다. 궁극기를 준비했다가 취소할 수 있으며 실제 작도에만 6을 소비한다. 전투 사이에 공명이 유지된다.

- 이안 `흑유리 개방`: 이번 작도 피해 +6, 적중한 적의 이번 이동 봉쇄.
- 루나 `백야의 포옹`: 이번 자신 적중 반경 1. 자가 적중 시 추가 정화·보호막 8·회복 5.

## 표시와 작도 시간

카드 앞면은 기술명·빈칸이 있는 파편 기호·짧은 변화·능력 요약이다. 여덟 장 손패에서는 큰 기호와 두 줄 요약을 쓰고 호버 카드를 확대한다. 수식과 지속시간은 호버 상세, 완성 수식은 `수식 보기`로 연다. 왼쪽 조립대에는 이름과 파편을 순서대로 쌓고 확정된 파편은 색을 낮춘다. 등급은 은회색/청록/라벤더/금색 테두리이며 상세와 보상에서 등급명을 함께 표시한다.

작도 1.85초: 0~0.18초 집광, 0.18~0.96초 중심에서 바깥으로 실제 선 공개, 1.08초 결과 처리, 이후 적중 파편·피해 숫자·잔광, 1.85초 적 행동과 다음 손패. 밝은 선은 얇은 백색 중심과 보라색 부드러운 가장자리로 구성한다. 전체 예측선은 유지한다. 궁극기는 이름 띠가 겹쳐진다.

현재 파편 궤적은 1,536개 선분과 Core 클리핑을 렌더러·적/자신 판정이 공유한다. 최대 주파수 96을 넘는 추가 파편은 거부한다. legacy 계산기 768개/일반 곡선 160개는 이전 모드다. 선분 근사 오차는 남으며 적응형 샘플링은 아직 없다. 효과 때문에 수식 좌표를 움직이지 않는다. 별 모양·금속 장식·빛 번짐은 판정에 참여하지 않는다. 작도 중 카드·이동 입력은 잠긴다.

## 이후 후보 — 미구현

봉쇄 지대는 이동 회피가 지나치게 강할 때, 밀치기는 적 배치를 바꾸는 선택이 부족할 때, 카드 보존은 다음 턴 준비가 부족할 때 검토한다. 반사·부식·침묵·보스 좌표 왜곡은 현재 카드 가독성과 밸런스를 검증한 뒤 추가한다. 복잡한 효과를 별도 카드로 계속 분리하여 조작 수를 다시 늘리지 않는다.
