# GRAPHACLYSM 게임 기획서

버전 0.9 · 2026-09-06 · 수식 파편·응축 전투 v5.

## 핵심 경험

**카드의 빈칸에 앞선 식 전체를 넣고, 여러 턴 모은 파편을 하나의 궤적으로 방출한다.** 완성 그래프를 고르거나 계산기에 식을 입력하는 게임이 아니다. 카드에는 고유 기호와 미완성 수식, 함께 발동하는 능력을 담는다.

화면에서는 선택한 파편이 차곡차곡 조립대에 놓인다. 수학적으로는 뒤의 카드가 앞선 궤적 전체를 감싼다. 값에 sin을 반복 적용하는 연산만으로는 모양이 비슷해지므로, 앞선 궤적을 역회전·고속 반복·회전·반경 변조하는 연산을 함께 쓴다. 잔향 뒤 윤무와 윤무 뒤 잔향은 다른 결과다.

## 현재 전투

| 항목 | 구현 |
|---|---|
| 카드 | FragmentCardCatalog 10종, 기호/수식 파편 하나 + 능력 1~2개 |
| 비용 | 에너지 비용 없음. 카드와 이동 모두 무료 |
| 시작 | 이안·루나 각각 12장 덱, 시작 손패 5장. 어느 파편이든 첫 카드로 사용 |
| 손패 | 쓰지 않은 카드는 유지, 최대 8장. 적 턴 후 기본 2장 보충 |
| 조립대 | 최대 8장. 카드는 손패에서 별도 예약 영역으로 이동 |
| 응축 | 식과 손패를 보존하며 적 턴을 진행하고 보충. 방출/해체 사이 최대 두 번 |
| 방출 | 조립한 식과 모든 적중 능력 발동. 이후 조립대 초기화, 남은 손패 유지 |
| 해체 | 조립한 파편을 버리고 적 턴 진행. 공격과 파편의 추가 드로우 없음 |
| 드로우 능력 | 새로 붙인 파편의 보너스를 다음 보충에 한 번 적용. 손패 한도까지 받음 |
| 취소 | 이번 응축 이후 붙인 파편만 역순 취소. 응축한 파편은 확정. 이동은 작도 전 취소 가능 |
| 모으는 보상 | 첫 파편 이후 한 장마다 적중 피해 +2, 최대 +14. 겹친 선은 대상당 한 번 판정 |

준비에는 적의 행동을 감수하는 비용이 있다. 드로우 카드를 즉시 재활용하거나 취소로 새 카드를 엿보는 반복을 막기 위해 예약된 카드는 드로우/버린 더미와 분리한다. 드로우는 턴을 확정한 뒤 지급한다. 손패가 가득 차면 넘치는 드로우는 보관하지 않는다.

캐릭터 HP는 이안 42, 루나 36. 자신이 같은 선에 닿으면 기본 보호막 3과 카드의 자신 능력, 적은 피해와 적 능력을 받는다. 공명 최대 6과 두 궁극기를 유지한다. 이안은 피해 +6·적 이동 봉쇄, 루나는 자기 적중 반경 확대·정화·보호막 8·회복 5다.

## 아름다운 무늬를 만드는 방법

각 파편은 단순한 스칼라가 아니라 이전의 **평면 궤적 F(t)**를 받는다. 빈 조립대에는 모든 카드가 공통으로 사용하는 회전 기준 F₀(t)=1.6exp(it)가 있지만, 파편을 하나 붙이기 전에는 선도 공격도 없다. 시작 전용 카드를 뽑지 않는다.

잔향은 `F(t)+½F(−3t)`, 윤무는 `exp(2it)F(t)`다. 겹치기와 회전의 순서가 달라지면 회전 성분이 달라진다. 개화는 반경을 흔들고 유리정원은 복소 궤적을 제곱한다. 복잡한 무늬를 완성 이미지로 숨겨 둔 것이 아니라 카드 순서로 실제 계산한다.

에너지와 기존 잉크 64 제한은 현재 전투에서 사용하지 않는다. 대신 조립 슬롯·보존 손패·응축 횟수로 준비량을 제한한다. 수학 출력은 1,536개 선분과 최대 주파수 96의 제작상 한도를 둔다. 회전이 너무 촘촘해지는 카드는 추가할 수 없다. 카드의 위치·크기 변경도 그대로 적용하며 화면에 맞추어 자동 정규화하지 않는다.

## 던전과 아트

v4의 시드 생성 8층 던전, 전체 15~22개 방, 이벤트 6종, 전투·정예·보스·유물·휴식방, 카드 제거와 여덟 적 배치를 유지한다. 3층 비전투·5층 유물·8층 보스와 경로 접근성을 보장한다. 새 여정·재시작은 새 시드를 사용한다.

현재 유물 풀은 FragmentRelicCatalog다. 이전 에너지 유물 두 종은 턴 드로우 +1로 바꿨고, 시작 손패·피해·승리 회복 유물을 유지한다. 제거·보상에는 새 파편 풀이 나온다.

이안의 기존 디자인과 루나의 흰 단발·청록 재킷·바지·천문 작도 도구를 유지한다. 상아색 여백, 먹빛 정면 좌표판, 중심에서 바깥으로 드러나는 보랏빛 작도와 세 서체를 사용한다. 카드에는 비용 숫자와 완성 그래프 그림을 없애고 빈칸이 있는 파편 기호를 크게 놓는다. 자세한 변형 규칙은 호버와 수식 보기에 둔다.
