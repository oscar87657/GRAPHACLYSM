# 다시 만드는 성좌: 행동이 이어지는 하나의 나무

2026-09-13 재설계 초안. 이번에 반영한 것은 키워드 클릭 설명이다. 아래 성장 경로·비용·새 능력은 후속 구현 명세이며 아직 게임 규칙에 적용하지 않았다.

## 최신 요청으로 변경 · 규칙33 이후

아래의 ‘캐릭터당144노드 유지’는 더 이상 최신 방향이 아니다. 사용자는 전투방식별50~60노드, 하나의 뿌리에서 뻗는 전용 나무와 중요한 배타 갈림길을 요청했다. 궁극기 선행 구현과 최신 트리 후속 기준은 `BATTLE_REWORK_V33.md`를 따른다. 아래는 이전 검토 기록이다.

## 유지할 것과 바꿀 것

캐릭터당144개 규모의 나무, 아래에서 위로 올라가는 방향, 드래그·스크롤, 검색, 클릭 상세, 개별 환급, 전후 비교와 체험은 유지한다. 기술·궁극기·공통 효과를 별도 나무로 나누지 않는다. 같은 행동을 확장하는 노드가 가까워야 하지만, 좌우 대칭이나 기술 분류 때문에 억지로 모으지 않는다.

가장 먼저 없앨 것은 **효과 없는 노드를 돈 내고 지나가는 경로**다. 현재 `GrowthRuntimeSupport`는 핵심4개·조건부 특성3개·기존 궁극기6개를 새 전투 방식에 연결하지만, 그 길에는 미구현 노드가 섞여 있다. `IsImplemented` 표시만 바꾸거나 모든 빈자리에 피해 보너스를 붙이지 않는다.

출발할 때 고른 집행·기록·조율·관측은 이미 작동하는 능력이다. 같은 능력을 다시 사는 통행료로 쓰지 않는다. 출발 형태는 무료 장착 기록으로 표시하고, 처음6점은 그 능력을 확장하는 선택에 사용한다. 다른 출발 형태로 전환하는 기능과 추가 강화는 구분한다.

## 배치와 구매 규칙

바닥의 출발 기록 하나에서 최대3갈래로 출발한다. 이 지점은 효과 없는 유료 노드가 아닌 무료 출발 표식이다. 한 노드에서 나가는 일반 경로는 최대3개, 받는 경로는 최대2개를 목표로 한다. 실제로 두 능력이 모두 필요한 혼합 노드에만 AND 조건을 사용하고, 대체 진입은 OR라고 선 옆에 표시한다.

모든 선행 노드는 후속보다 낮은 행에 둔다. 한 행은 최대6개, 긴 연결선은 빈 통로를 지나도록 한다. 행 간격은 제목·기능명·상태 배지를 포함한 실제 노드 높이보다 커야 한다. 선행이 아닌 관련 효과는 연결선 대신 상세창의 ‘잘 맞는 능력’으로 보여준다.

위로 올라갈수록 ‘수치가 큼’이 아니라 조작과 전투의 변화가 커진다.

| 높이 | 선택의 역할 | 비용 초안 |
| --- | --- | --- |
| 출발 | 이미 고른 전투 방식 확인 | 무료 |
| 아래 | 기준점·카드·자가 적중을 사용하는 새 선택 하나 | 1점 |
| 중간 | 기술의 발동 조건·위치·순서를 변경 | 1~2점 |
| 위쪽 | 두 행동을 연결하거나 궁극기를 특화 | 2점 |
| 꼭대기 | 이전 선택을 확장하는 각성 | 2~3점 |

누적 투자 제한은 긴 필수 경로와 중복해서 적용하지 않는다. 첫 확장에22점 같은 문턱이 생기지 않도록, 한 갈래의 첫 변화는 시작6점 안에서 도달시키고 첫 혼합은1층 보스 전에 선택할 수 있게 한다. 최종35점 기본 예산은 우선 유지하되 상점 성장점까지 포함해 검증한다.

## 먼저 연결할 실제 행동

아래는 제작 순서다. 게임에서는 표의 분류별로 갈라진 화면을 만들지 않는다. 기존 ID는 효과가 이어지는 경우만 재사용하고, 의미를 바꾸면 새로운 규칙 정의로 분리한다.

| 우선 노드 | 플레이어가 다르게 하는 일 | 상태·판정 계약 |
| --- | --- | --- |
| 원점 못 | 지난 기준점과 현재 몸 중 다음 식의 시작점을 선택 | 빈 조립에서만 선택. 이동·카드 취소와 저장 재생에 좌표 보존 |
| 마지막 주석 | 마지막 카드의 모양 변환만 생략하고 적중 능력을 활용 | 원본 카드는 소비. 드로우 재발동 없음. 실제 식 재계산 |
| 자기 서명 → 반사 장갑 | 자신과 적을 함께 맞힌 뒤 방어한 공격을 다음 균열로 전환 | 서명은 반사 장갑을 찍기 전에도 다음 기술의 자기 보호에 사용하도록 함께 재설계. 막은 실제 공격만 계산 |
| 파열 집행 | 균열을 작도에 남길지 돌진으로 먼저 소비할지 선택 | 기존 구현 재사용. 다른 방식에서는 적용되지 않음을 표시 |
| 먹빛 필사 | 당장 방출하는 대신 응축하며 다음 공격을 준비 | 기존 기록형 효과 재사용. 응축 비용·적 행동은 그대로 |
| 이중 장부 | 두 기록 중 이번 적 배치에 맞는 하나를 선택 | 실제 선분 두 벌 보관. 사용하지 않은 기록 유지. 카드 능력 복사 없음 |
| 역상 조율 | 같은 식을 회전할지 뒤집을지 선택 | 기존 반전 조준 재사용. 미리보기와 실행 좌표 공유 |
| 이동 관측 | 몸을 피신시키며 위성을 남길지 함께 옮길지 선택 | 이동 확정 전에 두 결과 예고. 이동 취소는 위성도 되돌림 |
| 귀환문 | 식을 몸으로 가져오거나 몸을 기존 원점으로 이동 | 둘 중 하나만. 지형·경계·고정 검사. 카드 소비/취소 규칙 명시 |
| 반격 작도 | 보호막으로 버틴 뒤 최근 도형으로 반격 | 실제 적 공격 흡수에만 반응. 적 행동 단계당1회, 자기 재귀 금지 |

각각은 작동하는 작은 선택이어야 한다. ‘표식을 얻지만 몇 단계 뒤까지 아무 데도 쓰지 못함’이 남으면 첫 노드의 효과를 함께 고친다. 원점 기억→기록 위치 선택, 자가 적중→방어 반격, 이동 관측→귀환문처럼 공통과 캐릭터 노드를 섞어 연결한다.

## 궁극기는 이번 재설계의 상단에 포함한다

이안은 **집중해서 끝내기 / 다음 턴을 준비하기**, 루나는 **위치를 관리하며 지키기 / 손패를 둘로 나누기**를 먼저 완성한다. 나머지 궁극기는 이 차이가 실제 전투에서 확인된 뒤 확장한다.

- 임계점: 이번 도안에 실제로 맞는 적 중 한 명을 지정해 집중 공격한다. 피해가 어디서 모이는지 미리 보여주고 빗나간 적을 강제로 맞히지 않는다.
- 불멸의 기록: 현재 도안을 다음 두 턴에 남긴다. 적의 다음 위치를 예측해 기록하는 궁극기다. 일반 기록과 서로 덮어쓰지 않도록 슬롯과 발동 순서를 정한다.
- 만월의 포옹: 현재 도안 주변에 성역을 남긴다. 언제 보호받고 언제 사라지는지 전장에 표시한다. 보호막 수치만 늘리는 궁극기로 끝내지 않는다.
- 시계 없는 밤: 첫 방출 뒤 남은 손패로 한 번 더 조립하고 나서 적이 행동한다. 추가 드로우·일반 이동 갱신·같은 궁극기 재사용은 없다. 두 번째 방출을 포기하고 적 행동으로 넘기는 버튼도 둔다.

복제는 기하·피해 사건이며 카드 사용 사건이 아니다. 추가 공격이 기존 표식을 소비해 강하게 터지는 연계는 허용하되, 그 결과가 동일 기록/반격 사건을 다시 생성하는 순환은 차단한다. 각성은 투자한 플레이를 넓히는 보상으로 만들고 모든 보상을 동일 크기의 불이익과 교환하지 않는다.

## 실제 나무로 옮기는 단계

1. 새 원정 전용 성장 규칙과 무료 출발 기록을 만든다. 기존31 이하 원정은 예전 노드·가격·선행·명령을 그대로 재생한다. 진행 중 투자나 저장을 자동 초기화하지 않는다.
2. 실제 효과가 있는 노드 사이의 구매 경로를 먼저 연결한다. 미구현240개 설계는 삭제하지 않되 회색 계획 노드는 구매·선행 계산에서 제외한다. 새 경로를 사기 위해 계획 노드를 구매해야 하는 경우는 테스트 실패다.
3. 위 첫 확장과 네 궁극기를 한 묶음씩 Core·조준·예측·명령 기록·UI에 연결한다. 보조 노드 하나 때문에 기존 전투 방식을 다른 것으로 덮어쓰지 않는다.
4. 캐릭터당144개 전체를 같은 원칙으로 재배치한다. 미연결 설계를 한꺼번에 활성화하지 않고, 검증된 효과가 생길 때 실제 구매 경로로 편입한다. 원정 중 카탈로그 변경은 금지한다.

플레이 확인: 같은 적 배치에서 선택 전후로 몸/원점/카드 순서/방출 시점 중 무엇을 바꾸었는지 말할 수 있어야 한다. 이안 집행·기록과 루나 조율·관측을 각각 첫 층까지 진행하고, 첫 확장을 산 직후 써볼 전투가 있는지 확인한다. 숫자만 달라지고 행동이 그대로라면 상단 각성으로 늘리기 전에 해당 노드부터 다시 고친다.
