# 카드 색 전체 재분류 · 검토안 1

> 아래는 이전1차 검토 기록이다. 현재는 [규칙29의21/21/42/21 분포·효과·상점](CARD_MARKET_V29.md)으로 대체되었다.

2026-09-13. 105종 전체를 재검토했다. 사용자 후속 피드백으로 2차 조정한다. 이전 v28 계통 단위 분류를 대체한다.

## 기준

- 회색: 이동·확대·축소·고정 회전·단순 반사처럼 도안 구조를 보존하는 조절.
- 청록: 단일 특징이나 낮은 주기 조형을 더하는 재료.
- 보라: 도안 구조·적중 구도를 뚜렷하게 재구성하는 변형.
- 금색: 높은 밀도의 재직조나 반경 변조, 비선형/역행 합성으로 조합 결과가 크게 확장되는 핵심 변형.

연산 개수나 부가 효과 수가 아닌 실제 변형 범위·밀도·합성 확장성을 우선한다. 같은 계통도 각 변형별로 배정했다. 반복 횟수는 참고 지표이며 그 자체가 피해/범위 증가를 보장하지 않는다. 초기 원에서 단순해 보여도 비원형 도안을 합성했을 때 커지는 변화를 고려한다. 정화만으로 자동 금색이 되는 예외는 표시 분류에서 제거했다. 수치 기반 전수 플레이 밸런스 검증은 아니며 제작자 판단의 검토안이다.

분포: 회색 12, 청록 19, 보라 37, 금색 37. 총105종 중 39종의 색이 바뀐다. 같은 색 유지도 검토 결과다.

## 저장·가격·전투 보존

CardDefinition.DiagramRarity와 WeaveArchive.DiagramGrade가 현재 표시 분류를 소유한다. 기존 Rarity / WeaveProfile.Tier는 역사적 보상 추첨·상점 가격·위력을 보존하는 데이터로 유지한다. UI 전부와 도감 색 필터/화면 검증은 DiagramRarity를 사용한다. 이전 저장 카드도 최신 색을 보여준다. 이번에는 가격·등장 확률·카드 도안·부가 효과·피해·수식 제한을 변경하지 않는다. 따라서 새 원정 없이 재실행으로 색을 확인할 수 있다. 규칙28/저널 유지.

새 메모리는 WeaveArchive 정적 수명의 16개 4문자 문자열 표와 그 참조 배열뿐이다. 표시 조회는 switch/인덱스 조회이며 프레임별 할당은 없다. 프로필 Tier를 표시 등급으로 재사용하지 않는다.
