# 잔광 성좌 확장 · v41

## 범위

기존 14노드 / 26단계를 24노드 / 36단계로 확장한다. 기존 투자, 비용, 선행 조건, 분대 선택, 잔액을 보존한다. 추가 초기화나 환급은 하지 않는다. 전투용 성장점은 여전히 시작 3점 / 원정 총 9점이다.

## 추가 노드

모두 1단계. 선행은 해당 노드 1단계 이상이며, 새 효과는 기존 강화와 합산되어 다음 새 원정부터 적용된다.

| 노드 | 선행 | 실제 효과 | 잔광 |
| --- | --- | --- | ---: |
| 먼 길의 체력 | 최대 체력 | 최대 체력 +4 | 4 |
| 여분의 붕대 | 승리 회복 | 승리 회복 +1 | 4 |
| 깊게 울리는 기억 | 시작 공명 | 시작 공명 +1 | 5 |
| 겹쳐 쓴 부적 | 시작 보호막 | 시작 보호막 +3 | 5 |
| 든든한 출발 | 먼 길의 체력 | 최대 체력 +2, 시작 보호막 +2 | 6 |
| 다음 싸움의 준비 | 여분의 붕대 | 승리 회복 +1, 시작 공명 +1 | 6 |
| 넉넉한 여비 | 시작 은화 | 시작 은화 +8 | 5 |
| 숙련된 작도 | 작도 피해 | 그래프 피해 +1 | 6 |
| 두 번째 예비 열쇠 | 예비 열쇠 | 시작 열쇠 +1 | 6 |
| 넓게 펼친 손패 | 성장 경험 | 전투 시작 손패 +1, 매 턴 드로우 불변 | 7 |

손패는 기존 최대 손패 / 덱 크기 제한을 유지한다. 전체 투자 시 계정 기본 보조는 최대 체력 +12, 승리 회복 +5, 시작 공명 +4, 시작 보호막 +9, 작도 피해 +3, 시작 은화 +16, 추가 열쇠 +2, 시작 손패 +1이다. 분대와 유물 보조는 별도다. 잔광 수입과 성장 경험의 기존 상한은 늘리지 않는다.

## UI

기본 덱은 6장을 모두 들고 시작하므로 시작 손패 노드는 덱이 7장 이상이 된 뒤부터 유효하다. 노드 설명에 이 조건을 표시한다. 자동 검사는 기본 덱의 상한/저장 재생과, 카드가 늘어난 7장 덱의 실제 1장 증가를 나누어 확인한다.

단일 중앙 핵과 기존 줄기를 유지하고 후속 노드를 외곽으로 연결한다. 배경/노드 드래그, 세로 휠, Shift+휠 좌우 이동, 두 스크롤바, 중앙 복귀, 선행 노드로 화면 이동을 지원한다. 드래그 후 마우스를 떼면 노드 클릭이 발생하지 않는다. 클릭은 상세 선택뿐이며 습득 버튼에서만 구매한다.

노드 위치/이름은 정적 배열, 단계/설명 문자열은 계정과 선택이 바뀔 때 캐시한다. 이동 상태는 View 수명이며 계정이나 전투를 변경하지 않는다. 선분은 계산으로 viewport에 자르고, 중첩 GUI 그룹과 회전 선분의 clipping 충돌을 피한다.

## 저장 호환

- 계정 저장 v4: 기존 안정 ID 14개 뒤에 10개 추가. v1의 6개, v2/v3의 14개 저장을 읽고 추가 노드는 미습득으로 둔다. v3의 초기화 완료 표식은 그대로 유지한다.
- v40에서 이미 수행한 초기화를 다시 실행하지 않는다. 아직 v1/v2인 계정의 기존 v40 일회성 초기화 경로는 유지한다.
- 원정 규칙 41: 준비 명령의 비트 10~13에 추가 은화/작도/열쇠/손패를 저장한다. 예약 비트 9와 미정의 비트는 거절한다. 규칙 39 이하 파일에 확장 비트가 있으면 읽기를 거절한다.
- 체력/회복/공명/보호막은 기존 LegacyBenefits 시작 스냅샷에 합산된다. 이미 진행 중인 원정은 계정 재참조 없이 당시의 수치와 명령으로 재생한다.
- 사용자 저장 파일을 직접 수정하거나 사용자 Editor를 종료하지 않는다. 검사에는 별도 사본과 임시 계정만 사용한다.
