# 궁극기 선행 개편과 보스 추첨 · 규칙33

## 이번에 적용한 것

사용자가 요청한 순서대로 궁극기부터 바꾼다. 새 원정은 집행/기록/조율/관측에 따른 전용 궁극기를 시작부터 사용하며, 기존 궁극기의 단순 피해·자가 반경·회복 보정은 중복 적용하지 않는다. 공명6을 준비하고 실제 방출에서 소비하는 조작은 유지한다. 기존32 이하 저장은 이전 궁극기와 고정 보스 편성으로 재생한다.

| 전투방식 | 궁극기 | 실제 동작 |
| --- | --- | --- |
| 집행 이안 | 검은 종결선 | 본 작도로 맞히는 적을 중심으로 반경1.8 추가 공격12. 한 적은 여러 파열에 겹쳐도 한 번만 추가 피해. 돌진 대기 초기화 |
| 기록 이안 | 불멸의 기록 | 현재 실제 도안을 원래 좌표에 보관. 다음 두 번의 본 방출에 피해8+저장한 조립 위력으로 재현. 일반 K 기록과 별도 보관 |
| 조율 루나 | 시계 없는 밤 | 첫 방출 후 적 행동을 보류하고 남은 손패로 두 번째 조립. 추가 드로우·이동 갱신·상태 시간 경과·기술 대기 감소 없음. 두 번째 방출 또는 ‘추가 조립 포기 · 적 행동’으로 종료 |
| 관측 루나 | 만월의 성역 | 현재 실제 도안을 두 번의 적 행동까지 유지. 적 행동 직전 몸 또는 위성이 도안 선의0.85 안에 있으면 보호막10. 몸/위성 중복 지급 없음 |

집행 파열의 중심은 본 피해 적용 전에 고정한다. 본 공격으로 적을 처치해도 그 자리에서 예정한 파열은 발생한다. 기록/파열은 카드 사용·드로우·공명·유물 평가를 새로 호출하지 않는다. 일반 기록 뒤 궁극 후속을 해결하고, 새 궁극 기록을 보관한다. 보관/재현은 원본 카드 예약과 구분된다.

시계 없는 밤의 두 번째 조립에서는 응축과 궁극기 재사용을 막는다. 첫 조립 전에 이미 쓴 이동을 취소하거나 다시 받지 못한다. 아직 쓰지 않은 이동/기술은 기존 같은 턴의 기회를 사용할 수 있다. 첫 식의 드로우 능력은 적 행동 뒤까지 보류하고 두 번째 식의 드로우와 합산한다. 추가 조립을 포기해도 첫 식에서 발생한 드로우는 잃지 않는다. 추가 조립으로 이미 죽인 적은 다시 행동하지 않으며, 승리하면 바로 보상으로 이어진다.

성역은 원래 좌표의 도형을 유지한다. 몸이나 위성을 옮기면 그 도형에 실제로 접촉하는지를 다시 확인한다. 화면에는 남은 적 행동 횟수와 현재 접촉 시 보호막 획득 여부를 표시한다. 얇은 도안 선은 위치 표시이며0.85의 보호 반경 전체를 면으로 칠한 전용 성역 연출은 아직 없다.

## 층별 무작위 보스

기존5종에 새5종을 추가해 총10종이다. 각 층에서 해당 층의 두 후보 중 하나를 원정 시드로 선택한다. 방 진입이나 저장 불러오기 때 다시 추첨하지 않는다. 새 후보들은 기존 공격 도형을 서로 다르게 조합하는 패턴형 보스이며, 다섯 개의 완전히 새로운 공격 판정 시스템을 뜻하지 않는다.

| 층 | 기존 후보 | 새 후보 / 세 공격 |
| --- | --- | --- |
| 1 | 흑유리 섭정 | 거울의 결투사 / 쌍점·직선·쌍점 |
| 2 | 침묵의 서고장 | 잿빛 주교 / 십자·가로 띠·쌍점 |
| 3 | 무명의 천문왕 | 궤도를 삼키는 자 / 고리·가로 띠·직선 |
| 4 | 격자의 설계자 | 공백의 측량사 / 체크무늬·쌍점·격자 |
| 5 | 일식의 군주 | 종야의 지휘자 / 격자·고리·체크무늬 |

새 보스는 네 턴째 보호막12로 재정비하며, 체력 절반 이하의 다음 턴부터 공격 순서가 바뀌고 공격+2. 체력/공격의 기본값은 각 층 기존 보스와 같은120/6,170/7,220/8,270/9,340/10이다. 새 후보는 호위와 장애물 없이 배치한다. 기존 후보의 편성은 유지하므로 두 후보의 총 난이도가 동일하다고 보장하지는 않는다.

## 화면과 기존 성좌

루나 선택 화면의 두 줄 전투 설명을 기존 대사 ‘어긋난 회전을, 새로운 궤적으로 잇는다.’로 교체해 이안과 형식을 맞췄다. 전투방식 설명은 출발 선택에 유지한다.

새 원정의 이전 궁극기 노드는 구매/장착을 차단하고 전용 궁극기로 교체되었다고 안내한다. 효과 없는 구매를 허용하지 않는다. 이전 저장에서는 이전 노드 구매를 그대로 유지한다. 이번 단계에서50~60노드 전용 성좌를 구현한 것은 아니다.

## 다음 단계 · 최신 사용자 요청이 이전144노드 설계보다 우선

- 집행/기록/조율/관측마다50~60개, 목표55개의 전용 나무. 캐릭터당144개의 공용 나무 유지 방침을 폐기한다.
- 각 화면에는 출발 전투방식의 나무 하나만 표시한다. 하나의 무료 뿌리에서 아래→위로 성장하며 드래그/확대·축소를 유지한다.
- 뿌리는 이미 쓰는 능력의 출발점이다. 뿌리 최대3개, 보통 노드 최대2~3개의 후속 연결. 선행은 항상 더 아래에 두고 독립 노드를 만들지 않는다.
- 작동 방식이 충돌하는 중요한 갈림길은 배타 선택이다. 한쪽을 습득하면 반대쪽과 그 후속 경로가 잠긴다. 모든 갈림길을 배타로 만들어 다른 능력과의 조합까지 막지는 않는다.
- 모든 유료 노드는 실제 전투 효과와 검증을 갖춘 뒤 구매 가능하게 한다. 개수만 맞춘 샘플/통행료 노드는 새 나무에 넣지 않는다.
- 궁극기 분기는 이번 네 궁극기를 확장한다. 기술/궁극기/공통 효과를 별도 작은 트리로 나누지 않고 관련 플레이 흐름 속에 섞는다.
- 원정 도중 기존 투자를 자동 삭제하거나 무관한 효과로 옮기지 않는다. 새로운 전용 성장 카탈로그와 저장 버전을 별도로 적용한다.
