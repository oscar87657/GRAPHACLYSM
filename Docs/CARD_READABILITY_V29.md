# 카드 효과 가독성 · 규칙29 유지

2026-09-13. 카드 효과가 붙어 보인다는 피드백에 따라 Presentation만 수정한다. 카드105종/색 비율/효과/확률/가격/상점 상품/저장 규칙은 변경하지 않는다.

## 읽는 순서

후속 요청: 카드 맨 아래의 뽑기/위력 배지와 전용 구분선을 제거했다. 손패·확대·상점·도감·보상이 같은 앞면을 사용한다. 작은 카드의 설명 공간을 늘리고 실제 드로우 효과/상세 위력 정보와 전투 수치는 유지한다.

1. 도안 변화: 설명 문장을 먼저 보여준다.
2. 조립 위력: 별도 작은 줄. 복잡한 수식은 수식 안내에 포인터를 올려 확인한다. 상점 상세에는 하단에도 수식을 분리한다.
3. 효과: 각 효과에 별도 배경·안쪽 여백·블록 사이12px 간격을 준다.
4. 각 블록은 대상과 효과 이름 → 실제 효과 → 지속시간/제약 순서다. 즉시 회복/정화와 지속형 상태를 구별하고, 드로우의 파편당1회/응축 보너스 상한을 보존한다.

확대 카드 앞면의 가로 키워드 칩은 세로2행 요약으로 바꾼다. 대상·효과명·수치, 그 아래 기간을 표시한다. 요약 영역을 가리키면 기존 키워드 상세가 열린다. 손패 위 확대 카드는340×420으로 키우고 위로 이동해 손패와의 연결 통로·클릭 우선순위를 유지한다.

상점 상세, 도감, 전투 오른쪽 효과 안내, 보상 호버 상세, 보유 덱에 동일한 효과 블록을 적용한다. 보상 사이드 패널은 넓히고, 도감은 설명 영역을 확보하되 같은 실제 도안을 작은 동일 비율 영역에 보여준다. 수식이나 카드 효과를 없애거나 새 능력처럼 바꾸지 않는다.

## 소유권·성능·입력

`SkillVisual`에 EffectTitles/Bodies/Notes/Badges와 RuleText/OutputText를 View 초기화 시 캐시한다. 각 배열 길이는 카드 능력 수+드로우 표시 수(현재 파편 최대2)다. 과거/현재 실제 카드 참조별 설명을 유지한다. 새 정적 변경 가능 상태나 Core 의존성을 추가하지 않는다.

`GraphaclysmCardReadability`가4개 GUIStyle 및 재사용 GUIContent1개를 View 수명에 보관한다. 레이아웃은 실제 글꼴 CalcHeight로 줄바꿈 높이를 측정하며, 프레임마다 문자열 분해/배열 생성은 하지 않는다. 효과 블록의 필요한 높이와 제공 영역의 차이를 진단값으로 기록한다.

카드 구매/선택/방출 규칙과 상점 상세 버튼은 유지한다. 카드를 가리킬 때 오른쪽 효과 설명이 뜨는 기존 동작은 그대로이며 새로운 강제 팝업을 추가하지 않는다. 사용자 Editor와 저장을 보존하고 격리 사본에서 검사한다.
